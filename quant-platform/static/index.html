    策略 API 速查

    日频回测：handle_data 中的委托会在下一交易日开盘撮合

    生命周期

    initialize(context)

    回测开始时调用一次，用于设置参数、基准、费用。

    handle_data(context, data)

    每个交易日收盘后调用，编写信号逻辑并下单。

    下单（次日开盘成交）

    order(security, amount)

    按股数买卖，正数买入、负数卖出。

    order_value(security, value)

    按金额买卖，正数买入、负数卖出。

    order_target(security, amount)

    调整持仓到指定股数，传 0 即清仓。

    order_target_value(security, value)

    调整持仓到指定市值。

    order_target_percent(security, percent)

    调整持仓到总资产的指定比例，例如 0.95。

    行情数据

    data.current(security, field)

    当前 bar 的 open / high / low / close / volume。

    data[security]

    当前 bar 对象，含 close、limit_up、limit_down、paused 等。

    attribute_history(security, count, unit='1d', fields=None)

    最近 count 根日线，返回 {field: [...]}，包含当日。

    history(security, count, field='close')

    最近 count 个收盘价（或指定字段）的列表。

    get_current_data()

    全部标的当前 bar 的字典。

    账户与持仓

    context.portfolio.total_value

    账户总资产（现金 + 持仓市值）。

    context.portfolio.available_cash

    可用现金。

    context.portfolio.positions

    持仓字典：{code: Position}，Position 含 amount / available / avg_cost / price。

    get_position(security)

    返回单个持仓对象或 None。

    交易设置

    set_benchmark(security)

    设置业绩基准，如 000300.XSHG。代码中的设置会覆盖顶部基准选择。

    set_commission(rate, min_commission, stamp_duty)

    佣金率、最低佣金、卖出印花税。

    set_slippage(slippage)

    单边滑点比例，默认 0.0005。

    工具

    g

    跨交易日保存状态的对象，例如 g.counter = 0。

    log.info / log.warn / log.error

    写运行日志，显示在「运行日志」页。

    get_date()

    当前回测日期（date 对象）。

    交易规则

    • A 股 T+1：当日买入的股份次日才可卖出。
    • 买入按 100 股整手；卖出零股仅在清仓时允许。
    • 涨跌停 ±10%；佣金万三（最低 5 元）；卖出印花税 0.05%；默认滑点单边 0.05%。
    • 策略代码在本机执行，请只运行你信任的代码。
