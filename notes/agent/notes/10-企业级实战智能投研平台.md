# 10 企业级实战：智能投研平台

## 一句话

**本章把前九章落成一个可评审、可上线、可运维的企业级系统：一家券商/资管公司的智能投研平台，约 300 名研究员与投资经理用自然语言提问，Agent 调用行情、财报、研报 RAG、新闻、计算器等工具，产出带引用的结构化投研简报，经人工审批后发布。** 评审时真正被追问的不是「能不能跑」，而是多租户隔离、权限、审计、合规、成本与 SLO——这些才决定系统能不能进生产。

## 业务背景与目标

平台服务一家中型券商的研究所与资管投研团队（人数为示例规模）：研究员 240、投资经理 40、合规/风控 12，另有平台运维与数据管理员按最小权限只读/写入。

| 场景 | 典型提问 | 期望输出 | 主要工具 | 交互 | 建议 SLO（示例） |
| --- | --- | --- | --- | --- | --- |
| 个股速览 | 「宁德时代最近基本面怎么样？」 | 结论 + 关键事实 + 风险 | 行情、财报、新闻、研报 RAG | 同步 | P95 ≤ 15s |
| 财报对比 | 「对比这三家近三年毛利率和现金流」 | 对比表 + 差异解释 | 财报 ×N、计算器 | 同步/异步 | P95 ≤ 25s |
| 舆情跟踪 | 「过去 7 天 XX 的负面事件」 | 时间线 + 影响判断 + 来源 | 新闻、公告 | 定时异步 | 15 分钟内送达 |
| 研报初稿 | 「写一份 XX 首次覆盖的框架」 | 带引用的初稿 | 研报 RAG、财报、计算器 | 异步 | P95 ≤ 90s，人工修改量 ≤ 30% |

| 类型 | 成功指标 | 示例目标/SLO 建议 | 说明 |
| --- | --- | --- | --- |
| 北极星 | 周活跃研究员占比 | ≥ 60% | 有真实采纳行为 |
| 质量 | 简报采纳率 | ≥ 55% | 复制/下载/点赞 |
| 质量 | 引用可核验率 | ≥ 98% | 能定位到原文 |
| 风控 | 跨租户越权事件 | 0 | 一票否决 |

**非目标**（写进方案，避免范围蔓延）：

- 不做交易指令生成与下单执行，Agent 只产出研究材料。
- 不输出投资建议，不做组合推荐，不做自动发布。
- 一期只覆盖 A 股与公募基金，港股/美股/衍生品后续扩展。

| 决策点 | 选择 | 放弃的方案 | 理由 |
| --- | --- | --- | --- |
| 单/多 Agent | 单 Agent + 规划器 + 多工具 | 多 Agent 分工 | 任务线性；多 Agent 成本 3-10 倍，审批追踪更难 |
| 编排 | LangGraph 显式状态机 | 手写 while 循环 | 需要审批中断、断点续跑、崩溃恢复 |
| 同步/异步 | 15s 内同步，长任务走队列 | 全部同步 | 研报初稿 90s 会打爆连接池 |
| 隔离 | 逻辑隔离，大租户独立向量 namespace | 每租户独立集群 | 成本可控，当前规模无需物理隔离 |

## 多租户与权限

`tenant_id` 从 SSO token 解析后注入上下文，贯穿网关、编排、工具、检索、存储、日志。模型永远看不到也改不了它。

| 资源 | 隔离手段 | 关键约束 |
| --- | --- | --- |
| Postgres | 每表带 `tenant_id`，启用 RLS | 应用用受限角色，RLS 兜底 |
| Redis | key 前缀 `t:{tenant_id}:` | 禁止无前缀 key |
| 向量库 | 大租户独立 namespace，小租户共享 + 强制 filter | 检索入口统一封装 |
| 对象存储 | 前缀 `tenant/{id}/` + bucket policy | 预签名 URL 短时效 |
| 日志/Trace | 全字段带 `tenant_id` | 跨租户查询需审批 |

RBAC 管「能不能用这个工具」，ABAC 管「能看哪部分数据」，两者在工具网关叠加：

| 角色 | 工具权限（scope） | 数据范围 |
| --- | --- | --- |
| researcher | `market/financial/news/report:read` `calc:run` | 本部门 + 公开，密级 ≤ 1 |
| pm | 同上 + `portfolio:read` | 跨部门观点，密级 ≤ 2，禁客户信息 |
| compliance | `audit:read` `report:read` | 审计与发布物，密级 ≤ 2 |
| admin | `*` | 不含研报正文，需二次授权 |

ABAC 属性：`dept`、`clearance`（0 公开 / 1 内部 / 2 机密）、`market`、`data_domain`、`time_window`（离职员工禁入）。

```python
@dataclass(frozen=True)
class Principal:
    tenant_id: str; user_id: str; roles: frozenset[str]
    dept: str; scopes: frozenset[str]; clearance: int
def auth_middleware(request) -> Principal:
    c = verify_jwt(request.headers["Authorization"])    # 伪代码：验签 + 过期校验
    return Principal(c["tid"], c["sub"], frozenset(c["roles"]),
                     c["dept"], frozenset(c["scopes"]), c["clearance"])
def require(p: Principal, scope: str) -> None:
    if "*" in p.scopes or scope in p.scopes:
        return
    raise PermissionDenied(f"{p.user_id} 缺少 {scope}")
def authorize_tool(p: Principal, spec: "ToolSpec", raw: dict) -> dict:
    """工具执行前最后一道闸门，返回清洗后的参数。"""
    require(p, spec.scope)
    if p.clearance < spec.min_clearance:
        raise PermissionDenied("数据密级不足")
    if spec.allowed_depts and p.dept not in spec.allowed_depts:
        raise PermissionDenied("部门无权访问")
    if "tenant_id" in raw:
        # tenant_id 只能由服务端注入，客户端传入一律拒绝
        raise PermissionDenied("禁止客户端指定 tenant_id")
    return {k: v for k, v in raw.items() if k not in spec.fields_deny}
```

**权限红线**：Prompt 不是权限边界，所有判断必须在代码里；股票代码、文档 ID 要做归属校验；向量检索的租户过滤由服务端拼装；CI 必须有跨租户、跨部门、超密级三类用例。

## 工具层：Tool Gateway

| 工具 | 输入 | 输出 | 超时 | 重试 | 缓存 | scope |
| --- | --- | --- | --- | --- | --- | --- |
| `get_quote` | 6 位代码 | 最新价/涨跌幅/成交额 | 3s | 1 | 30s | `market:read` |
| `get_financials` | 代码、指标、报告期 | 指标 + 单位 + 口径 | 5s | 1 | 1h | `financial:read` |
| `search_news` | 关键词、天数（含公告） | top5 标题/日期/摘要 | 5s | 1 | 10min | `news:read` |
| `search_reports` | 查询、tickers | 片段 + 元数据 + 引用 ID | 8s | 1 | 10min | `report:read` |
| `calculator` | 受限表达式 | 数值 | 1s | 0 | 无 | `calc:run` |

统一 Schema 约定：一个工具只做一件事；描述写清**何时用、何时不用、单位、数据截止时间**；JSON Schema 强制校验；统一返回 `{data, as_of, source}` 或 `{error:{code,message,retryable}}`；错误回灌让模型自纠；单轮最多 4 个并行调用；写操作用 `tenant+tool+业务主键` 作幂等键，只读工具用参数哈希做缓存键。

```python
class ToolError(Exception):
    def __init__(self, code, message, retryable=False):
        self.code, self.message, self.retryable = code, message, retryable
@dataclass(frozen=True)
class ToolSpec:
    name: str; description: str; parameters: dict; scope: str
    timeout_s: float = 8.0; retries: int = 1; cache_ttl_s: int = 0
    min_clearance: int = 0; allowed_depts: frozenset[str] | None = None
    fields_deny: frozenset[str] = frozenset()
@dataclass
class ToolContext:
    principal: Principal; run_id: str; tenant_id: str
class CircuitBreaker:
    def __init__(self, threshold=5, cooldown_s=30):
        self.threshold, self.cooldown_s = threshold, cooldown_s
        self.fails, self.state, self.opened_at = 0, "closed", 0.0
    def call(self, fn):
        if self.state == "open":
            if time.time() - self.opened_at < self.cooldown_s:
                raise ToolError("CIRCUIT_OPEN", "工具暂不可用", True)
            self.state = "half_open"
        try:
            result = fn()
        except Exception:
            self.fails += 1
            if self.fails >= self.threshold:
                self.state, self.opened_at = "open", time.time()
            raise
        self.fails, self.state = 0, "closed"
        return result
def _with_timeout(fn, timeout_s, ctx, args):
    with ThreadPoolExecutor(max_workers=1) as pool:
        try:
            return pool.submit(fn, ctx, **args).result(timeout=timeout_s)
        except FuturesTimeout:
            raise ToolError("TIMEOUT", f"超过 {timeout_s}s", True)
def _audit(ctx, spec, args, status, ms, result=None):
    d = lambda v: hashlib.sha256(json.dumps(v, sort_keys=True).encode()).hexdigest()[:16]
    audit_sink.write({"run_id": ctx.run_id, "tenant_id": ctx.tenant_id,
                      "user_id": ctx.principal.user_id, "tool": spec.name,
                      "args_digest": d(args), "status": status, "latency_ms": round(ms, 1),
                      "result_digest": d(result) if result else None})
def register(spec: ToolSpec):
    def deco(fn):
        breaker, cache = BREAKERS.setdefault(spec.name, CircuitBreaker()), TTLCache()
        @functools.wraps(fn)
        def wrapper(ctx, **raw):
            args = authorize_tool(ctx.principal, spec, raw)    # 权限 + 清洗
            jsonschema.validate(args, spec.parameters)
            key = hashlib.sha256(json.dumps([ctx.tenant_id, spec.name, args],
                                            sort_keys=True).encode()).hexdigest()
            if spec.cache_ttl_s and (hit := cache.get(key)):
                return hit
            started = time.perf_counter()
            for attempt in range(spec.retries + 1):
                try:
                    result = breaker.call(lambda: _with_timeout(fn, spec.timeout_s, ctx, args))
                    cache.set(key, result, spec.cache_ttl_s)
                    _audit(ctx, spec, args, "ok", (time.perf_counter() - started) * 1000, result)
                    return result
                except ToolError as e:
                    if not e.retryable or attempt == spec.retries:
                        _audit(ctx, spec, args, e.code, (time.perf_counter() - started) * 1000)
                        return {"error": {"code": e.code, "message": e.message}}
                    time.sleep(0.2 * 2 ** attempt)
        REGISTRY[spec.name] = wrapper
        return wrapper
    return deco

def invoke(ctx, name, args):
    fn = REGISTRY.get(name)
    if fn is None:
        return {"error": {"code": "UNKNOWN_TOOL", "message": f"不存在：{name}"}}
    try:
        return fn(ctx, **args)
    except PermissionDenied as e:
        return {"error": {"code": "FORBIDDEN", "message": str(e)}}
```

## 编排层：LangGraph 状态机

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `run_id` / `tenant_id` | str | 全链路标识与隔离 |
| `user` | dict | user_id、部门、角色、scopes、密级 |
| `question` | str | 脱敏后的问题 |
| `messages` | list | 对话与工具消息 |
| `plan` | list[dict] | 规划步骤，≤ 6 |
| `evidence` | list[dict] | 工具结果 + 数字 + 来源 |
| `budget` | Budget | 步数、token、金额、截止时间 |
| `review` / `draft` / `approval` | dict | 审校、草稿、审批 |
| `steps` / `route` / `status` | int/str | 轮数、路由、状态 |

```
START → intake ─(空/违规)→ END
          │
          ▼
      planner（≤6 步）
          │
          ▼
   executor_llm ◄──────────┐
     │ tool_calls           │
     ▼                      │
   executor_tools ──────────┘
     │ 无调用 / 预算耗尽 / 步数超限
     ▼
   reviewer ──不通过且轮次<1──► executor_llm
     │ 通过或已重试
     ▼
   approval（HITL）──驳回──► END(rejected)
     │ 通过
     ▼
   publisher → END
```

```python
client = OpenAI(api_key=os.getenv("DEEPSEEK_API_KEY"), base_url="https://api.deepseek.com")
MODEL = os.getenv("AGENT_MODEL", "deepseek-chat")
PRICE_IN, PRICE_OUT = 2.0, 8.0            # 元/百万 token，示例价

@dataclass
class Budget:
    max_steps: int = 6; max_tokens: int = 60_000; max_cost_cny: float = 0.30
    used_tokens: int = 0; used_cost_cny: float = 0.0; deadline_ts: float = 0.0
def charge(b: Budget, usage) -> Budget:
    cost = (usage.prompt_tokens * PRICE_IN + usage.completion_tokens * PRICE_OUT) / 1e6
    return replace(b, used_tokens=b.used_tokens + usage.total_tokens,
                   used_cost_cny=round(b.used_cost_cny + cost, 6))
def exhausted(b: Budget) -> str | None:
    if b.used_tokens >= b.max_tokens: return "TOKEN_BUDGET"
    if b.used_cost_cny >= b.max_cost_cny: return "COST_BUDGET"
    if b.deadline_ts and time.time() > b.deadline_ts: return "DEADLINE"
    return None
class State(TypedDict):
    run_id: str; tenant_id: str; user: dict; question: str
    messages: Annotated[list, add_messages]
    evidence: Annotated[list[dict], operator.add]
    plan: list[dict]; budget: Budget; review: dict
    draft: dict | None; approval: dict | None
    steps: int; route: str; status: str
PLANNER_PROMPT = """拆成不超过 6 步的研究计划，只输出 JSON：
{"steps":[{"goal":"...","tools":["get_quote"]}]}。先硬数据，再研报观点，最后舆情。"""
EXECUTOR_PROMPT = """数字只能来自工具，估算必须用 calculator；观点必须带 [R1] 引用；
无证据写「未获取到」；不输出买卖建议；信息足够就停止调用工具。"""
def intake(s: State) -> dict:
    q = s["question"].strip()[:2000]
    if not q:
        return {"status": "rejected", "route": "end"}
    clean, _ = redact(q)
    return {"question": clean, "steps": 0,
            "budget": replace(s["budget"], deadline_ts=time.time() + 120),
            "messages": [{"role": "user", "content": clean}], "status": "planning"}
def planner(s: State) -> dict:
    resp = client.chat.completions.create(
        model=MODEL, temperature=0, response_format={"type": "json_object"},
        messages=[{"role": "system", "content": PLANNER_PROMPT},
                  {"role": "user", "content": s["question"]}])
    plan = json.loads(resp.choices[0].message.content or "{}").get("steps", [])[:6]
    return {"plan": plan, "budget": charge(s["budget"], resp.usage), "status": "executing"}
def executor_llm(s: State) -> dict:
    reason = exhausted(s["budget"])
    if reason or s["steps"] >= s["budget"].max_steps:
        return {"route": "review", "status": reason or "MAX_STEPS"}
    resp = client.chat.completions.create(
        model=MODEL, temperature=0.2,
        messages=[{"role": "system", "content": EXECUTOR_PROMPT}, *s["messages"]],
        tools=tool_schemas_for(s["user"]["scopes"]), tool_choice="auto")
    msg = resp.choices[0].message
    return {"messages": [msg], "budget": charge(s["budget"], resp.usage),
            "steps": s["steps"] + 1, "route": "tools" if msg.tool_calls else "review"}
def executor_tools(s: State) -> dict:
    ctx = ToolContext(principal_from_state(s), s["run_id"], s["tenant_id"])
    msgs, evidence = [], []
    for call in (s["messages"][-1].tool_calls or [])[:4]:
        args = json.loads(call.function.arguments or "{}")
        result = invoke(ctx, call.function.name, args)
        msgs.append({"role": "tool", "tool_call_id": call.id,
                     "content": json.dumps(result, ensure_ascii=False)})
        if result.get("error", {}).get("code") != "FORBIDDEN":
            evidence.append({"tool": call.function.name, "result": result,
                             "numbers": extract_numbers(result)})
    return {"messages": msgs, "evidence": evidence, "route": "executor"}
def reviewer(s: State) -> dict:
    draft = build_draft(s["question"], s["evidence"])
    problems = []
    if not draft.get("citations"): problems.append("NO_CITATION")
    if bad := check_numbers(draft, s["evidence"]): problems.append(f"UNSOURCED:{len(bad)}")
    if not compliance_gate(json.dumps(draft, ensure_ascii=False))["pass"]:
        problems.append("COMPLIANCE")
    if problems and s["review"].get("round", 0) < 1:
        return {"review": {"round": 1, "problems": problems}, "route": "executor",
                "messages": [{"role": "user", "content": f"审校未通过 {problems}，请补引用并删除无来源数字。"}]}
    return {"draft": draft, "review": {"round": 1, "problems": problems}, "route": "approval"}
def approval(s: State) -> dict:
    decision = interrupt({"run_id": s["run_id"], "draft": s["draft"], "review": s["review"],
                          "required_approver": "compliance" if s["review"]["problems"] else "author"})
    ok = decision.get("action") == "approve"          # 挂起，checkpoint 落 Postgres
    return {"approval": decision, "status": "approved" if ok else "rejected",
            "route": "publish" if ok else "end"}
def publisher(s: State) -> dict:
    key = f"{s['tenant_id']}/{s['run_id']}.md"
    object_store.put(key, render_markdown(s["draft"], s["approval"]).encode())
    notify(s["user"]["user_id"], f"简报已发布：{key}")
    audit_sink.write({"event": "publish", "run_id": s["run_id"], "key": key})
    return {"status": "published", "route": "end"}

g = StateGraph(State)
for name, fn in {"intake": intake, "planner": planner, "executor_llm": executor_llm,
                 "executor_tools": executor_tools, "reviewer": reviewer,
                 "approval": approval, "publisher": publisher}.items():
    g.add_node(name, fn)
g.add_edge(START, "intake")
g.add_conditional_edges("intake", lambda s: "end" if s["status"] == "rejected" else "planner",
                        {"planner": "planner", "end": END})
g.add_edge("planner", "executor_llm")
g.add_conditional_edges("executor_llm", lambda s: "executor_tools" if s["route"] == "tools" else "reviewer",
                        {"executor_tools": "executor_tools", "reviewer": "reviewer"})
g.add_edge("executor_tools", "executor_llm")
g.add_conditional_edges("reviewer", lambda s: "executor_llm" if s["route"] == "executor" else "approval",
                        {"executor_llm": "executor_llm", "approval": "approval"})
g.add_conditional_edges("approval", lambda s: "publisher" if s["route"] == "publish" else "end",
                        {"publisher": "publisher", "end": END})
g.add_edge("publisher", END)
from psycopg_pool import ConnectionPool
pool = ConnectionPool(os.environ["PG_DSN"], kwargs={"autocommit": True})

checkpointer.setup()

```

## 知识层：多租户 RAG

切块与检索的原理见 RAG 主题（第 03/04 章），这里讲平台化：**检索入口只有一处，租户过滤不可绕过，引用必须可定位**。隔离方案按租户规模选择：独立实例（强隔离、高成本）/ 独立 namespace（默认）/ 共享 collection + 强制 filter（小租户，需兜底）。

每个 chunk 至少带这些元数据：

| 字段 | 示例 | 用途 |
| --- | --- | --- |
| `tenant_id` | `broker_a` | 隔离 |
| `doc_id` / `version` | `rpt_0912` / `v3` | 引用与版本 |
| `publisher` / `author_dept` | `研究院电新组` | 可信度与权限 |
| `published_at` / `tickers` | `2026-09-12` / `["300750"]` | 时效、标的过滤 |
| `sensitivity` / `allowed_depts` | `1` / `["equity_research","*"]` | 密级与部门 |
| `page` / `section` | `12` / `竞争格局` | 引用定位 |

```
研报 PDF/HTML → 解析（版式/表格）→ 清洗去页眉页脚
  → 按章节切块（表格整块保留）→ 摘要/关键词 → 嵌入
  → 写临时版本 → 质量校验（条数/空块/重复）
  → 原子切换 alias → 旧版本保留 7 天可回滚
```

深度研报按章节 400-600 token、重叠 80；财报按报表 + 附注、重叠 50；公告按事项、不重叠。索引用 `doc_hash` 去重，嵌入模型升级必须全量重建并 A/B。

```python
@dataclass(frozen=True)
class Citation:
    cid: str; doc_id: str; page: int | None; snippet: str

def retrieve_reports(p: Principal, query: str, *, tickers=None, top_k=20, top_n=6):
    flt = {"tenant_id": p.tenant_id,                    # 服务端强制，模型不可见
           "sensitivity": {"$lte": p.clearance},
           "allowed_depts": {"$in": [p.dept, "*"]}}
    if tickers:
        flt["tickers"] = {"$in": tickers}
    hits = vector.search(collection=f"reports_{p.tenant_id}",
                         vector=embed(query), filter=flt, top_k=top_k)
    if not hits:                                        # 向量为空时关键词兜底
        hits = bm25_fallback(query, flt, top_k=top_k)
    return [Citation(cid=f"R{i+1}", doc_id=h.doc_id, page=h.page, snippet=h.text[:400])
            for i, h in enumerate(rerank(query, hits, top_n=top_n))]
```

引用是**契约**：写作节点只能引用检索返回的 `cid`，前端按 `doc_id + page` 跳原文；无引用的事实陈述降级为「观点」或删除；检索为空返回「未检索到内部研报」，禁止让模型自由发挥。

渲染结构固定为：标题 + 数据时间 → 结论 → 关键事实表（指标/数值/期间/来源）→ 观点 → 风险 → 引用列表 → 免责声明。免责声明由发布器统一追加，不交给模型。

**数字溯源**：工具返回数值时同步抽取数字白名单；草稿中的每个数字必须命中白名单，否则回炉或降级为定性描述。

```python
NUMBER = re.compile(r"(?<![\w.])-?\d+(?:\.\d+)?(?![\w.])")

def check_numbers(draft: dict, evidence: list[dict]) -> list[str]:
    allowed = {round(float(n), 2) for e in evidence for n in e.get("numbers", [])}
    allowed |= {float(y) for y in range(2018, 2031)}       # 年份白名单
    return [f"{sec}:{raw}" for sec in ("conclusion", "facts", "views", "risks")
            for item in draft.get(sec, [])
            for raw in NUMBER.findall(str(item.get("text") or item.get("value", "")))
            if round(float(raw), 2) not in allowed]
```

**PII 与合规过滤**：入模前、出模后各脱敏一次；敏感词与直接建议拦截；命中转人工。

```python
PII = {"phone": re.compile(r"1[3-9]\d{9}"), "id_card": re.compile(r"\d{17}[\dXx]"),
       "email": re.compile(r"[\w.+-]+@[\w-]+\.[\w.]+"), "bank_card": re.compile(r"\b\d{16,19}\b")}
BANNED = ("保证收益", "稳赚不赔", "内幕消息", "必涨", "推荐买入")
ADVICE = re.compile(r"(建议|应当)(买入|卖出|加仓|减仓)")

def redact(text: str) -> tuple[str, dict[str, int]]:
    counts = {}
    for name, pattern in PII.items():
        text, n = pattern.subn(f"[{name.upper()}]", text)
        if n: counts[name] = n
    return text, counts

def compliance_gate(text: str) -> dict:
    hits = [w for w in BANNED if w in text]
    if ADVICE.search(text): hits.append("direct_advice")
    return {"pass": not hits, "hits": hits}
```

| 风险级别 | 判定 | 审批要求 | 处理 |
| --- | --- | --- | --- |
| 低 | 个人速览，全公开数据 | 作者确认 | 可归档到个人空间 |
| 中 | 含观点、发部门群、含内部研报 | 组长审批 | 审校问题清零 |
| 高 | 研报初稿、对外材料、敏感标的 | 合规 + 组长双签 | 保留意见与版本 |

审计日志追加写、不可篡改，记录 run/用户/租户/工具/审批/发布物，保留期按公司制度（示例 ≥ 3 年）。

## 成本、容量与延迟

模型分级：意图/实体走规则 + 小模型；规划与执行用 `deepseek-chat`；复杂对比与审校按需用 `deepseek-reasoner`；嵌入/重排用本地 bge-m3 + reranker，保证数据不出域。

成本假设（示例，替换为真实合同价）：输入 ¥2/百万 token、输出 ¥8/百万 token，缓存命中 5 折，平均 5 次 LLM 调用。

| 调用 | 输入 token | 输出 token |
| --- | --- | --- |
| 规划 | 1,200 | 300 |
| 执行 3 轮 | 24,000 | 1,800 |
| 审校 | 10,000 | 600 |
| 终稿 | 6,000 | 1,500 |
| 合计 | 41,200 | 4,200 |

未计缓存约 `41.2k×2/1M + 4.2k×8/1M ≈ ¥0.116`；加嵌入/重排/工具约 ¥0.01-0.02，单任务 **¥0.11-0.14**。按 300 人 × 8 次/天 × 22 天 ≈ 5.28 万次/月，模型成本约 **¥6,000-7,500/月**（示例估算，不含基础设施与人力）。

容量（示例）：日任务约 2,400 次，峰值小时 360 次（0.1 次/秒），平均耗时 12s → 平均并发 1.2；按 5 倍突发设计 20 个执行槽，单 Pod 8 槽、3 副本；审批等待不占槽。

## 常见问题

**Q1：为什么不拆成多 Agent？**
四类场景大多围绕单只股票或单组对比，流程线性、共享同一份证据，单 Agent + 规划器足够。多 Agent 的收益在上下文隔离与角色分工，代价是 3-10 倍成本、跨 Agent 证据一致性难保证、审批链路更复杂。研报初稿后续可拆成「研究/写作/合规」，但必须共享证据库与引用 ID。

**Q2：多租户隔离为什么不能只靠 Prompt？**
Prompt 是建议不是边界。正确做法是四层硬隔离：token 解析租户 → 网关与编排校验归属 → 工具网关做 scope/ABAC → 存储与检索做服务端过滤。任何一层都不能省，并要有跨租户测试持续验证。

**Q3：人工审批会不会拖垮吞吐？**
会，如果审批占用执行线程。平台在 `interrupt` 时把 checkpoint 落 Postgres，执行槽立即释放；审批人几小时后处理，再用 `Command(resume=...)` 恢复。低风险个人速览作者自确认，中高风险进组长/合规队列；审批 SLA 与积压单独监控。

**Q4：怎么保证简报里的数字不幻觉？**
三道闸：工具返回结构化数值 + `as_of` 与来源；Prompt 明确「数字只能来自证据，估算必须用计算器」；审校用正则抽取草稿数字与证据白名单比对，不匹配就回炉或降级。计算器结果也作为证据入库。
