# agent-platform · 金融 Agent 平台实战

一个**企业内部多租户的垂直 Agent 平台**项目实战：平台方提供模型、工具、知识库与运行时，业务部门在其上自助注册 MCP、上架 Agent、调试并调用，全程可审计。

本主题按「项目需求 → 平台设计 → 技术架构 → 部署运维 → 上线验收」组织，共 5 章，配套一个可运行的平台 Demo（FastAPI + SQLite + Vue 3）。

## 章节

| 章节 | 内容 |
| --- | --- |
| 01 项目需求与业务场景 | 平台定位、角色与权限、场景清单、功能与非功能需求、验收指标 |
| 02 平台设计与领域模型 | 领域模型与 ER、租户隔离、RBAC/ABAC、Agent 与 MCP 生命周期、API 与表结构 |
| 03 技术架构与核心链路 | 分层架构、Agent 运行时、MCP 网关、模型网关、会话与异步、可观测与安全 |
| 04 部署与运维 | 部署拓扑、依赖组件、配置、K8s、监控告警、备份与升级回滚、容量估算 |
| 05 上线验收与 FAQ | 准入清单、压测与灰度、故障演练、常见问题与评审问答 |

## 启动演示

```bash
./start.sh              # 启动后端并打开 Vue 控制台
./start.sh --reset      # 清空演示数据后重建
./start.sh --port 9000  # 指定端口
./start.sh --no-browser # 只启动服务
```

首次运行需安装依赖：

```bash
python3 -m pip install -r demos/requirements.txt
```

控制台支持切换演示身份（两家租户、三种角色），可完整体验：

1. 注册 MCP 工具（开发者注册后待管理员启用；自定义端点会按 JSON-RPC 真实调用）
2. 创建 Agent（只能勾选当前角色有权限的工具）
3. 提交审核 → 管理员发布 / 驳回
4. 调试台运行（真实模型自主选择工具，查看 thought / action / observation 链路）
5. 用「研究员」身份调用含财报工具的 Agent，观察运行时权限拦截
6. 审计页查看跨租户与治理动作留痕

> 模型：默认调用 DeepSeek（读取 `DEEPSEEK_API_KEY`），未配置或调用失败时自动降级为离线模拟并在步骤中标注。
> 工具：行情 / 财报 / 研报 / 合规 / 计算器为内置真实执行逻辑（演示数据集）；自定义 MCP 通过 JSON-RPC 真实请求注册的 HTTP 端点。
> 生产替换点（PostgreSQL 行级安全、模型网关、MCP 网关、向量库）见第 03/04 章。

也可在仓库根目录：`python3 main.py agent-platform`。
