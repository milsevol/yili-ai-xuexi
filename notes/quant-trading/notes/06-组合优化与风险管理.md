# 06 组合优化与风险管理

## 一句话定位

组合优化把「一堆看好的标的」变成「一组可执行的权重」，风险管理则回答「这组权重最坏会亏多少、亏到什么程度必须收手」。

## 解决什么问题

信号层只告诉你「谁可能涨」，组合层要解决四个冲突：

1. **收益与分散**：全押最强信号收益最高，但一次看错就出局；
2. **暴露与约束**：因子选股天然带行业与风格暴露，不做中性化就会变成行业赌注；
3. **换手与成本**：优化器每次都会给出「理论最优权重」，但每次调仓都要付钱；
4. **杠杆与生存**：杠杆能放大收益，也能让一次极端行情直接清零。

组合优化的输出不是一个「最优点」，而是一组**在约束下可执行、可解释、可承受**的权重。

## 从信号到组合

一个完整的组合构建流程：

```
预期收益 μ  ─┐
风险矩阵 Σ  ─┼─▶ 优化器（目标 + 约束）─▶ 目标权重 ─▶ 交易清单
约束条件 C  ─┘                                    │
                                          ┌───────┘
                                          ▼
                                    风控校验（暴露/回撤/流动性）
```

| 环节 | 输入 | 常见做法 |
| --- | --- | --- |
| 预期收益估计 | 因子打分、信号强度、历史均值 | 打分映射、IC 加权、收缩到行业均值 |
| 风险估计 | 收益率序列、因子暴露 | 样本协方差 + 收缩、因子模型协方差 |
| 约束 | 合规、风控、容量 | 行业中性、单票上限、换手上限、禁投池 |
| 优化目标 | 效用函数 | 最大化 `μᵀw - λ/2·wᵀΣw`，或最小化风险 |

约束不是「优化器的附加项」，而是**策略定义的一部分**。把单票上限从 5% 改到 10%，得到的可能是完全不同的策略，风险收益特征也随之改变。

## Markowitz 均值方差

### 目标函数

```
max  wᵀμ - (λ/2)·wᵀΣw
s.t. Σw_i = 1        （权重之和为 1）
     w_i ≥ 0         （不许做空，A 股多数场景）
     |w_i| ≤ c       （单票上限）
```

λ 是风险厌恶系数：λ 越大越偏向低波动组合。给定不同的 λ，解出的 `(σ_p, μ_p)` 在图上构成有效前沿：

```
预期收益
 0.16 |                          ● 全仓资产 2
      |                     ●
      |                ●         ← 有效前沿（上半支）
      |           ●
      |      ●  ← 最小方差组合
      |   ●
 0.08 |● 全仓资产 1
      +-------------------------------- 波动率
       0.15                        0.28
```

下半支（同样波动但收益更低）是无效的，理性投资者只会在上半支选择，具体位置由风险偏好决定。

### 误差最大化器

均值方差优化对输入极其敏感。原因很直接：最优权重 `w* ∝ Σ⁻¹μ`，协方差矩阵的**逆**会把小特征值放大成巨大的方向性下注。两个后果：

- 预期收益估偏 1 个百分点，权重可能从 10% 跳到 60%，甚至顶到约束边界；
- 两只高度相关的股票，样本协方差几乎奇异，优化器会在两者之间给出极端的多空权重。

所以工业界几乎不用「裸的」均值方差：要么把 μ 换成因子打分并大幅收缩，要么加厚约束（行业中性、单票上限、换手上限），要么直接改用最小方差 / 风险平价这类不依赖 μ 的方法。

## 协方差估计

### 样本协方差的问题

设资产数 N、样本期 T。样本协方差 `S = (1/(T-1))·Σ(r_t - r̄)(r_t - r̄)ᵀ`：

- **维度灾难**：N = 500、T = 250 时，S 的秩最多 249，必然奇异，逆矩阵不存在或不稳定；
- **噪声主导**：即使 N < T，特征值最小的那些方向几乎全是噪声，而 `Σ⁻¹` 恰好放大这些方向；
- **时变**：用 3 年数据估的长期风险，在波动率突变时严重滞后。

### 收缩估计（Ledoit-Wolf）

```
Σ_shrunk = δ·F + (1 - δ)·S

S：样本协方差
F：结构化目标（如对角矩阵、常相关矩阵、单因子模型）
δ ∈ [0, 1]：由数据自动估计的收缩强度
```

直觉：N/T 越大、样本越噪，δ 越接近 1，权重越偏向结构化的先验。这一步几乎不损失信息，却能显著改善样本外表现，是组合优化里性价比最高的技巧之一。

### 因子模型协方差

```
Σ = B·Σ_f·Bᵀ + D

B：N×K 的因子暴露矩阵
Σ_f：K×K 的因子协方差（K 通常几十个，估计稳定）
D：对角矩阵，特质方差
```

它把 N×N 的估计问题降成 K×K + N 个方差，维度灾难自然消失，而且风险能直接归因到因子。

## 替代方案

| 方法 | 需要 μ | 核心思想 | 优点 | 缺点 |
| --- | --- | --- | --- | --- |
| 均值方差 | 需要 | 最大化风险调整后收益 | 理论最优 | 对输入极敏感 |
| 最小方差 | 不需要 | 只最小化 `wᵀΣw` | 稳健、无需预测收益 | 可能集中在低波行业，收益偏低 |
| 风险平价 / ERC | 不需要 | 每个资产的风险贡献相等 | 分散度好、无需 μ | 忽略收益差异，可能重仓低收益资产 |
| Black-Litterman | 需要观点 | 市场均衡收益 + 主观观点，贝叶斯融合 | 权重稳定、可解释 | 需要设定观点置信度 |
| HRP（分层风险平价） | 不需要 | 聚类后按树结构递归分配风险 | 无需求逆、样本外稳健 | 计算稍复杂，权重不够透明 |

**等风险贡献（ERC）** 的定义：设组合风险 `σ_p = sqrt(wᵀΣw)`，第 i 个资产的边际风险贡献 `MRC_i = (Σw)_i / σ_p`，风险贡献 `RC_i = w_i·MRC_i`。ERC 要求所有 `RC_i` 相等，即 `RC_i / σ_p = 1/N`。

两资产时有解析解：`w_1 = σ_2 / (σ_1 + σ_2)`（交叉项恰好抵消，与相关系数无关）。多资产需要迭代求解。

**Black-Litterman** 的核心是「不要直接预测收益，而是从市场均衡权重反推隐含收益，再用自己的观点做贝叶斯修正」。这一步把 μ 的估计从「拍脑袋」变成「市场先验 + 可控偏离」，权重稳定性提升明显。

## 多因子风险模型

Barra 类模型的结构：

```
r = X·f + u

r：N 只股票的收益向量
X：N×K 的因子暴露（行业因子 + 风格因子：市值、估值、动量、波动、流动性…）
f：K 维因子收益
u：特质收益，假设互不相关

组合风险：
σ_p² = wᵀ(X·Σ_f·Xᵀ + Δ)w
     = 因子风险 + 特质风险
```

三个用途：

- **风险归因**：组合波动里有多少来自行业、多少来自风格、多少来自个股；
- **约束优化**：把「行业暴露 = 0」「市值暴露 = 0」写成线性约束，避免策略偷偷加杠杆；
- **绩效归因**：把超额拆成因子收益（beta 暴露赚的）和特质收益（选股 alpha）。

## 风险度量

| 指标 | 定义 | 用途 | 局限 |
| --- | --- | --- | --- |
| 波动率 | `std(r) * sqrt(252)` | 最基础的尺度度量 | 不区分上下行 |
| Beta | `cov(r, r_m) / var(r_m)` | 相对市场的系统性风险 | 假设线性关系稳定 |
| VaR（95%） | 未来一天损失超过该值的概率为 5% | 监管与限额的通用语言 | 不看尾部有多深、不满足次可加性 |
| CVaR / ES | 超过 VaR 那部分的平均损失 | 刻画尾部厚度 | 依赖历史分布，极端样本少 |
| 最大回撤 | 峰值到谷底的最大跌幅 | 真实体验与赎回压力 | 强依赖样本区间 |
| 压力测试 | 情景假设下的损失 | 覆盖历史没发生过的情况 | 情景设计主观 |

### VaR 的三种算法

```
历史模拟法：取过去 N 天组合收益的 5% 分位数
          优点：不假设分布；缺点：完全依赖历史窗口

参数法（方差-协方差）：VaR = -(μ - z·σ)
          z(95%) = 1.645, z(99%) = 2.326
          优点：快；缺点：假设正态，低估尾部

蒙特卡洛：模拟成千上万条路径，取分位数
          优点：灵活（可加非线性、期权）；缺点：慢、依赖模型设定
```

VaR 的三个致命局限：

1. **尾部盲区**：95% VaR 对「最坏 5% 里到底亏 3% 还是 30%」一无所知，必须配合 CVaR；
2. **非正态**：收益率尖峰厚尾，参数法系统性低估极端损失；
3. **模型风险**：用平静期数据估的 VaR，在危机时会给出「风险很低」的错误信号。

## 仓位与杠杆管理

### 凯利公式

```
f* = (b·p - q) / b = p - q/b

b：赔率（赢了赚 b 倍本金）
p：胜率
q = 1 - p
```

凯利的性质：在已知真实 p、b 的前提下，`f*` 使长期对数增长最大化。问题在于 p 和 b 都是估计值，**估高了就是过度下注**，而过度下注的惩罚是不对称的：下注 2 倍凯利，长期增长率变成 0；下注超过某个临界值，期望增长率为负。

实务做法是**半凯利甚至四分之一的凯利**：牺牲约 25% 的增长速度，换取回撤减半和对参数误差的容忍度。

### 波动率目标

```
目标杠杆 = 目标年化波动 / 已实现年化波动（过去 20~60 日）

例：目标波动 10%，当前已实现波动 20% → 杠杆 0.5
    目标波动 10%，当前已实现波动 8%  → 杠杆 1.25（需设上限）
```

它的效果是「风险恒定」：波动高时自动减仓，波动低时加仓，组合的净值波动更平稳。代价是**在波动率跳升时会机械减仓**，可能卖在阶段低点，所以通常叠加杠杆上限和换手约束。

### 风险预算与回撤降杠杆

```
风险预算：给每个策略/因子分配波动贡献，而不是分配资金
          （资金 50/50 不等于风险 50/50）

回撤触发：
  组合回撤 > 5%  → 杠杆 ×0.8
  组合回撤 > 10% → 杠杆 ×0.5，暂停加仓
  组合回撤 > 15% → 人工复核，逐笔检查是否模型失效
```

回撤规则的价值在于**把「要不要减仓」这个情绪决策提前写成规则**。但规则本身要能区分「正常回撤」和「模型失效」：如果回撤伴随因子 IC 持续为负、成交显著恶化，那不该只是降杠杆，而应该停策略。

## 实践代码

四段：两资产有效前沿网格搜索、ERC 迭代求解、历史模拟法 VaR/CVaR、凯利仓位。

```python
import numpy as np
import pandas as pd

# ==================== 1. 两资产有效前沿（纯网格搜索） ====================
mu = np.array([0.08, 0.16])              # 年化预期收益
sig = np.array([0.15, 0.28])             # 年化波动
rho = 0.25
Sigma = np.array([[sig[0]**2, rho * sig[0] * sig[1]],
                  [rho * sig[0] * sig[1], sig[1]**2]])
rf = 0.02

ws = np.linspace(0.0, 1.0, 1001)
ret_g = ws * mu[0] + (1 - ws) * mu[1]
var_g = (ws**2 * Sigma[0, 0]
         + (1 - ws)**2 * Sigma[1, 1]
         + 2 * ws * (1 - ws) * Sigma[0, 1])
vol_g = np.sqrt(var_g)
sharpe_g = (ret_g - rf) / vol_g

front = pd.DataFrame({"w1": ws, "ret": ret_g, "vol": vol_g, "sharpe": sharpe_g})
i_mv, i_ms = int(np.argmin(vol_g)), int(np.argmax(sharpe_g))
print("最小方差组合:", front.iloc[i_mv].round(4).to_dict())
print("最大夏普组合:", front.iloc[i_ms].round(4).to_dict())

# 解析解校验：两资产最小方差权重
w_mv = (Sigma[1, 1] - Sigma[0, 1]) / (Sigma[0, 0] + Sigma[1, 1] - 2 * Sigma[0, 1])
print(f"最小方差权重解析解 w1 = {w_mv:.4f}")

# 敏感性：预期收益上调 3 个百分点，最优权重跳多远
mu2 = mu + np.array([0.03, 0.0])
sharpe2 = ((ws * mu2[0] + (1 - ws) * mu2[1]) - rf) / vol_g
print(f"μ1 上调 3pp 后最大夏普的 w1 = {ws[int(np.argmax(sharpe2))]:.3f}"
      f"（原为 {ws[i_ms]:.3f}）")

# ==================== 2. 等风险贡献 ERC（阻尼乘性迭代） ====================
def erc_weights(Sigma, iters=20000, tol=1e-11):
    n = Sigma.shape[0]
    w = np.ones(n) / n
    for _ in range(iters):
        rc = w * (Sigma @ w)                     # 各资产风险贡献
        w_new = w * (rc.mean() / rc) ** 0.5      # 幂次阻尼，避免震荡
        w_new = w_new / w_new.sum()
        if np.max(np.abs(w_new - w)) < tol:
            return w_new
        w = w_new
    return w

# 两资产：与解析解对比（ERC 权重与相关系数无关）
w_erc2 = erc_weights(Sigma)
print(f"\nERC 两资产权重 = {w_erc2.round(4)}，"
      f"解析解 = {(np.array([sig[1], sig[0]]) / sig.sum()).round(4)}")

# 四资产：单因子结构 + 特质风险
rng = np.random.default_rng(0)
B = rng.normal(0.9, 0.25, (4, 1))                    # 市场因子暴露
D = np.diag(rng.uniform(0.02, 0.06, 4) ** 2)         # 特质方差
Sigma4 = B @ B.T * 0.0016 + D                        # 因子方差取 0.04^2

w_erc = erc_weights(Sigma4)
rc = w_erc * (Sigma4 @ w_erc)
print(f"\n四资产 ERC 权重 = {w_erc.round(4)}")
print(f"风险贡献占比   = {(rc / rc.sum()).round(4)}   # 应全部接近 0.25")

# ==================== 3. 历史模拟法 VaR / CVaR ====================
rng = np.random.default_rng(7)
n = 1000
df_t = 4
scale = 1 / np.sqrt(df_t / (df_t - 2))                # 把 t 分布标准化到单位方差
common = rng.standard_t(df_t, n) * scale              # 厚尾的共同市场冲击
R = np.column_stack([
    0.0004 + 0.012 * common + 0.008 * rng.normal(0, 1, n),
    0.0003 + 0.008 * common + 0.010 * rng.normal(0, 1, n),
    0.0005 + 0.004 * common + 0.014 * rng.normal(0, 1, n),
])
w_pf = np.array([0.5, 0.3, 0.2])
port_ret = R @ w_pf

def var_cvar(x, alpha=0.95):
    q = np.quantile(x, 1 - alpha)                     # 左尾分位点（负数）
    tail = x[x <= q]
    return -q, -tail.mean()                           # 转成「正数表示损失」

print("\n历史模拟法（1000 天，组合权重 50/30/20）")
for a in (0.95, 0.99):
    v, c = var_cvar(port_ret, a)
    print(f"  {a:.0%} 一日 VaR = {v:.2%}，CVaR = {c:.2%}")

# 参数法对照：正态假设会低估尾部
mu_d, sd_d = port_ret.mean(), port_ret.std(ddof=1)
for a, z in ((0.95, 1.645), (0.99, 2.326)):
    print(f"  参数法 {a:.0%} VaR = {-(mu_d - z * sd_d):.2%}")
print(f"  样本超额峰度 = {((port_ret - mu_d) ** 4).mean() / port_ret.var() ** 2:.2f}"
      f"（正态为 3，越大尾巴越厚）")

# ==================== 4. 凯利仓位 ====================
def kelly(p, b):
    return (b * p - (1 - p)) / b

def exp_log_growth(f, p, b):
    return p * np.log(1 + b * f) + (1 - p) * np.log(1 - f)

print("\n凯利仓位与过度下注的代价")
for p, b in [(0.55, 1.5), (0.45, 2.5), (0.60, 1.0)]:
    f_star = kelly(p, b)
    print(f"  p={p:.2f}, b={b:.1f} -> 全凯利 {f_star:.3f}，"
          f"半凯利 {f_star/2:.3f}，"
          f"增长: 全凯利 {exp_log_growth(f_star, p, b):.5f} / "
          f"半凯利 {exp_log_growth(f_star/2, p, b):.5f} / "
          f"1.5 倍 {exp_log_growth(1.5*f_star, p, b):.5f}")

# 波动率目标示例
target_vol, realized_vol, max_lev = 0.10, 0.22, 1.5
print(f"\n波动率目标: 目标 {target_vol:.0%} / 已实现 {realized_vol:.0%}"
      f" -> 杠杆 {min(target_vol / realized_vol, max_lev):.2f}")
```

输出解读：

- 最小方差组合与解析解一致，说明网格搜索的正确性；最大夏普组合通常落在两资产之间（分散化的收益）。
- μ 上调 3 个百分点后最优权重明显移动，这就是「误差最大化器」的直观证据：预测误差被 `Σ⁻¹` 放大成权重误差。
- 四资产 ERC 的风险贡献占比全部接近 0.25，这是收敛正确的标志；若不收敛，占比会明显分化。
- 历史模拟法 VaR 大于参数法 VaR，差额就是「厚尾」的代价；请注意这个差别在 99% 分位上比 95% 分位更明显。
- 凯利的增长列显示：1.5 倍凯利的对数增长明显低于全凯利，过度下注的损失是非线性的。

## 常见误区与坑

1. **把优化器输出当真理**。优化器只会解你写的数学题，题目（μ、Σ、约束）错了，答案一定错。先检查输入，再看权重。
2. **忽略约束导致不可交易**。解出来的权重全是 0.3% 的碎股、或集中在停牌股上，实盘根本执行不了。约束里必须包含最小权重、流动性、禁投池。
3. **用短期协方差估长期风险**。20 日窗口在平静期给出极低波动，诱导加杠杆；建议用 60~250 日 + 收缩估计，并做波动率情景压力测试。
4. **只算 VaR 不管尾部相关性**。危机时相关性趋近 1，平时分散的组合会瞬间变成单一风险。要用压力情景（如全市场 -8%）而不是协方差矩阵。
5. **杠杆放大尾部风险**。2 倍杠杆下，-25% 的组合回撤就是 -50% 的账户回撤，可能触发清盘线。杠杆要先算「多大回撤会出局」，再倒推可用倍数。
6. **风险平价等于分散**。风险平价只保证风险贡献相等，不保证因子分散；如果所有资产都押同一个因子，ERC 组合依然是单因子赌注。

## 常见问题 Q&A

**Q：为什么不直接全仓夏普最高的资产？**
A：单资产夏普高不代表组合夏普高。相关性低于 1 时，加入一个夏普稍低但与现有资产低相关的标的，组合夏普可能更高。优化的本质是利用相关性，而不是挑单点最优。

**Q：ERC 和风险平价的区别？**
A：广义上风险平价指「按风险预算分配」，ERC 是风险预算全部相等的特例。行业里两个词常混用，看到时确认对方说的是「等风险贡献」还是「含杠杆的桥水式全天候」。

**Q：Black-Litterman 的观点怎么给？**
A：两类来源：量化信号（把因子打分转成预期收益，置信度用 IC 的稳定性衡量）和主观判断（研究员给出区间与置信度）。关键是**置信度必须显式建模**，否则 BL 退化成普通均值方差。

**Q：VaR 用 95% 还是 99%？**
A：95% 适合日常监控（样本多、估计稳），99% 适合资本充足与限额（但尾部样本少、估计噪声大）。实务上两个都报，并以 CVaR 为主做尾部管理。

**Q：凯利公式能直接用于股票组合吗？**
A：不能直接用。凯利要求二元结果和已知的 p、b；股票收益是连续分布，参数估计误差大。实务做法是用凯利估计「大致量级」，再打 1/4~1/2 折扣，并叠加波动率目标和回撤规则。

**Q：组合优化该多久跑一次？**
A：看信号衰减速度。日频多因子通常周度或双周度调仓，中间用阈值触发（偏离目标权重超过一定幅度才交易）。每天重优化会产生大量无意义的换手。
