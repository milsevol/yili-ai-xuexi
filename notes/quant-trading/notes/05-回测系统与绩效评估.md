# 05 回测系统与绩效评估

## 一句话定位

回测就是用历史数据回答「如果当时严格按这套规则交易，账户会发生什么」；它的职责是**排除明显不行的策略**，而不是证明某个策略一定行。

## 解决什么问题

策略写完不能直接上钱。回测系统要解决三件事：

1. **可复现**：同一份数据、同一套参数、同一个成本假设，任何人跑出来结果一致；
2. **可信**：没有前视、没有幸存者偏差、成本与成交假设接近真实；
3. **可比较**：不同策略、不同参数、不同样本区间能用同一套指标横向对比。

一句话：回测是**筛选器 + 诊断仪**。它筛掉 90% 的想法，并告诉你剩下 10% 是怎么赚的、在什么情况下会亏。

## 回测的本质与边界

```
真实交易：  t 时刻的信息 → 决策 → t+1 时刻按当时盘口成交 → 成本 → 持仓
回测：      t 时刻的信息 → 决策 → t+1 时刻按假设价格成交   → 成本假设 → 持仓
```

两者的差距全在「假设」二字。回测结果和实盘的差距通常来自三块：成交假设过于乐观（用收盘价成交、忽略涨跌停）、成本估计过低（只算佣金不算冲击）、以及过拟合（参数是看着这段历史调出来的）。

一个健康的预期是：**回测夏普 1.5 的策略，实盘能做到 0.8~1.0 就算成功**。任何宣称「回测和实盘几乎一样」的说法，要么是策略容量极小，要么是回测写错了。

## 七大偏差

| 偏差 | 具体反例 | 修正方法 |
| --- | --- | --- |
| 前视偏差（look-ahead） | 用当日收盘价计算均线，又用当日收盘价成交；用年报数据在 12 月 31 日就选股 | 信号 `shift(1)`；财务数据用**公告日**而非报告期；严格区分 `decision_time` 与 `execution_time` |
| 幸存者偏差 | 只用「今天还活着」的股票池回测十年前，退市股全部消失 | 使用含退市标的的历史成分股名单（point-in-time universe） |
| 数据窥探 / 多重检验 | 试了 200 组参数，报告最好的那组夏普 2.3 | 记录试验总数，做 deflated Sharpe 或随机化检验 |
| 过度拟合 | 参数多到能拟合每段噪声，样本内完美样本外崩溃 | 限制参数个数、要求参数平原、滚动前推验证 |
| 忽略交易成本 | 日频全仓换手，回测不扣任何费用 | 佣金 + 印花税 + 过户费 + 滑点 + 冲击成本，按换手逐笔扣 |
| 无法成交假设 | 涨停板照样买入、停牌股照样调仓、小盘股按收盘价满仓进出 | 涨跌停过滤、停牌冻结、成交量参与率上限（如 ≤ 当日成交量的 10%） |
| 时间对齐错误 | 日线信号与分钟数据混用；跨时区品种用同一根 bar；复权价与原始价混算 | 统一时间戳与频率、明确 bar 的 `open/close` 定义、复权口径全链路一致 |

**最容易犯的是前视偏差**，因为它不报错、不回撤异常、只是让结果变好看。一个实用的自检方法：把所有数据源整体延后一天重跑，如果绩效大幅下降，说明你在偷看未来。

## 向量化回测 vs 事件驱动回测

| 维度 | 向量化 | 事件驱动 |
| --- | --- | --- |
| 实现方式 | pandas/numpy 对整个序列做运算 | 逐 bar/逐 tick 循环，撮合引擎处理订单 |
| 速度 | 快（毫秒级） | 慢（分钟到小时，取决于标的数与频率） |
| 真实性 | 弱：难以表达「部分成交、订单被拒、资金不足」 | 强：可模拟订单生命周期、保证金、撮合优先级 |
| 成本建模 | 近似（按仓位变化乘费率） | 精确（逐笔成交、冲击模型） |
| 适用 | 日频、单资产、参数扫描、快速原型 | 多资产组合、日内、期货保证金、实盘对接 |

实践路径通常是：**向量化做研究（跑几千组参数），事件驱动做验收（跑最终候选策略）**。两者结果应当接近；差异过大说明成本或成交假设不一致。

### 撮合假设

```
保守程度递增：
1. 当日收盘价成交                 ← 最乐观，几乎必然高估
2. 次日开盘价成交                 ← 日频策略的默认选择
3. 次日 VWAP / TWAP 成交          ← 更接近大资金实际
4. 次日开盘 + 滑点 + 参与率约束    ← 可用于验收
```

bar 内成交顺序尤其影响止损类策略：如果一根 K 线同时触发止盈和止损，回测按哪个先算，结果会差很多。保守做法是**按不利方向优先**（先算止损）。

## 回测系统的组成

```
┌──────────┐   ┌──────────┐   ┌──────────┐
│  数据层   │──▶│  策略层   │──▶│  组合层   │
│ 行情/财务 │   │ 信号生成  │   │ 仓位/约束 │
└──────────┘   └──────────┘   └────┬─────┘
                                    ▼
┌──────────┐   ┌──────────┐   ┌──────────┐
│  绩效层   │◀──│  成本层   │◀──│  撮合层   │
│ 指标/归因 │   │ 佣金/滑点 │   │ 成交/拒单 │
└──────────┘   └──────────┘   └──────────┘
```

关键接口设计（事件驱动的典型形态）：

```
class Strategy:
    def on_bar(self, bar):          # 每根 bar 到达时调用，只能看到当前及历史数据
        ...
    def generate_signals(self, df)  # 向量化形态：一次性输出目标仓位序列
        ...
```

两条铁律：

- **策略层只能读取 `t` 及之前的数据**，撮合层只能在 `t+1` 及之后成交；
- **组合层负责约束**（单票上限、行业中性、资金不足），策略层不应该知道账户有多少钱。

## 绩效指标体系

设日收益序列为 `r_t`，净值 `NAV_t = Π(1+r_i)`，年化周期数 `A = 252`。

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| 累计收益 | `NAV_n - 1` | 全区间总收益 |
| 年化收益 | `(1 + 累计收益)^(A/n) - 1` | 几何年化，n 为交易日数 |
| 年化波动 | `std(r) * sqrt(A)` | 用样本标准差，日频年化 |
| 夏普比率 | `(mean(r) - rf/A) / std(r) * sqrt(A)` | 每单位总风险的超额收益 |
| Sortino | `(mean(r)*A - rf) / (std(r<0)*sqrt(A))` | 只惩罚下行波动 |
| 最大回撤 MDD | `min(NAV / cummax(NAV) - 1)` | 峰值到谷底的最大跌幅 |
| Calmar | `年化收益 / |MDD|` | 收益与回撤的性价比 |
| 胜率 | 盈利期数 / 有持仓期数 | 单独看没有意义，要和盈亏比一起看 |
| 盈亏比 | 平均盈利 / 平均亏损 | 与胜率共同决定期望 |
| 换手率 | `Σ|Δpos| / n * A` | 双边年化换手，成本的直接驱动 |
| 跟踪误差 | `std(r - r_bench) * sqrt(A)` | 相对基准的偏离 |
| 信息比率 IR | `mean(r - r_bench) / std(r - r_bench) * sqrt(A)` | 每单位主动风险的超额 |
| 容量 | `min(ADV) * 参与率 / 目标仓位` | 策略能承载的资金规模 |

几个容易误用的点：

- **夏普的分母是总波动**，一个靠「偶尔暴涨、平时不动」的策略夏普可能不错，但 Sortino 和 MDD 会暴露真实体验；
- **MDD 依赖样本区间**，换个起点数字就变，报告时必须写清区间；
- **胜率 × 盈亏比 ≈ 期望**：胜率 80% 盈亏比 0.2 的策略，期望可能不如胜率 40% 盈亏比 2.5 的策略；
- **换手率是成本的先行指标**：双边年化换手 2000% × 单边 15bp = 年化 60bp 的纯成本，还不含冲击。

## 基准与归因

超额收益 = 策略收益 - 基准收益。基准选错，超额毫无意义：股票多头策略对沪深 300，中性策略对无风险利率，CTA 对商品指数。

**Brinson 归因**把主动收益拆成三块：

```
总超额 = 配置效应 + 选股效应 + 交互效应

配置效应 = Σ_i (w_p,i - w_b,i) * r_b,i
选股效应 = Σ_i w_b,i * (r_p,i - r_b,i)
交互效应 = Σ_i (w_p,i - w_b,i) * (r_p,i - r_b,i)
```

其中 `w_p / w_b` 是组合/基准在行业 i 的权重，`r_p / r_b` 是对应行业收益。它能回答一个关键问题：**你的超额是选对了行业，还是选对了股票？** 如果超额几乎全部来自配置效应，那这个策略本质上是行业轮动，风险约束和容量评估都要按行业轮动的标准来。

## 实践代码

生成 500 天行情，跑双均线，做含成本与零成本两版回测，输出完整指标表。

```python
import numpy as np
import pandas as pd

# ==================== 1. 生成 500 天模拟行情 ====================
rng = np.random.default_rng(5)
n_days = 500
ret_sim = rng.normal(0.0005, 0.014, n_days)
ret_sim[220:280] -= 0.005                       # 人为插入一段系统性下跌
price = pd.Series(100 * np.exp(np.cumsum(ret_sim)), name="close")

# ==================== 2. 双均线策略 + 向量化回测 ====================
def backtest(price, fast=5, slow=20, fee=0.0005, slippage=0.0010):
    """fee: 佣金+印花税等显性费用；slippage: 滑点与冲击的简化估计"""
    df = pd.DataFrame({"close": price})
    df["ma_fast"] = df["close"].rolling(fast).mean()
    df["ma_slow"] = df["close"].rolling(slow).mean()
    df["signal"] = (df["ma_fast"] > df["ma_slow"]).astype(float)
    df.loc[df["ma_slow"].isna(), "signal"] = 0.0

    # 前视偏差防线：T 日收盘产生的信号，T+1 才进入持仓
    df["pos"] = df["signal"].shift(1).fillna(0.0)
    df["ret"] = df["close"].pct_change().fillna(0.0)
    df["turnover"] = df["pos"].diff().abs().fillna(0.0)

    df["gross"] = df["pos"] * df["ret"]
    df["cost"] = df["turnover"] * (fee + slippage)
    df["net"] = df["gross"] - df["cost"]
    df["nav"] = (1 + df["net"]).cumprod()
    df["bench_nav"] = (1 + df["ret"]).cumprod()   # 基准：买入持有
    return df

# ==================== 3. 绩效指标 ====================
def metrics(df, rf=0.02, periods=252):
    r, nav, n = df["net"], df["nav"], len(df)
    total = nav.iloc[-1] - 1.0
    ann_ret = (1 + total) ** (periods / n) - 1
    ann_vol = r.std(ddof=1) * np.sqrt(periods)
    sharpe = (r.mean() - rf / periods) / r.std(ddof=1) * np.sqrt(periods)
    downside = r[r < 0].std(ddof=1) * np.sqrt(periods)
    sortino = (r.mean() * periods - rf) / downside
    mdd = (nav / nav.cummax() - 1).min()
    calmar = ann_ret / abs(mdd)

    active = df["pos"] > 0
    win_rate = (r[active] > 0).mean()
    avg_win = r[active & (r > 0)].mean()
    avg_loss = abs(r[active & (r < 0)].mean())
    pl_ratio = avg_win / avg_loss

    ex = r - df["ret"]
    te = ex.std(ddof=1) * np.sqrt(periods)
    ir = ex.mean() / ex.std(ddof=1) * np.sqrt(periods)

    return {
        "累计收益": total,
        "年化收益": ann_ret,
        "年化波动": ann_vol,
        "夏普": sharpe,
        "Sortino": sortino,
        "最大回撤": mdd,
        "Calmar": calmar,
        "胜率": win_rate,
        "盈亏比": pl_ratio,
        "年化换手": df["turnover"].sum() / n * periods,
        "跟踪误差": te,
        "信息比率": ir,
    }

# ==================== 4. 含成本 vs 零成本 ====================
df_cost = backtest(price)
df_free = backtest(price, fee=0.0, slippage=0.0)

table = pd.DataFrame({
    "含成本": metrics(df_cost),
    "零成本": metrics(df_free),
})
table["差异"] = table["含成本"] - table["零成本"]

print("指标对比（500 天，双均线 5/20，基准费率 5bp 佣金 + 10bp 滑点）")
print(table.round(4).to_string())
print(f"\n累计交易成本占初始净值: {df_cost['cost'].sum():.2%}")
print(f"期末净值: 含成本 {df_cost['nav'].iloc[-1]:.4f} / "
      f"零成本 {df_free['nav'].iloc[-1]:.4f} / "
      f"基准 {df_cost['bench_nav'].iloc[-1]:.4f}")

# ==================== 5. 换手对成本的敏感度 ====================
print("\n换手假设对净值的影响（费率按单边计）")
for fee, slip in [(0.0, 0.0), (0.0001, 0.0002), (0.0003, 0.0005), (0.0005, 0.0010)]:
    net = backtest(price, fee=fee, slippage=slip)["nav"].iloc[-1]
    print(f"  fee={fee:.4f}, slippage={slip:.4f} -> 期末净值 {net:.4f}")
```

输出解读：

- 「差异」列直接量化了成本拖累。本例中成本吃掉了约 3.6 个百分点的累计收益（毛收益约 17.5%，净收益约 13.9%），相当于毛收益的两成。换手更高的策略里，年化被成本吃掉 3~8 个百分点并不罕见；如果成本拖累超过毛收益的一半，说明换手太高、信号太碎。
- 零成本版本的意义是**上界**：如果连零成本都不赚钱，问题在信号本身；如果零成本很好而含成本很差，问题在频率与容量。
- 最后一组表展示「成本假设敏感性」：真实成本落在哪一档，决定了策略能不能上线。用最保守那档仍然成立，才值得继续。

## 回测结果可信度检查清单

1. **样本外**：留出至少 30% 的时间完全不参与任何决策（包括参数选择）。
2. **滚动前推**：walk-forward 各段的样本外绩效是否稳定，参数是否频繁跳变。
3. **参数稳定性**：最优参数 ±30% 邻域内绩效不坍塌。
4. **成本敏感**：把成本翻倍后是否仍然为正。
5. **容量测算**：按 10% 参与率估算的最大资金量，是否满足你的目标规模。
6. **极端行情**：单独看 2015 股灾、2020 年 3 月、2022 年 4 月这类区间的表现。
7. **随机化检验**：打乱收益率顺序或 block bootstrap 1000 次，真实绩效应显著优于随机分布。
8. **执行假设复核**：随机抽 20 笔交易，逐笔人工核对信号时间、成交价、成本是否正确。
9. **基准合理性**：超额是否只是承担了更多 beta 或小市值暴露。
10. **归因可解释**：超额来自哪里，能否用一句话说清；说不清的超额通常是数据问题。

## 常见误区与坑

1. **只看年化不看回撤**。年化 30% 但 MDD 60% 的策略，多数人拿不住；先看回撤能否承受，再看收益。
2. **用全样本调参再报告全样本绩效**。这是最常见的自欺。定参和评估必须用不同时间段。
3. **把日内收益当成日收益**。用当天开盘买入、当天收盘卖出的收益，当成 T 日信号可以拿到的收益，是典型的前视。
4. **忽略复权**。用未复权价格算均线，除权日会出现假跌破；用后复权价格算「每股价格」又会失真。统一用后复权价算信号，用真实价格算资金。
5. **成本只算佣金**。印花税、过户费、融券费、冲击成本往往比佣金大一个量级。
6. **把回测当证明**。回测通过只意味着「没被证伪」，不意味着「未来会赚」。

## 常见问题 Q&A

**Q：向量化回测够用吗，一定要写事件驱动吗？**
A：日频、股票多头、单资产或少量资产，向量化足够，而且能快速扫参数。涉及期货保证金、日内撮合、部分成交、多资产资金共享时，必须上事件驱动。折中方案是向量化出信号 + 事件驱动做最终验收。

**Q：夏普多少才算好？**
A：看频率与市场。日频股票多头的实盘夏普 0.5~1.0 已属不错，高频做市可以到 5 以上但容量极小。比较时要在同一频率、同一杠杆、同一区间下比，跨频率比夏普没有意义。

**Q：最大回撤怎么报告才诚实？**
A：写清三件事：样本区间、是否含成本、是策略层还是产品层（加了杠杆和资金分配后通常更大）。同时给出回撤持续天数，30% 回撤持续 3 个月和持续 3 年是完全不同的体验。

**Q：为什么零成本回测和含成本差那么多？**
A：换手高。先算 `盈亏平衡成本 = 年化超额收益 / 年化换手`，如果这个数字低于 5bp，说明策略对成本极度敏感，必须降低频率或提高单笔预期收益。

**Q：样本外表现比样本内好，是好事吗？**
A：通常是运气，不要因此加仓。更可能的原因是样本外刚好赶上了有利行情，检验方法是多段滚动样本外，看分布而不是看单次。
