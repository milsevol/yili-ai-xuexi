# 09 AI 与量化投研

## 一句话定位

机器学习在量化里的正确定位是**非线性因子合成器与预测器**，不是「替代研究」的魔法。它把几十个弱因子映射成对未来收益的条件期望，价值来自非线性与交互项；但数据量、信噪比、非平稳这三大约束决定了它很容易过拟合，工程纪律比模型复杂度重要得多。

## 解决什么问题

- 手工给因子加权（等权、IC 加权）无法捕捉因子之间的交互和尾部非线性。
- 标签定义随意（未来 1 日收益 > 0），导致模型学到的只是市场 beta 或噪声。
- 用随机 K-Fold 交叉验证，训练集和测试集共享未来信息，回测虚高。
- 试了 200 个模型，挑回测最好的那个，实盘迅速失效。
- 把 LLM 当成「预测涨跌」的模型，而不是信息处理工具。

## 三大约束

| 约束 | 含义 | 后果 | 应对 |
| --- | --- | --- | --- |
| 数据量 | 日频 A 股 20 年约 5000 个交易日，截面虽有几千只票，但有效样本远少于图像/文本 | 深度模型容易记住噪声 | 从线性/树模型起步，强正则，简化模型 |
| 信噪比 | 日频收益的可解释部分通常只有几个百分点 | 准确率 52% 可能已经不错 | 看 IC、收益、换手，而不是准确率 |
| 非平稳 | 因子有效性、波动率、交易规则都在变 | 训练集的最优参数在测试集失效 | 时序验证、滚动重训、漂移监控 |

## 监督学习流程

```text
行情/财务/另类数据
      │
      ▼
特征（因子矩阵）──> 截面标准化 / 缺失处理 / 去极值
      │
      ▼
标签（未来收益 / 涨跌分类 / 三重障碍）
      │
      ▼
时序切分（Purged K-Fold / Walk-Forward）
      │
      ▼
模型（线性 / 树 / 时序 / 强化学习）
      │
      ▼
预测（收益、概率、排序分数）
      │
      ▼
组合构建（排序、加权、约束、成本）
      │
      ▼
回测与实盘
```

**标签设计决定模型上限。** 同样的特征，用「未来 1 日收益」回归和用「未来 10 日、带波动率缩放、扣除成本后的三重障碍标签」分类，学到的完全是两类东西。前者噪声极大，后者更接近真实交易决策。

### 三重障碍法（Triple Barrier）

对每个样本 `t`，从 `P_t` 出发设三道障碍：

```text
上障碍 = P_t * (1 + k_up   * σ_t)
下障碍 = P_t * (1 - k_down * σ_t)
时间障碍 = t + H

先触及上障碍 → 标签 +1（止盈/做多成功）
先触及下障碍 → 标签 -1（止损/做空成功）
先到时间障碍 → 标签  0（中性/超时平仓）
```

`σ_t` 用滚动波动率估计，`k_up/k_down` 要覆盖交易成本与目标盈亏比。优点是标签自带「持有期 + 止损止盈」的交易语义；坑是样本重叠（相邻 `t` 的持有期交叉）会造成信息泄漏，必须配合 Purged CV。

## 模型谱系

| 模型 | 适合 | 优点 | 坑 |
| --- | --- | --- | --- |
| 线性回归 / Ridge / Lasso | 因子少、样本少、需要解释 | 稳定、可解释、训练快 | 抓不到非线性；Lasso 在强相关因子里随机选一个 |
| 随机森林 | 中小规模表格数据 | 非线性、抗噪、无需太多调参 | 外推能力差；对时序漂移敏感 |
| LightGBM / XGBoost | 表格因子合成的主力 | 精度高、训练快、支持缺失 | 容易过拟合；必须做时序 CV 和早停 |
| LSTM / Transformer | 序列模式、分钟级 | 能建模时序依赖 | 数据需求大、训练不稳定、解释性差 |
| 强化学习 | 仓位控制、执行优化 | 直接优化长期目标 | 奖励设计难、样本效率低、极难稳定 |

实践顺序：**Ridge 做 baseline → LightGBM 做主模型 → 深度模型只在数据量和算力都充足时尝试**。如果 LightGBM 相对 Ridge 没有稳定提升，问题通常在特征或标签，不在模型。

## 时序交叉验证

普通 K-Fold 会把未来数据混进训练集：测试集是 2023 年，训练集却包含 2024 年，模型「见过未来」。金融数据还有第二层泄漏：标签有持有期，`t` 的标签用到了 `t+10` 的价格，如果训练集末尾与测试集开头只隔一天，仍然重叠。

**Purged K-Fold + Embargo**：

```text
时间轴 ──────────────────────────────────────────────>

训练折 1 │ 训练折 2 │ embargo │ 测试折 │ embargo │ 训练折 3
                         ↑                    ↑
                  删除与测试标签重叠的样本   测试后再空一段，防止特征窗口泄漏
```

- **Purge**：删除训练集中标签区间与测试集标签区间重叠的样本。
- **Embargo**：在测试集前后再留一段空白（如持有期长度），防止特征计算窗口跨过边界。
- **Walk-Forward**：更严格的时间序列验证，训练窗口滚动向前，每次只用过去预测未来。它更接近实盘，但测试段少、评估方差大。

结论：**任何随机打乱的 K-Fold 在金融时序上都是错的**，不管模型多简单。

## 过拟合与多重检验

假设你试了 `N` 个策略，每个策略真实夏普为 0。取最大值，期望大约是：

```text
E[max SR] ≈ sqrt(2 * ln N)
```

`N=100` 时约 3.0，`N=1000` 时约 3.7。也就是说，**即使所有策略都是纯噪声，试 100 个也能挑出一个夏普 2~3 的「冠军」**。这就是回测虚高的统计根源。

Deflated Sharpe Ratio（Bailey & Lopez de Prado）做的事，就是把「试验次数、试验间相关性、样本长度、收益偏度/峰度」折算进显著性检验：

```text
DSR = Φ( (SR - SR0) * sqrt(T - 1)
         / sqrt(1 - γ3*SR + (γ4 - 1)/4 * SR^2) )
```

`SR0` 不是 0，而是「N 次独立试验下预期最大夏普」，`Φ` 是标准正态分布函数。DSR 越低，说明你的夏普越可能只是选择偏差。

工程对策：**策略试验登记表**。

| 字段 | 示例 |
| --- | --- |
| trial_id | 2024-06-01-mom-v3 |
| 假设 | 20 日动量在中小盘有效 |
| 股票池 / 区间 | 中证 500，2018–2024 |
| 特征与参数 | mom20、行业中性、Top 20% |
| 验证方式 | Walk-Forward，训练 3 年，测试 6 个月 |
| 样本外夏普 / IC | 0.8 / 0.035 |
| 成本假设 | 单边 15 bp + 冲击 |
| 结论 | 保留 / 淘汰 / 待观察 |

登记的意义不是形式主义，而是让「我试过多少次」变成可审计的事实。没有登记，DSR 无法计算，过拟合无法被约束。

## 特征工程与可解释性

- **截面 vs 时序**：截面因子（估值、动量排名）做截面标准化；时序因子（波动率、换手率变化）做时序标准化。混用会把市场整体状态误当成个股差异。
- **缺失与极值**：先做行业/市值中性化，再缩尾（如 1%/99% 分位），缺失值单独标记，不要无脑填 0。
- **特征稳定性**：滚动计算因子的 RankIC 与 IC 衰减。一个因子在训练期 IC 0.08、近一年 0.01，模型再复杂也救不回来。
- **可解释性**：树模型看 gain/cover 重要性，配合 SHAP 看单样本归因；线性模型看系数稳定性。重要的是「模型是否依赖了不该依赖的特征」（如未来才公布的数据、停牌标记）。
- **特征版本**：每个特征记录计算逻辑、数据快照、更新时间。因子定义改一个字，历史值就会变，必须可追溯。

## LLM 在投研中的应用

LLM 的正确角色是**信息处理加速器**，不是价格预测器。

| 场景 | 做法 | 价值 | 风险 |
| --- | --- | --- | --- |
| 财报/公告抽取 | 结构化营收、利润、指引、风险提示 | 把非结构化文本变成因子 | 数字幻觉、口径错误 |
| 研报/新闻摘要 | 每日批量摘要、主题归类 | 节省研究员时间 | 时效、版权、重复内容 |
| 事件结构化 | 并购、减持、诉讼、政策映射到行业 | 事件驱动信号 | 事件定义模糊、漏报 |
| 舆情情绪 | 情感分类、讨论热度 | 另类因子 | 水军、幸存者偏差、合规 |
| 投研问答/代码助手 | 查文档、写 SQL、生成回测代码 | 提升效率 | 代码正确性需人工验证 |

局限很明确：

- **幻觉**：会编造数字和引用，关键字段必须回原文核对。
- **时效**：模型知识截止，实时事件要靠检索增强。
- **合规**：把未公开信息、付费研报喂给第三方 API 可能违规。
- **可复现**：同一 prompt 不同时间输出不同，难以做严格回测。正确做法是把 LLM 输出**固化成结构化字段**，落库、打时间戳，再当作普通因子使用。

一句话：**LLM 负责「读得多、读得快」，不负责「猜得准」。**

## 工程化

- **特征库**：离线批量计算 + 在线点查同一套逻辑；特征定义、单位、更新频率、缺失规则写进元数据。
- **模型版本**：模型文件、训练数据快照、超参数、代码 commit 绑定成一个版本号；线上只认版本号。
- **离线/在线一致性**：训练用 T 日收盘后数据，线上也必须用同一时点数据；不要用「实时快照」去复现「历史收盘」。
- **模型监控**：预测分布漂移（PSI）、特征缺失率、IC 滚动均值、换手率、与基准的相关性。漂移超阈值自动降权或停用。
- **重训节奏**：日频模型按月/季度滚动重训，避免每天追噪声；重训后先跑纸面交易再切生产。

## 实践一：Walk-Forward 逻辑回归与样本外 IC

不依赖 sklearn，用 numpy 实现带 L2 的逻辑回归梯度下降。数据是合成的：5 个因子，前 3 个有真实信号，后 2 个是噪声。

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(2024)
n_days, n_stocks, n_feat = 1200, 60, 5

# 因子：截面标准化，前 3 个有预测力，后 2 个纯噪声
F = rng.normal(size=(n_days, n_stocks, n_feat))
F = (F - F.mean(axis=1, keepdims=True)) / (F.std(axis=1, keepdims=True) + 1e-12)

mu = 0.0012 * F[:, :, 0] - 0.0008 * F[:, :, 1] + 0.0004 * F[:, :, 2]
ret = mu + rng.normal(0, 0.02, size=(n_days, n_stocks))
label = (ret > np.median(ret, axis=1, keepdims=True)).astype(float)


def fit_logistic(X, y, l2=1e-3, lr=0.3, epochs=500):
    """批量梯度下降 + L2，返回权重与截距。"""
    w = np.zeros(X.shape[1])
    b = 0.0
    n = len(y)
    for _ in range(epochs):
        z = X @ w + b
        p = 1 / (1 + np.exp(-np.clip(z, -30, 30)))
        g = p - y
        w -= lr * (X.T @ g / n + l2 * w)
        b -= lr * g.mean()
    return w, b


train_days, test_days = 250, 20
preds, rets, labels, coefs, idx = [], [], [], [], []

for start in range(train_days, n_days - test_days + 1, test_days):
    Xtr = F[start - train_days:start].reshape(-1, n_feat)
    ytr = label[start - train_days:start].ravel()
    mu_, sd_ = Xtr.mean(axis=0), Xtr.std(axis=0) + 1e-12
    Xtr = (Xtr - mu_) / sd_              # 只用训练集统计量，避免泄漏

    w, b = fit_logistic(Xtr, ytr)

    Xte = (F[start:start + test_days].reshape(-1, n_feat) - mu_) / sd_
    p = 1 / (1 + np.exp(-np.clip(Xte @ w + b, -30, 30)))

    preds.append(p.reshape(test_days, n_stocks))
    rets.append(ret[start:start + test_days])
    labels.append(label[start:start + test_days])
    coefs.append(w)
    idx.extend(range(start, start + test_days))

pred = pd.DataFrame(np.vstack(preds), index=idx)
fwd = pd.DataFrame(np.vstack(rets), index=idx)
lab = pd.DataFrame(np.vstack(labels), index=idx)

# RankIC：先做截面排序，再算逐日相关系数
ic = pred.rank(axis=1).corrwith(fwd.rank(axis=1), axis=1)
print("样本外 RankIC 均值 %.4f，标准差 %.4f，年化 ICIR %.2f" % (
    ic.mean(), ic.std(), ic.mean() / ic.std() * np.sqrt(252)))

# 用预测值做多空组合（截面去均值、按绝对值归一）
weight = pred.sub(pred.mean(axis=1), axis=0)
weight = weight.div(weight.abs().sum(axis=1), axis=0)
ls = (weight * fwd).sum(axis=1)
print("多空组合年化夏普（未扣成本）: %.2f" % (ls.mean() / ls.std() * np.sqrt(252)))
print("方向准确率: %.4f" % ((pred.values > 0.5).astype(float) == lab.values).mean())
print("各因子平均权重:", np.round(np.mean(coefs, axis=0), 4))
```

典型输出：RankIC 约 0.07、年化 ICIR 约 9、方向准确率约 52.4%，前三个因子的权重明显大于后两个噪声因子。注意这是**合成数据且未扣交易成本**，夏普没有现实意义；这段代码验证的是「流程正确、没有未来泄漏、模型能从噪声中恢复真实结构」。

真实项目里把 `fit_logistic` 换成 LightGBM，加上早停、单调约束、特征重要性，其余流程不变。

## 实践二：试验次数如何虚高最优夏普

生成 2000 个「真实夏普为 0」的随机策略，每个策略 252 天收益，看不同试验次数下最优夏普的分布：

```python
import numpy as np

rng = np.random.default_rng(7)
n_days = 252
pool = rng.normal(0, 1 / np.sqrt(n_days), size=(2000, n_days))
sharpe = pool.mean(axis=1) / pool.std(axis=1) * np.sqrt(n_days)

print("全部策略: 平均夏普 %.2f，标准差 %.2f" % (sharpe.mean(), sharpe.std()))
print("\n试验次数   最优夏普   P(最优>1.5)   P(最优>2.0)")
for n in [10, 50, 100, 500, 2000]:
    best = sharpe[:n]
    print("%8d   %8.2f   %10.2f   %10.2f" % (
        n, best.max(), (best > 1.5).mean(), (best > 2.0).mean()))

print("\n2000 次试验的全局最优: %.2f" % sharpe.max())
print("理论近似 sqrt(2*ln(N)): %.2f" % np.sqrt(2 * np.log(2000)))
```

典型结果：全部策略平均夏普接近 0，但试 100 次的最优约 2.6，试 2000 次的最优约 3.1。**这不是策略有效，而是选择偏差。** 所以「我回测出一个夏普 2.5 的策略」本身不构成证据，必须报告试了多少次、怎么选的、样本外表现如何。

## 实践三：三重障碍法打标签

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(11)
n = 600
ret = rng.normal(0.0002, 0.012, n)
price = 100 * np.exp(np.cumsum(ret))
vol = pd.Series(ret).rolling(20).std().bfill().values

K_UP, K_DOWN, HORIZON = 2.0, 2.0, 10
labels, holding, hit_type = [], [], []

for t in range(n - HORIZON):
    upper = price[t] * (1 + K_UP * vol[t])
    lower = price[t] * (1 - K_DOWN * vol[t])
    outcome = 0
    for j in range(1, HORIZON + 1):
        if price[t + j] >= upper:
            outcome, days, hit = 1, j, "上障碍"
            break
        if price[t + j] <= lower:
            outcome, days, hit = -1, j, "下障碍"
            break
    else:
        days, hit = HORIZON, "时间障碍"
    labels.append(outcome)
    holding.append(days)
    hit_type.append(hit)

dist = pd.Series(labels).value_counts(normalize=True).sort_index()
print("标签分布（-1 下跌 / 0 时间 / +1 上涨）:")
print(dist.round(3).to_string())
print("\n触及类型占比:")
print(pd.Series(hit_type).value_counts(normalize=True).round(3).to_string())
print("\n平均持有天数: %.2f" % np.mean(holding))
for k in [-1, 0, 1]:
    days = [d for d, y in zip(holding, labels) if y == k]
    print("标签 %+d 的平均持有天数: %.2f" % (k, np.mean(days)))
```

典型结果：上障碍约 43%、下障碍约 38%、时间障碍约 19%，平均持有 5.6 天。标签分布严重不平衡时，分类器会倾向多数类；要么做类别权重，要么把时间障碍样本单独作为「中性」类，要么改用回归目标。

注意：三重障碍必须用**当时可知的波动率**（滚动窗口），且持有期重叠会让相邻标签高度相关，训练集切分要 Purge。

## 常见误区与坑

1. **用未来数据做特征**：财报用「报告期」而不是「公告日」，把未公布的数据提前用了；或者用当日收盘价算的特征去预测当日收益。
2. **随机 K-Fold**：训练集包含未来，回测夏普虚高，实盘归零。
3. **只看准确率**：类别不平衡时 90% 准确率可能只是「全猜多数类」；要看 IC、收益、换手和成本后表现。
4. **把 LLM 当预测模型**：让 LLM 直接输出「明天涨跌」，既不可复现，也无法回测，还可能有合规风险。
5. **忽略交易成本**：日频高换手模型，毛收益 20%、成本 15%，净值曲线很难看。
6. **用全样本标准化**：均值和方差用了未来数据，属于隐性泄漏。标准化参数只能来自训练集。
7. **频繁重训追噪声**：每天用最新数据重训，模型在噪声里来回横跳。设定重训频率和切换门槛。
8. **不记录试验次数**：只留下「成功」的回测，无法计算 DSR，也无法判断是不是运气。

## 常见问题 Q&A

**Q1：没有机器学习基础能做量化吗？**
能。日频基本面/量价策略的核心是数据清洗、因子逻辑、组合优化和成本控制，线性模型加严格回测就能跑。ML 是边际增强，不是入场门票。

**Q2：为什么树模型在量化里比深度学习常见？**
表格型因子、样本量有限、需要可解释和快速迭代，正好是 LightGBM/XGBoost 的强项。深度学习需要更大数据量、更稳定的分布和更强的工程能力，收益不一定更好。

**Q3：标签用收益率回归还是分类？**
收益回归保留幅度信息但噪声大；分类稳健但丢幅度。实践常用「截面排序 + 分类」或「波动率缩放后的收益回归」，再用三重障碍引入交易语义。关键是一致：训练标签和实盘决策必须对应。

**Q4：样本外 IC 多少算可用？**
日频截面 RankIC 长期均值 0.02~0.05 已可能有价值，但必须结合换手、成本和容量看。IC 0.05 且每天换手 100%，成本可能吃光收益；IC 0.03 且低换手，反而更实用。

**Q5：LLM 能直接生成因子吗？**
可以生成候选逻辑和代码，但必须人工验证数据时点、计算口径、是否含未来信息，并放进统一的因子回测框架。把 LLM 输出直接上实盘，是把幻觉引入资金曲线。

**Q6：模型多久重训一次？**
看策略频率和稳定性。日频模型常见月度或季度重训；分钟级高频模型可能每日更新，但要有严格的样本外监控和回滚机制。重训频率本身也是一个需要验证的超参数。

## 自测

1. 为什么普通 K-Fold 在金融时序上会泄漏？Purge 和 Embargo 分别解决什么问题？
2. 三重障碍法的三个障碍如何设置？标签重叠会带来什么后果？
3. 试了 50 个策略，最优夏普 2.2，如何判断它是否显著？需要哪些额外信息？
4. 用 LLM 抽取财报数据做因子，工程上必须补哪三件事才能用于回测？
5. 某模型训练集 IC 0.08、测试集 IC 0.01，列出至少三种可能原因和排查顺序。
6. 为什么「准确率 55%」不如「RankIC 0.04 + 低换手」更能说明策略有价值？

参考要点：1）训练集含未来样本；Purge 删除标签区间重叠，Embargo 在边界留空防特征窗口泄漏。2）上下障碍按波动率缩放并覆盖成本，时间障碍设持有期；重叠导致样本相关、CV 泄漏。3）需要试验次数、策略间相关性、样本长度、偏度峰度，计算 DSR 或至少做 Bonferroni 式折扣。4）固化输出 schema、打公告时间戳、回原文校验关键数字，并落库成可追溯特征。5）过拟合、特征漂移、标签泄漏、训练/测试分布不同；先查时间戳与特征计算，再看稳定性，最后才怀疑模型。6）准确率忽略幅度和排序，IC 直接衡量排序能力，低换手决定成本后是否可交易。
