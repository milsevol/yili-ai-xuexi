# 10 工具生态与 FAQ

## 一句话定位

量化工具链没有「最好」，只有「和你的频率、资金、工程能力匹配」。日频个人策略用 pandas + Parquet + 一个轻量回测框架就能闭环；分钟级、多账户、多策略才需要向量化引擎、消息队列和交易网关。先跑通含成本的完整回路，再按瓶颈换工具。

## 解决什么问题

- 面对几十个库不知道从哪下手，装了 qlib 又被数据准备劝退。
- 回测框架选型靠别人推荐，结果多资产、A 股规则、实盘对接都不匹配。
- 代码全堆在 notebook 里，换台机器就跑不起来，无法复盘。
- 不知道每个阶段该学什么、做到什么程度算过关。
- 踩了复权、PIT、幸存者偏差的坑，却不知道错在哪一步。

三条硬规则：

1. `factors/` 和 `strategies/` 不读文件、不连数据库，保证回测与实盘调用同一份逻辑。
2. `notebooks/` 里的结论必须沉淀成 `factors/` 或 `strategies/` 的代码，否则不可复现。
3. 每个数据快照带 manifest（日期、来源、行数、hash），回测报告必须记录用了哪个快照。

## 三阶段学习路线

### 阶段一：跑通含成本的日频回测

目标不是赚钱，而是验证「数据 → 因子 → 信号 → 撮合 → 成本 → 指标 → 报告」全链路正确。

- 数据：一只宽基成分股，5 年以上日线，处理复权、停牌、涨跌停。
- 因子：1 个简单动量或均值回归因子。
- 回测：T 日信号 T+1 开盘成交，单边成本 10–20 bp，按 100 股取整。
- 指标：年化收益、波动、夏普、最大回撤、Calmar、年换手。
- 验收：能解释每一笔交易为什么发生；把成本从 0 调到 30 bp，结果单调变差。

### 阶段二：小资金实盘（模拟盘 → 实盘）

- 先跑 2–3 个月模拟盘，记录信号与实际成交的差异。
- 用最小资金实盘（能覆盖 100 股和最低佣金即可），重点验证下单、回报、对账、断线恢复。
- 建立每日对账和告警；每周复盘滑点、成交率、IS。
- 验收：连续 20 个交易日对账无差异，最大回撤在预案内，kill switch 演练成功。

### 阶段三：规模化（多策略、组合、风控、运维）

- 多策略资金分配：风险平价、波动率目标、相关性约束。
- 组合层风控：总敞口、行业中性、单票上限、回撤降仓。
- 工程：任务调度、监控看板、日志归档、版本发布与回滚。
- 验收：新增策略不影响存量；任一策略可独立停用；故障能在 10 分钟内定位。

## 实践：最小成本敏感回测

用 60 日均线趋势策略，比较 0/5/15/30 bp 单边成本下的表现。注意 `signal.shift(1)` 保证 T 日收盘信号在 T+1 生效，避免未来函数。

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(2024)
dates = pd.bdate_range("2020-01-01", periods=750)
ret = rng.normal(0.0004, 0.015, len(dates))
df = pd.DataFrame({"close": 100 * np.cumprod(1 + ret)}, index=dates)
df["ret"] = df["close"].pct_change().fillna(0.0)
df["ma60"] = df["close"].rolling(60).mean()
df["signal"] = (df["close"] > df["ma60"]).astype(int)


def backtest(df, cost_bps):
    pos = df["signal"].shift(1).fillna(0)          # T 日信号，T+1 生效
    turnover = pos.diff().abs().fillna(pos.abs())  # 仓位变化即换手
    strat_ret = pos * df["ret"] - turnover * cost_bps / 10000
    nav = (1 + strat_ret).cumprod()
    ann = nav.iloc[-1] ** (252 / len(nav)) - 1
    vol = strat_ret.std() * np.sqrt(252)
    sharpe = strat_ret.mean() / strat_ret.std() * np.sqrt(252)
    mdd = (nav / nav.cummax() - 1).min()
    return {
        "年化收益": ann,
        "年化波动": vol,
        "夏普": sharpe,
        "最大回撤": mdd,
        "Calmar": ann / abs(mdd) if mdd else np.nan,
        "年换手": turnover.sum() * 252 / len(turnover),
    }


result = pd.DataFrame({f"{c}bp": backtest(df, c) for c in [0, 5, 15, 30]}).T
print(result.round(3).to_string())
```

典型输出：0 bp 年化约 4.6%、夏普 0.34；15 bp 年化降到 2.3%；30 bp 年化接近 0。年换手约 14.8 倍，意味着成本对净值的影响是线性的、可预测的。**如果你的策略只有在 0 成本下才赚钱，它就不是策略，是幻觉。**

这段代码刻意省略了涨跌停、停牌、分红、最低佣金等细节，用于理解主流程；真实回测必须逐项补上。

## 常见坑清单

1. **复权方式不统一**：回测用后复权、实盘用不复权，均线和收益率全部错位。统一用一份带复权因子的事实表，在读取层决定展示方式。
2. **PIT 陷阱**：用财报的「报告期」而不是「公告日」，把尚未公布的数据提前用了。所有财务因子必须按公告日对齐。
3. **幸存者偏差**：只用当前存续的股票回测，退市、暂停上市的票被剔除，收益被高估。股票池要包含历史成分与退市样本。
4. **滑点假设过低**：回测统一 5 bp，实盘小盘股冲击 30 bp 以上。按标的流动性、下单量动态估计。
5. **涨跌停不可成交**：一字涨停买不进、跌停卖不出，回测却当普通成交。用开盘价与涨跌停价判断可成交性。
6. **停牌处理**：停牌期间信号仍在，复牌后价格跳空。停牌日不生成订单，复牌按真实价格成交。
7. **未来函数**：用当日收盘价算信号又用当日收盘价成交；用全样本均值标准化；用未来才知道的成分股名单。任何「今天知道明天」都是泄漏。
8. **参数过拟合**：在同一个区间试几百组参数，挑最优。用样本外/滚动验证，并记录试验次数。
9. **数据对齐错误**：不同频率、不同时区、不同交易日的表直接 `merge`，产生大量 NaN 或错位。先对齐交易日历和时区。
10. **时区混用**：服务器 UTC、数据北京时间、日志本地时间，三套时间导致盘中判断错乱。全链路统一时区。
11. **最低 5 元佣金**：多数券商设 5 元最低佣金，小资金单笔按 5 元收，频繁小额交易的成本远高于万三。回测要按「max(费率×金额, 5 元)」计算。
12. **融资成本**：加杠杆只算收益不算利息和强平风险。融资年化 5%–8%，必须计入。
13. **容量被忽略**：策略在 100 万时有效，到 1 亿时冲击成本吃光收益。用「下单量/日均成交量」估算容量上限。
14. **分红送转**：除权除息导致价格跳空，不复权会把分红当成下跌。用复权价或显式加回分红。
15. **交易日历想当然**：用「周一到周五」推算，遇到节假日、临时休市、半日市全错。用权威交易日历。
16. **把历史成交量当可成交量**：你的订单会改变市场，也会和其他算法单竞争。按参与率折减。
17. **用收盘价成交**：尾盘流动性、集合竞价规则、涨跌停都可能让收盘价不可得。至少用次日开盘价 + 滑点。
18. **频繁调参**：每天根据昨日表现改参数，本质是在拟合噪声。设定调参频率和最小样本量。

## FAQ

**Q1：需要多少资金起步？**
股票策略建议至少 5–10 万元：能分散 5–10 只票、满足 100 股整数倍、佣金不被最低 5 元过度侵蚀。资金更少可以先做模拟盘或 ETF，重点验证流程而不是收益。期货有保证金门槛，另算。

**Q2：数学要学到什么程度？**
入门只需要概率统计（均值、方差、相关性、回归）、线性代数和一点微积分。进阶再补时间序列、凸优化、随机过程。不要为了「学完数学」推迟动手，很多坑是数据和工程问题，不是数学问题。

**Q3：Python 够不够？**
个人研究到中小规模实盘完全够。瓶颈通常在数据质量、执行和运维，不在语言。只有极低延迟（微秒级）或超大规模计算才需要 C++/Rust。

**Q4：要不要学 C++？**
做日频/分钟级不需要；做高频、做市、FPGA 才需要。先能用 Python 稳定赚钱，再考虑降延迟，否则是过早优化。

**Q5：一个人能做量化吗？**
能，但要做减法：选一个市场、一个频率、一类因子，把数据和执行做扎实。一个人最大的风险不是模型不够复杂，而是运维、风控、心理和资金管理。

**Q6：A 股 T+1 对策略有什么影响？**
当日买入不能当日卖出，日内反转、打板、高频做市类策略受限；信号必须是「隔日可执行」的。卖出资金当日可继续买入，但提现通常 T+1。回测必须模拟 T+1 持仓约束。

**Q7：量化会不会加剧亏损？**
会。量化只是把决策规则化，规则错了会更快、更机械地亏。杠杆、过度拟合、缺少风控的量化，亏损速度可能超过主观交易。先控制单笔风险和总回撤，再谈收益。

**Q8：多久能稳定盈利？**
没有标准答案。多数人需要 1–3 年完成「不亏大钱 → 小亏 → 持平 → 稳定」的过程，且稳定是相对的。把目标设为「先活下来、再验证边际」，比设「半年翻倍」现实。

**Q9：如何判断回测可信？**
看五件事：是否含真实成本、是否处理涨跌停/停牌/复权、是否样本外验证、试验次数是否记录、容量是否估算。任何一项缺失，夏普都要打折。最好的验证是小资金实盘。

**Q10：因子失效怎么办？**
先区分「正常回撤」和「逻辑失效」：看滚动 IC、分组收益、换手、相关性是否结构性变化。若逻辑被市场结构破坏（如规则改变、参与者变化），下线；若只是短期拥挤，降权并观察。不要用调参硬救。

**Q11：先做因子还是先做回测框架？**
先做最小回测框架（能算成本、能出净值），否则因子好坏无法判断；但不要一开始造「通用平台」。用 100 行代码跑通，再随需求扩展。

**Q12：数据从哪里来？**
入门用 akshare/baostock 免费数据；需要稳定财务和行情用 tushare 或商业数据；机构用 Wind/聚宽/米筐。无论哪种，都要自己落一份快照并校验，不能每次回测都实时拉。

**Q13：需要买 Wind 吗？**
个人不建议。Wind 贵且授权限制多，免费数据加严格清洗能满足日频研究。只有做机构级基本面、覆盖全市场细节、需要合规数据源时才值得。

**Q14：用现成平台还是自建？**
研究阶段用现成平台（聚宽/米筐/qlib）快速验证；实盘建议自建执行与风控，因为平台对券商通道、异常处理、审计的支持有限。折中方案：研究在平台，信号落地到自己进程。

**Q15：个人能做高频吗？**
很难。高频需要低延迟通道、托管、极低费率、强大的运维和风控，个人在成本和合规上都不占优。分钟级或日内波段是更现实的方向。

**Q16：如何控制回撤？**
三层：仓位（波动率目标、风险预算）、分散（多策略、多因子、行业中性）、熔断（回撤触发降仓/停机）。回撤控制一定牺牲收益，关键是在事前定义「可接受的最大回撤」。

**Q17：要不要做空/对冲？**
A 股个股做空难，常用股指期货、ETF 对冲。对冲能降低 beta，但会引入基差、保证金和展期成本；不是所有策略都适合对冲。先看策略收益是 alpha 还是 beta。

**Q18：模拟盘要跑多久？**
至少 2–3 个月，覆盖不同市场状态；更重要的是覆盖「异常」：断线、废单、涨跌停、停牌、除权。模拟盘不能完全替代实盘，但能暴露 80% 的工程问题。

**Q19：最大的坑是什么？**
不是模型不够好，而是「用不可信的回测说服自己」。数据泄漏、成本低估、幸存者偏差三者叠加，能造出任何想要的曲线。

**Q20：学量化要不要读研/考证？**
不是必需。数学、统计、编程、金融知识的组合比学历标签更重要；有真实可复现的项目和实盘记录，比证书有说服力。研究型岗位会更看重学历，个人交易不看。

## 术语表

| 术语 | 含义 | 备注 |
| --- | --- | --- |
| Alpha | 超出基准的超额收益 | 扣除 beta 后的部分 |
| Beta | 对市场基准的敏感度 | `β = Cov(r, r_m)/Var(r_m)` |
| IC | 因子值与未来收益的相关系数 | 常用 Pearson IC |
| RankIC | 因子排名与未来收益排名的相关系数 | 对极值更稳健，A 股常用 |
| IR | 信息比率，超额收益 / 跟踪误差 | 衡量相对基准的稳定性 |
| Sharpe | 夏普比率，`(收益 - 无风险利率)/波动率` | 需说明年化方式 |
| Sortino | 只用下行波动计算的风险调整收益 | 对上涨波动不惩罚 |
| MDD | 最大回撤，净值从峰值到谷底的最大跌幅 | 负数表示 |
| Calmar | 年化收益 / 最大回撤绝对值 | 衡量回撤性价比 |
| 换手率 | 一定期内买卖金额 / 平均持仓市值 | 双边/单边口径要统一 |
| 滑点 | 成交价与基准价的差 | 用 bps 表示 |
| 冲击成本 | 自己的交易对价格造成的推动 | 随下单速率上升 |
| 容量 | 策略在成本可控下能承载的资金规模 | 受流动性约束 |
| PIT | Point-in-Time，只用当时可知的数据 | 财务因子按公告日 |
| 幸存者偏差 | 只统计存续样本导致的高估 | 退市股票也要纳入 |
| 多空 | 同时做多和做空 | A 股个股做空受限 |
| 对冲 | 用衍生品或反向头寸抵消 beta | 有基差和保证金成本 |
| 杠杆 | 用借入资金放大仓位 | 放大收益也放大回撤 |
| 归因 | 把收益拆解到因子/行业/个股/交易 | 判断收益来源 |
| 波动率 | 收益率的标准差 | 常年化，`σ_daily × sqrt(252)` |
| 跟踪误差 | 组合与基准收益差的标准差 | 指数增强核心指标 |
| 胜率 | 盈利交易数 / 总交易数 | 必须和盈亏比一起看 |
