# 04 策略体系与信号构建

## 一句话定位

策略是「在什么市场状态下、对哪些资产、按什么规则下注」的完整契约；信号构建就是把这个契约翻译成可计算、可回测、可执行的数值序列。

## 解决什么问题

把「我觉得这个票要涨」变成「当 20 日均线上穿 60 日均线、且过去 20 日日均成交额大于 2 亿元时，次日开盘建立 1 个单位多头，价格跌破入场价 2 倍 ATR 时平仓」。

没有这一步转换，策略无法被检验，也无法被复用、组合和归因。信号层必须同时回答三件事：

1. **方向**：做多、做空、还是空仓；
2. **强度**：仓位多大（0.1 仓还是满仓，是否有杠杆）；
3. **有效期**：持有到什么时候、什么条件下退出。

指标的选取只是最表层的一步，真正决定策略上限的是「这个信号背后有没有可解释的收益来源」，以及「它和已有信号的相关性有多高」。

## 策略分类树

```
量化策略
├── 方向性（单资产择时，赚 beta / 时序风险溢价）
│   ├── 趋势 / 动量：双均线、通道突破、时序动量、ATR 跟踪止损
│   └── 均值回归：布林带、RSI、偏离均线回归、隔夜反转
├── 相对价值（两腿及以上，赚价差收敛）
│   ├── 统计套利：配对交易、协整组合、ETF 折溢价
│   └── 跨期 / 期现：期货跨月价差、基差、期现套利
├── 横截面（多标的排序，赚截面离散度）
│   ├── 多因子选股：价值 / 质量 / 动量 / 低波 / 成长
│   └── 指数增强：在跟踪误差约束下做 alpha
├── 事件驱动（赚信息扩散的时间差）
│   └── 财报超预期、并购重组、指数调仓、大宗交易、增减持
└── 做市 / 高频（赚价差与微观结构）
    └── 双边报价、订单簿不平衡、延迟套利
```

分类的意义在于**收益来源和失效条件不同**：趋势策略怕震荡，均值回归怕单边，多因子怕风格切换，事件驱动怕拥挤，做市怕毒性订单流。知道策略属于哪一类，才知道它什么时候会亏、亏多少、该不该坚持。

## 趋势跟踪

### 双均线与通道突破

```
MA_n(t) = (P_t + P_{t-1} + ... + P_{t-n+1}) / n
signal  = 1 if MA_fast > MA_slow else 0

唐奇安通道（Donchian）：
upper(t) = max(High, N)
lower(t) = min(Low,  N)
入场：收盘价突破 upper(N=20)  → 做多
出场：收盘价跌破 lower(N=10)  → 平仓
```

海龟法则的核心不是通道，而是**波动率归一化的仓位**：先用 ATR 度量波动，再让每笔交易的风险预算相等。

```
TR(t)  = max(High-Low, |High-PrevClose|, |Low-PrevClose|)
ATR(t) = EMA(TR, n)                    # 常用 n = 14~20
止损距离 = k * ATR                     # k = 2~3
手数     = 单笔风险预算 / (止损距离 * 合约乘数)
```

ATR 止损比固定百分比止损更合理：同样 2% 止损，在高波动品种上会被反复扫损，在低波动品种上又太宽松。

### 时序动量与截面动量

| 维度 | 时序动量（absolute） | 截面动量（relative） |
| --- | --- | --- |
| 问题 | 这个资产未来会涨吗 | 哪个资产会跑赢其他 |
| 信号 | 过去 12 个月收益 > 0 则做多，否则空仓/做空 | 按过去 12 个月收益排序，多空各 20% |
| 组合 | 每个资产独立决策，天然多空不对称 | 多空对冲，市场 beta 近似中性 |
| 容量 | 大（期货、ETF） | 中（受融券与流动性约束） |
| 典型失效 | 快速 V 型反转、政策干预 | 动量崩溃（momentum crash）、风格急转 |

### 收益特征

- **胜率低（30%~45%）、盈亏比高（2~3 倍）**：大多数交易小亏离场，少数趋势吃到完整波段。
- **收益右偏**：月度收益分布有正尾部，靠少数几个月贡献全年利润。
- **震荡市连续回撤**：假突破导致「小亏 - 小亏 - 小亏」，回撤期可能持续 1~2 年。
- **长周期才有效**：日频信号噪声大，月度、季度级别的动量在百年数据上仍然稳健（AQR 的百年趋势跟踪研究是经典证据）。
- **危机 alpha**：股票市场急跌时趋势策略常能反手做空，与股债组合负相关，这是它被配置的主要理由。

## 均值回归

### 三种常见做法

```
布林带：mid = MA(P, n),  sd = std(P, n)
        upper = mid + k*sd,  lower = mid - k*sd
        z = (P - mid) / sd          # 价格偏离多少个标准差

RSI：RS = 平均涨幅(n) / 平均跌幅(n)
     RSI = 100 - 100 / (1 + RS)     # >70 超买，<30 超卖

配对：spread = log(P_A) - beta * log(P_B)     # beta 由 OLS 估计
      z = (spread - mean(spread)) / std(spread)
      开仓 |z| > 2，平仓 |z| < 0.5，止损 |z| > 3.5
```

### 协整：配对交易的理论基础

**相关 ≠ 协整**。两只股票可能高度相关（同涨同跌），但价差持续发散；协整要求存在某个线性组合是平稳序列（均值回复）。

实践中的检验思路：

1. 用 OLS 回归 `log(P_A) = alpha + beta * log(P_B) + e`；
2. 对残差 `e` 做 ADF 单位根检验，拒绝单位根假设才认为存在协整关系；
3. 用样本外数据复核 beta 的稳定性（滚动回归，beta 漂移过大说明关系已破坏）。

ADF 检验只说明「历史上 mean-reverting」，不保证未来。配对关系可能因为基本面变化（并购、主业转型、指数调整）永久失效，所以**必须设时间止损**：价差不回归超过 N 天就认亏离场，而不是无限加仓摊平。

### 收益特征

- **胜率高（60%~80%）**，单笔盈利小，曲线平滑；
- **尾部风险大**：一次价差发散可以吞掉几十次盈利，这就是「在压路机前捡硬币」；
- **必须止损**，且止损要基于波动率而非固定比例；
- **容量受限于流动性**，且策略拥挤后价差收敛速度变快、幅度变小。

## 多因子选股

### 三种实现路径

| 方法 | 做法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 打分法 | 每个因子做标准化/分位数变换，加权求和得综合分，取 top N | 直观、可解释、易约束 | 权重靠拍脑袋，因子间相关性未处理 |
| 回归法 | 用历史截面估计 `r_{t+1} = a + Σ b_k f_{k,t} + e`，用 b 预测下期 | 权重由数据给出，有统计基础 | 多重共线性、时变系数、极端值敏感 |
| 机器学习 | GBDT / 神经网络直接学「因子 → 未来收益」映射 | 能捕捉非线性与交互 | 极易过拟合，特征泄漏风险高，可解释性差 |

打分法的关键细节：**因子方向统一**（低估值、低波动要取负号）、**去极值**（MAD 或 3σ 截断）、**行业与市值中性化**（否则因子变成行业 beta 或小市值 beta）。

### 指数增强的约束

指数增强 = 多因子 alpha + 严格的风险约束。约束不写清楚，回测再漂亮也落不了地：

| 约束 | 典型取值 | 作用 |
| --- | --- | --- |
| 跟踪误差 | 年化 3%~8% | 控制与基准的偏离度 |
| 行业偏离 | 单行业 ±2%~3% | 防止变成行业轮动 |
| 成分股内权重 | ≥ 80% | 保证是「增强」而非「主动」 |
| 单票上限 | 基准权重 + 1% | 控制个股风险 |
| 换手率 | 双边年化 < 500% | 控制成本与冲击 |
| 禁投池 | ST、停牌、退市风险 | 合规与可交易性 |

## 统计套利

### 三类典型形态

| 形态 | 交易逻辑 | 主要风险 |
| --- | --- | --- |
| 配对交易 | 同行业两只股票的价差偏离均值后做多低估、做空高估 | 关系破裂、融券成本、券源不足 |
| ETF 折溢价 | 溢价时买入成分股申购 ETF 卖出；折价时买入 ETF 赎回卖出 | 申赎门槛（通常百万级）、T+0/T+1 时滞、停牌成分股 |
| 期现套利 | 期货与现货基差偏离持有成本时反向操作，到期收敛 | 保证金追缴、分红预测误差、交割规则 |

期现套利的价格锚是**持有成本模型**：

```
F = S * exp((r - q) * T)
基差 = F - S
年化基差率 = (F/S - 1) * 365 / 剩余天数
```

其中 r 是资金成本，q 是分红率。当实际基差显著高于理论值时，做空期货 + 买入现货；反之反向。看似无风险，但保证金占用、追保时点、现货替代（用 ETF 代替一篮子股票会引入跟踪误差）都会侵蚀利润。

### 共性风险

1. **价差长期不回归**：统计关系有「半衰期」，超过 3~5 倍半衰期不收敛就该止损；
2. **融券成本与券源**：年化 8%~10% 的融券费率会直接吃掉大部分套利收益；
3. **流动性与冲击**：套利机会往往出现在流动性差的标的或极端时刻；
4. **拥挤**：公开的经典配对（如可口可乐/百事）早已被套利者抹平。

## CTA 与期货

期货策略和股票策略的工程差异，主要来自三个机制：

```
1. 保证金与杠杆
   名义价值 = 价格 * 合约乘数 * 手数
   占用保证金 = 名义价值 * 保证金率（10% 左右）
   杠杆倍数 = 1 / 保证金率 ≈ 10 倍（可用，但不该用满）

2. 换月 / 展期（roll）
   主力合约切换时平旧开新，产生展期损益
   展期收益 ≈ (近月价 - 远月价) / 远月价 （做多时）

3. 期限结构
   backwardation（近高远低）：做多有正展期收益，常见于供应紧张的商品
   contango（近低远高）：做多持续付出展期成本，常见于黄金、股指期货贴水反例
```

趋势策略在期货上比股票更有效，原因在于期货可以低成本做空、品种间相关性低、且商品有明显的期限结构溢价。代价是杠杆放大波动，**仓位必须以「波动率目标」而非「固定手数」来定**：`手数 = 目标风险 / (ATR * 合约乘数)`。

## 事件驱动

| 事件类型 | 信号定义 | 有效窗口 | 拥挤度 |
| --- | --- | --- | --- |
| 财报超预期 | 实际 EPS 超一致预期幅度、公告后跳空 | 公告后 1~60 天（PEAD 漂移） | 高 |
| 并购重组 | 停牌复牌、预案公告、过会 | 数天到数月 | 极高 |
| 指数调仓 | 成分股调整公告日至生效日 | 公告日 → 生效日 | 高（已被充分预期） |
| 大宗交易 | 折价率、买方席位、后续减持 | 1~20 天 | 中 |
| 股东增减持 | 增持计划、回购、清仓式减持 | 公告后 5~30 天 | 中低 |

事件研究的核心是**窗口与基准**：用市场模型 `r_i = a + b*r_m + e` 计算事件窗口内的异常收益 AR 与累计异常收益 CAR，再统计显著性与衰减速度。工程上要特别注意**公告时间戳**：盘后公告只能用次日开盘价交易，用公告日的收盘价就是前视偏差。

拥挤是事件策略的最大杀手：当一个规律被写进卖方报告，超额收益会从「事件后 60 天」压缩到「公告后 1 小时」。

## 信号构建工程

### 信号到仓位

```
阈值映射：  pos = 1 if signal > 0.5 else 0            # 简单，但会在阈值附近反复切换
连续映射：  pos = clip(signal, -1, 1)                 # 平滑，换手可控
分位映射：  pos = rank(signal) / N - 0.5              # 横截面用，天然均匀分布
波动率归一：pos = target_vol / sigma_20d * signal      # 让每单位信号承担相同风险
```

波动率归一化是性价比最高的一步：它让高波动品种自动减仓、低波动品种自动加仓，组合的风险贡献更均衡。

### 过滤条件

- **流动性**：过去 20 日日均成交额 < 5000 万元的标的直接剔除；
- **波动**：波动率过高（> 年化 80%）或过低（< 10%）都降权，前者是风险，后者是没弹性；
- **可交易性**：涨跌停、停牌、ST、次新股（上市 < 60 天）；
- **信号一致性**：与已有持仓方向冲突时，按「新信号强度 vs 旧信号强度」决定是否换手。

### 信号衰减与持有期

信号的有效性随时间衰减。横截面因子的 IC 通常在第 1~3 天最高，之后单调下降；日频反转信号半衰期可能只有 1 天。持有期设置原则：

```
持有期 ≈ 信号自相关系数的半衰期
换手成本 < 信号预期收益 * 持有期
```

如果信号每天变化但持有期是 20 天，说明你在用弱信号覆盖强信号；如果信号持续 20 天但每天调仓，说明你在无谓支付成本。

### 多信号合成

| 方法 | 规则 | 适用 |
| --- | --- | --- |
| 投票 | 多数信号同向才开仓 | 信号少、逻辑独立、追求稳健 |
| 等权 z-score | 各信号标准化后取平均 | 信号数量中等（3~10 个） |
| IC 加权 | 权重 ∝ 历史 IC / IC 波动 | 有足够历史、滚动估计 |
| 条件组合 | 趋势信号定方向，均值回归信号定时点 | 逻辑上分层，避免相互抵消 |

合成之前先看**信号相关性矩阵**。两个相关系数 0.9 的信号等权相加，等于给同一个信号双倍权重，还给人「多信号分散」的错觉。

## 过拟合与稳健性

### 参数平原

```
夏普
 1.2 |        ████
 1.0 |     ██████████
 0.8 |  ████████████████
 0.6 |██████████████████████
     +------------------------
      5   10   15   20   25   30   fast

参数平原：相邻参数表现接近 → 稳健
参数尖峰：只有 (12, 47) 表现好 → 几乎一定是噪声
```

判断标准：在最优参数周围 ±30% 的邻域内，绩效不应剧烈坍塌（夏普下降不超过 30%~50%）。

### 样本内外与滚动前推

```
训练 |---- 5 年 ----|  测试 |-- 1 年 --|
                    ↓ 前移
训练    |---- 5 年 ----|  测试 |-- 1 年 --|
                          ↓ 前移
训练       |---- 5 年 ----|  测试 |-- 1 年 --|
```

滚动前推（walk-forward）比单次样本外切分更接近实盘：每期都用「当时可获得的数据」重新定参，把各段样本外结果拼接起来看整体表现。参数的**稳定性**和绩效同等重要——每次重优化都跳到完全不同的参数，说明参数本身没有意义。

### 多重检验

试了 100 组参数，取夏普最高的那组，这个夏普是**有偏的**：100 次独立抽样中最大值天然高于均值。修正思路：

- 记录你试过的所有试验次数 N（包括失败的），用 deflated Sharpe ratio 或 Bonferroni 调整显著性门槛；
- 用随机化检验：把价格序列做 block bootstrap 或打乱收益率顺序，重跑策略 1000 次，看真实绩效是否落在随机分布的尾部之外；
- 优先选择**机制上有解释**的参数，而不是数据上最优的参数。

## 实践代码

下面用 numpy 生成两段风格不同的行情（单边趋势 / OU 均值回复震荡），分别跑双均线和布林带，观察「同一策略在不同市场状态下的表现差异」，最后做一次参数敏感度扫描。

```python
import numpy as np
import pandas as pd

# ============ 1. 造两段风格不同的行情 ============
def trending_price(n=300, drift=0.0012, vol=0.015, seed=7):
    """带漂移的随机游走：单边趋势行情"""
    rng = np.random.default_rng(seed)
    log_ret = rng.normal(drift, vol, n)
    return pd.Series(100 * np.exp(np.cumsum(log_ret)), name="close")

def choppy_price(n=300, theta=0.15, vol=0.015, seed=11):
    """OU 均值回复过程：区间震荡行情"""
    rng = np.random.default_rng(seed)
    x = np.zeros(n)
    for t in range(1, n):
        x[t] = x[t - 1] + theta * (0.0 - x[t - 1]) + rng.normal(0, vol)
    return pd.Series(100 * np.exp(x), name="close")

# ============ 2. 两类信号 ============
def dual_ma_signal(price, fast=10, slow=30):
    """趋势跟踪：快线在慢线上方做多，否则空仓"""
    ma_f = price.rolling(fast).mean()
    ma_s = price.rolling(slow).mean()
    sig = (ma_f > ma_s).astype(float)
    sig[ma_s.isna()] = 0.0
    return sig

def bollinger_signal(price, window=20, k=1.5):
    """均值回归：按 Z-score 反向持仓，截断到 [-1, 1]（正负号代表多空）"""
    ma = price.rolling(window).mean()
    sd = price.rolling(window).std()
    z = (price - ma) / sd
    pos = (-z).clip(-1, 1)                 # 高于均线做空，低于均线做多
    pos[sd.isna() | (sd == 0)] = 0.0
    return pos.fillna(0.0)

# ============ 3. 简易回测：T 日收盘出信号，T+1 生效 ============
def run(price, pos, cost=0.0008):
    ret = price.pct_change().fillna(0.0)
    pos_lag = pos.shift(1).fillna(0.0)     # 关键：避免前视偏差
    turnover = pos.diff().abs().fillna(0.0)
    pnl = pos_lag * ret - turnover * cost
    nav = (1 + pnl).cumprod()
    return {
        "总收益": nav.iloc[-1] - 1,
        "年化波动": pnl.std() * np.sqrt(252),
        "最大回撤": (nav / nav.cummax() - 1).min(),
        "胜率": (pnl[pos_lag != 0] > 0).mean(),
        "累计换手": turnover.sum(),
    }

# ============ 4. 两种行情 × 两种策略 ============
rows = []
for regime, price in [("单边趋势", trending_price()), ("区间震荡", choppy_price())]:
    for name, sig in [("双均线(趋势)", dual_ma_signal(price)),
                      ("布林带(均值回归)", bollinger_signal(price))]:
        rows.append({"行情": regime, "策略": name, **run(price, sig)})

table = pd.DataFrame(rows).set_index(["行情", "策略"]).round(3)
print(table.to_string())

# ============ 5. 参数平原：固定策略扫参数 ============
price = trending_price()
grid = []
for fast in (5, 10, 20):
    for slow in (30, 60, 90):
        if fast >= slow:
            continue
        total = run(price, dual_ma_signal(price, fast, slow))["总收益"]
        grid.append({"fast": fast, "slow": slow, "总收益": round(total, 3)})

print("\n双均线参数敏感度（单边趋势行情）")
print(pd.DataFrame(grid).pivot(index="fast", columns="slow", values="总收益").to_string())
```

预期能观察到的现象（数值因种子固定而确定）：

- 双均线在单边趋势行情里总收益为正、胜率一般、回撤可控；在震荡行情里被反复打脸，胜率低且连续小亏。
- 布林带在震荡行情里胜率高、曲线平滑；一旦行情单边，做空腿会持续逆势亏损，回撤明显放大。
- 参数表里如果某个格子明显高出周围一圈，先怀疑是噪声，而不是找到了圣杯。

## 常见误区与坑

1. **把参数调到历史最优**。历史最优 = 在噪声上做最大似然，样本外大概率均值回归。宁可选参数平原的中心。
2. **忽略交易成本**。日频换手的策略，双边 20bp 成本足以吃掉名义年化 15% 的 alpha 的一大半。先算「盈亏平衡换手率」，再决定信号频率。
3. **把震荡市策略用在单边市**。均值回归策略在中长期单边趋势里会持续逆势加仓，必须叠加趋势过滤器（如 200 日均线之上只做多）。
4. **信号频率与容量不匹配**。信号说「每天调仓」，但标的日均成交额只有 3000 万，你的策略容量上限就是几百万。
5. **只看信号 IC，不看可交易性**。IC 高但集中在涨停板或停牌前的样本，实盘根本拿不到。
6. **多信号盲目等权**。信号高度相关时等权等于加杠杆；先做相关性剔除，再谈合成。

## 常见问题 Q&A

**Q：趋势和均值回归能同时用吗？**
A：能，但要分层：用趋势信号决定「做不做、朝哪个方向」，用均值回归信号决定「什么时候进」。同一时间、同一标的用两个方向相反的信号等权相加，net 出来约等于零，只是多了手续费。

**Q：怎么判断一个信号是不是真的？**
A：三步。第一，机制上能否解释（谁在亏钱、为什么持续亏）；第二，样本外与滚动测试是否稳定；第三，扣掉保守成本后是否还有超额。三条缺一条就降低仓位而不是放弃验证。

**Q：信号每天变，但我想降低换手怎么办？**
A：三招：给信号加缓冲带（买入阈值 0.6、卖出阈值 0.4，中间不动）；用持仓成本约束（只有预期收益超过 2 倍成本才换仓）；把信号做时间平滑（EMA 平滑后的信号等价于延长持有期）。

**Q：配对交易的 beta 用静态还是滚动？**
A：滚动（如 60 日窗口），但要控制更新频率（每月重估），否则 beta 会被短期噪声带跑。同时监控 beta 的时序稳定性，漂移过大说明协整关系可能已破坏。

**Q：因子选股里，打分法和回归法该选哪个？**
A：因子数量少（< 10）、需要严格约束和可解释性，选打分法；因子多、要做因子择时和风险归因，选回归法。机器学习只在样本量足够（数年以上、数千只股票 × 多期）且能做严格样本外验证时才有意义。

**Q：事件驱动怎么避免「公告一出就买不到」？**
A：把可成交价格定义为「公告后第一个可交易时点的开盘价 + 滑点」，并检查该时点是否涨跌停。回测里凡是用了公告日收盘价的，结果一律作废重跑。
