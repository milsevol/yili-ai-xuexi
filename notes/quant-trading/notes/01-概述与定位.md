# 01 概述与定位

## 一句话定位

量化交易是用**系统化规则和模型**替代临场主观判断的投资方式。核心不是「预测得更准」，而是让每一个决策**可验证、可复制、可规模化**：同一份数据、同一套规则，今天和明年跑出来的信号应当一致；赚了知道赚在哪，亏了知道亏在哪。

## 解决什么问题

主观投资最难解决的三件事，恰好是量化要解决的问题：

| 痛点 | 主观交易的表现 | 量化交易的解法 |
| --- | --- | --- |
| 不可复现 | 同样看多，今天重仓、明天轻仓，理由说不清 | 规则写进代码，参数、阈值、股票池全部留痕 |
| 无法归因 | 赚钱归功于「眼光」，亏钱归咎于「市场」 | 收益拆成 Beta、行业、风格、Alpha、交易成本 |
| 难以规模化 | 一个基金经理只能深度覆盖几十只股票 | 一套系统可以扫描全市场几千只标的 |
| 情绪干扰 | 追涨杀跌、亏损扛单、盈利早卖 | 信号与执行分离，用流程和限额约束人 |
| 验证成本高 | 一个判断对错要等半年 | 历史回测、样本外检验、模拟盘快速证伪 |

量化的本质是**把投资变成一门可以反复做实验的工程学科**。实验有假设、有数据、有对照组、有误差分析；但实验也会失败，量化并不承诺赚钱。

## 概念与机制

### 一条完整的决策链路

```
数据 ──► 因子/特征 ──► 信号 ──► 组合 ──► 执行 ──► 风控 ──► 归因
 │          │            │         │        │        │        │
行情/财报   动量/价值    打分/预测  权重/约束 拆单/成本  限额/止损  收益拆解
另类数据    质量/情绪    阈值/排序  行业中性 算法交易  合规检查  Alpha/Beta
```

| 环节 | 输入 | 输出 | 最关键的问题 | 典型失败 |
| --- | --- | --- | --- | --- |
| 数据 | 行情、财报、公告、另类数据 | 清洗后的面板 | 有没有未来函数、幸存者偏差 | 用公告日之前的数据 |
| 因子 | 原始字段 | 可横截面排序的数值 | 有没有经济学逻辑 | 纯数据挖掘、因子拥挤 |
| 信号 | 因子值 | 买/卖/持有、打分 | 阈值是否稳定 | 参数过拟合 |
| 组合 | 信号、约束 | 目标权重 | 风险预算是否合理 | 行业/市值暴露失控 |
| 执行 | 目标权重、盘口 | 成交回报 | 成本与冲击 | 用收盘价假设成交 |
| 风控 | 持仓、市场状态 | 限额、降仓、止损 | 极端情形能否活下来 | 杠杆爆仓、流动性枯竭 |
| 归因 | 持仓、收益、因子暴露 | 收益来源报告 | 赚的是 Alpha 还是 Beta | 把风格收益当成能力 |

这条链路里，**越靠前的问题越致命**：数据错了，后面全错；因子没有逻辑，回测再好也只是拟合噪声；执行成本被低估，纸面 Alpha 会被真实交易吃光。

### 量化、主观与高频的边界

主观与量化是方法论的两端，现实中大量产品是混合体（quantamental）：量化筛股、主观复核，或主观定方向、量化做执行。

```
主观 ◄──────────── 方法论光谱 ────────────► 量化
   调研、拍板、集中持仓          规则、模型、分散持仓
                    │
                    └── 混合：量化初筛 + 主观深度研究
```

高频不是与量化并列的另一类，而是量化的一个子集，按持仓周期可以这样分：

```
量化交易
├── 低频（周—季）：多因子选股、指数增强、市场中性
├── 中频（日—周）：趋势/动量、均值回归、事件驱动
└── 高频（毫秒—秒）：做市、延迟套利、微观结构套利
```

| 维度 | 主观投资 | 量化投资 | 高频交易 |
| --- | --- | --- | --- |
| 决策依据 | 调研、产业判断、经验 | 数据、统计模型、规则 | 订单簿、延迟、微观结构 |
| 持仓周期 | 月—年 | 日—季 | 毫秒—秒 |
| 换手率 | 低 | 中 | 极高 |
| 容量 | 大 | 中—大 | 小 |
| 核心能力 | 商业理解、信息优势 | 统计、编程、工程 | 低延迟系统、硬件、做市牌照 |
| 主要风险 | 认知偏差、集中度 | 因子失效、过拟合 | 技术故障、逆向选择、监管 |

高频的容量通常很小，因为它的利润来自极短时间内的价差和返佣，规模一大就会自己把价差打平。**把高频的收益率套到大规模资金上，是最常见的容量误判。**

### 策略谱系

| 策略类型 | 收益来源 | 典型持仓周期 | 容量 | 换手 | 主要风险 |
| --- | --- | --- | --- | --- | --- |
| 趋势/动量 | 价格惯性、信息扩散慢、处置效应 | 天—月 | 中高 | 低—中 | 震荡市反复止损、动量崩溃 |
| 均值回归 | 短期过度反应后的修复 | 分钟—几天 | 中 | 高 | 趋势行情、流动性枯竭 |
| 统计套利 | 配对/协整价差回归 | 天—周 | 中 | 中高 | 关系破裂、拥挤平仓 |
| 多因子选股 | 风险溢价与错误定价 | 周—月 | 高 | 低—中 | 因子失效、风格暴露 |
| 指数增强 | Beta + 可控跟踪误差下的 Alpha | 月—季 | 高 | 低 | 跟踪误差失控、基准风格 |
| CTA/期货 | 趋势、期限结构、套利 | 天—月 | 高（商品） | 中 | 杠杆、跳空、展期损失 |
| 市场中性 | 多空对冲后的 Alpha | 周—月 | 中高 | 中 | 对冲成本、基差、拥挤 |
| 事件驱动 | 并购、重组、财报、指数调整 | 天—周 | 低—中 | 高 | 事件失败、停牌、监管 |
| 高频做市 | 买卖价差 + 交易所返佣 | 毫秒—秒 | 低 | 极高 | 逆向选择、技术故障、监管 |
| 跨市场/期现套利 | 同一资产在不同市场的价差收敛 | 秒—天 | 中 | 高 | 基差扩大、交易限制、资金成本 |

同一类策略在不同市场的表现差异很大：A 股的动量偏弱、反转偏强，小市值因子在 2017 年后波动显著放大；美股的动量与质量因子历史更长、更稳定，但拥挤度也更高。**策略谱系是地图，不是保证书。**

### 收益拆解：Alpha、Beta、杠杆与容量

单因子市场模型把收益拆成三块：

```
R = α + β·R_m + ε

R    ：策略收益
R_m  ：市场（基准）收益
β    ：对市场的暴露
α    ：剔除市场后的超额收益
ε    ：特质收益/噪声
```

- **Beta 收益**：承担市场风险换来的补偿。β=1 时，市场涨 10%，策略大约也涨 10%，这部分不是能力。
- **Alpha 收益**：与市场无关的超额。市场跌 20% 时仍能取得正收益，才更接近真正的 Alpha。
- **ε**：不可解释的残差。短期看像 Alpha，长期看可能只是噪声。

评价时不能只看总收益，还要看风险调整后的指标：

```
Sharpe   = (R_p - R_f) / σ_p
IR       = α / σ(ε)          # 信息比率，衡量主动管理效率
```

杠杆会把收益和风险同时放大：

```
R_equity = L·R_strategy - (L-1)·r_f - 交易成本
```

L=3 时，策略亏 10%，自有资金亏约 30%；再叠加券商的平仓线，可能等不到策略修复就被强制卖出。**杠杆不创造 Alpha，只改变收益的分布形状。**

容量（capacity）是策略寿命的硬约束。规模越大，交易冲击越高，净 Alpha 越低：

```
净 Alpha(AUM) ≈ α_0 - c·(AUM / ADV)^0.5

AUM：管理规模
ADV：标的平均日成交额
c  ：与波动率、交易频率有关的系数
```

直觉是：规模翻 4 倍，冲击成本大约翻 2 倍（平方根关系）。所以一个在小资金下年化 20% 的策略，做到几十亿可能只剩个位数。**评估策略时，必须同时问「收益率多少」和「这个收益率能承载多大规模」。**

### 产业链与角色

| 角色 | 靠什么赚钱 | 与量化的关系 |
| --- | --- | --- |
| 卖方研究所 | 分仓佣金、服务费 | 提供研究、盈利预测、行业数据 |
| 公募基金 | 管理费 | 量化产品、指数增强、ETF |
| 私募基金 | 管理费 + 业绩报酬 | 量化选股、CTA、市场中性、高频 |
| 券商自营 | 自有资金投资收益 | 做市、套利、方向性策略 |
| 券商资管/理财 | 管理费、超额分成 | 量化配置、FOF/MOM |
| 做市商 | 买卖价差、返佣 | 提供流动性，依赖低延迟系统 |
| 券商经纪/托管 | 佣金、托管费、两融利息 | 交易通道、交易单元、托管估值 |
| 数据供应商 | 数据订阅费 | 行情、基本面、另类数据 |
| 交易终端/OMS/PMS | 软件订阅、实施费 | 下单、风控、组合管理、归因 |
| 交易所/登记结算 | 经手费、上市费 | 制定规则、撮合、清算交收 |

一个小型量化团队通常只做「因子 + 组合 + 执行」三件事，数据、通道、托管、清算全部外购。**不要把产业链上每一环都自己造，除非规模足以摊薄成本。**

### 从业能力模型

| 能力 | 具体内容 | 常见短板 |
| --- | --- | --- |
| 数理统计 | 回归、假设检验、时间序列、面板数据、多重检验 | 只会跑 IC，不懂显著性从哪来 |
| 编程工程 | Python/pandas/numpy、SQL、Linux、版本管理、回测框架 | 研究代码能跑，生产环境一并发就崩 |
| 市场微观结构 | 订单簿、撮合、涨跌停、T+1、交易成本、流动性 | 回测假设成交价，实盘买不到 |
| 风控合规 | 限额、杠杆、集中度、程序化交易报备、异常交易 | 只盯收益，不盯回撤和合规 |
| 心理与流程纪律 | 接受回撤、不临时改参数、按流程上线/下线 | 一亏就改模型，一赚就加杠杆 |

真正区分从业者的，往往不是「谁的因子更复杂」，而是**谁更清楚自己的策略在什么条件下会失效，以及失效时怎么活下来**。

## 实践：把一条规则跑成最小回测

下面用模拟价格跑一个 20/60 日均线策略。重点不是这条均线能不能赚钱，而是看清「信号 → 持仓 → 成本 → 评价」的闭环，以及**用昨日信号、今日执行**避免未来函数。

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 1000
rets = rng.normal(0.0003, 0.015, n)          # 日收益：微弱正漂移 + 1.5% 波动
price = pd.Series(100 * np.cumprod(1 + rets))

fast = price.rolling(20).mean()
slow = price.rolling(60).mean()
signal = (fast > slow).astype(int)           # 1=持有，0=空仓
pos = signal.shift(1).fillna(0)              # 昨日收盘出信号，今日才持仓

ret = price.pct_change().fillna(0)
turnover = pos.diff().abs().fillna(0)        # 仓位变化即换手
cost = turnover * 0.001                      # 单边 10bp 的粗略成本（佣金+冲击）
strat = pos * ret - cost

def perf(r, name):
    nav = (1 + r).cumprod()
    ann = nav.iloc[-1] ** (252 / len(r)) - 1
    vol = r.std() * np.sqrt(252)
    sharpe = ann / vol if vol else 0.0
    mdd = (nav / nav.cummax() - 1).min()
    print(f"{name}: 年化 {ann:.2%}, 波动 {vol:.2%}, "
          f"Sharpe {sharpe:.2f}, 最大回撤 {mdd:.2%}")

perf(ret, "买入持有")
perf(strat, "20/60 均线")
print(f"换手次数 {int(turnover.sum())}, 持仓占比 {pos.mean():.1%}")
```

这段代码只验证了三件事：信号是否按时执行、成本是否被计入、评价是否同时看收益/波动/回撤。它不能证明策略有效——模拟数据里的「规律」是人为设定的，真实市场没有这么听话。**回测的第一作用是排除明显不成立的想法，而不是给收益背书。**

## 常见误区与坑

| 误解 | 事实 |
| --- | --- |
| 量化 = 高频 | 高频只是量化的一个子集；大量量化产品是周/月频的多因子或指数增强 |
| 量化 = 稳赚 | 量化只是把决策系统化，因子会失效、模型会过拟合、杠杆会爆仓 |
| 回测好 = 实盘好 | 回测可以调参数、忽略成本、偷看未来；实盘有冲击、停牌、涨跌停和资金约束 |
| AI 万能 | 机器学习能找非线性关系，但样本少、噪声大、 regime 变化快，过拟合更隐蔽 |
| 无风险套利 | 价差收敛不是必然，资金成本、交易限制、挤兑都会让「无风险」变有风险 |
| 因子越多越好 | 因子越多，多重检验和过拟合风险越高；相关性高的因子只是重复计价 |
| 有 Alpha 就能做大 | 容量决定规模上限，冲击成本会把小资金的高收益打成平庸 |

## 合规与监管

程序化交易在 A 股是明确受监管的行为。中国证监会《证券市场程序化交易管理规定（试行）》于 2024 年 5 月发布、2024 年 10 月 8 日起施行；沪深北交易所的《程序化交易管理实施细则》于 2025 年发布、2025 年 7 月 7 日起施行。规则的核心方向可以概括为：

- **先报告、后交易**：程序化交易投资者需报告账户、资金、交易策略、最高申报速率、单日最高申报笔数、交易软件等信息，信息重大变更要及时更新。
- **高频交易差异化监管**：对高频交易在报告信息、收费、交易监控等方面提出更严格要求。
- **异常交易监控**：重点监控短时间内高频申报/撤单、大笔连续密集申报导致价格或成交量异常等行为。
- **机构责任**：证券公司对客户程序化交易负有核查和管理责任；机构需建立合规风控、系统安全、公平交易等内部制度。
- **禁止性行为**：不得利用程序化交易从事内幕交易、利用未公开信息交易、操纵市场等违法违规行为。

实务上至少准备四样东西：**交易报备材料、策略与参数变更记录、实时风控阈值、异常交易处置流程**。具体报备口径、高频认定标准和监控指标以证监会及交易所最新规则为准，不要照搬旧版本或海外经验。

## 从想法到上线：全景流程

```
想法 → 逻辑验证 → 数据可行性 → 快速原型 → 严格回测 → 样本外/滚动检验
                                                              │
    ┌─────────────────────────────────────────────────────────┘
    ▼
模拟盘 → 小资金实盘 → 逐步加仓 → 持续监控/归因 → 迭代或下线
```

| 阶段 | 通过标准 | 不通过就停 |
| --- | --- | --- |
| 想法 | 能用一句话说清赚谁的钱、为什么对方愿意亏 | 只有「历史涨得好」 |
| 数据 | 有 Point-in-Time 数据，覆盖足够长的样本 | 数据缺失严重、无法复权 |
| 回测 | 扣费后仍有超额，参数不敏感，分组单调 | 只有一组参数好看 |
| 样本外 | 滚动/走样本外不崩，多个市场/时段一致 | 一换时间段就失效 |
| 模拟盘 | 实盘行情下信号、成交、风控都正常 | 成交率、滑点与回测差距过大 |
| 小资金 | 实盘收益与模拟盘偏差可解释 | 连续偏离且找不到原因 |
| 规模化 | 冲击成本可控，容量测算支持目标规模 | 规模一加收益就消失 |

## 常见问题 Q&A

**Q：会 Python 就能做量化吗？**

A：Python 只是工具。能写代码不等于能提出可检验的假设、能识别过拟合、能理解交易规则。编程是入场券，统计判断和市场理解决定上限。

**Q：多少资金可以开始？**

A：个人可以用几万元做低频策略验证，但要注意最低佣金 5 元会显著抬高小资金成本；机构策略通常要千万级以上才能摊薄数据、系统和人员成本。资金量越小，越应该关注成本而不是追求高换手。

**Q：一个人能做量化吗？**

A：能做低频、容量不大的策略（多因子、ETF 轮动、简单 CTA），但很难同时覆盖数据、研究、交易、运维、合规。更现实的做法是把执行和托管外包，自己专注研究与组合。

**Q：量化一定要预测涨跌吗？**

A：不一定。有的策略赚价差收敛（套利）、有的赚流动性提供（做市）、有的赚风险溢价（价值/质量），它们不要求精确预测方向，但都要求对收益来源有清晰解释。

**Q：为什么量化私募的收益差别那么大？**

A：策略类型、容量、杠杆、费率、样本期、幸存者偏差都会造成差异。排名靠前的产品往往同时承担了更高的风格暴露或流动性风险，不能只看收益不看回撤和规模。

**Q：回测年化 50% 可信吗？**

A：先问四个问题：扣费了吗？用了未来数据吗？参数试了多少组？容量多大？如果答不上来，50% 大概率是过拟合或成本假设过于乐观。
