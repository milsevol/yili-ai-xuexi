# 03 数据与因子研究

## 一句话定位

因子研究是把一个可解释的市场规律压缩成一列可排序的数字，再用统计检验判断它是否真的能预测未来收益。数据质量决定研究的上限，因子逻辑决定它能不能活过样本外；两者缺一，回测结果都只是历史噪声的漂亮包装。

## 数据分类

| 类别 | 典型内容 | 频率 | 获取成本 | 主要坑 |
| --- | --- | --- | --- | --- |
| Tick/逐笔成交 | 每笔成交、逐笔委托、撤单 | 毫秒—秒 | 高（交易所授权/券商 Level-2） | 数据量巨大、订单簿重建复杂、供应商字段不一致 |
| L1 快照 | 最新价、买卖一档、累计成交量 | 约 3 秒 | 中 | 只有一档，估不出深度；快照之间可能漏单 |
| L2 快照/逐笔 | 十档盘口、逐笔委托与成交 | 3 秒/毫秒 | 高 | 授权贵、历史覆盖短、清洗规则多 |
| 分钟线 | OHLCV、成交额 | 1 分钟 | 低 | 集合竞价处理、复权、成交量单位 |
| 日线 | OHLCV、市值、换手率 | 日 | 低 | 停牌、ST、退市、复权 |
| 基本面 | 三张表、财务指标、公告 | 季度/事件 | 中 | Point-in-Time、追溯调整、口径差异 |
| 另类数据 | 新闻舆情、研报、卫星、招聘、ESG、电商 | 不定 | 高 | 覆盖率、稳定性、合规、噪声 |
| 宏观与行业 | GDP、CPI、利率、行业产量/价格 | 月/季 | 低 | 发布时滞、修订、口径变化 |

常见数据源包括 Wind、Choice、同花顺 iFinD、聚源、交易所 Level-2，以及开源的 akshare、tushare 等。工具不是关键，**关键是每类数据的可见时点、覆盖范围和清洗成本**。

## 数据质量与陷阱

### 复权

除权除息会让价格出现「假跳空」：10 送 10 后股价从 10 元变成 5 元，不是跌了 50%。不做复权，动量、波动率、均线全部失真。

| 方式 | 定义 | 适合 | 不适合 |
| --- | --- | --- | --- |
| 前复权 | 以最新价为基准，向前调整历史价格 | 看图形、技术分析、展示 | 需要稳定历史价格水平的计算；新除权后历史值会变 |
| 后复权 | 以上市首日为基准，向后调整最新价格 | 回测、长期收益、因子计算 | 直接对照真实成交价 |
| 不复权 | 原始成交价 | 涨跌停判断、最小变动价位、真实成交、成交额 | 跨除权日计算收益 |

简化公式：

```
除权参考价 ≈ (前收盘价 - 每股现金红利) / (1 + 送转比例)
后复权价 = 原始价 × 累计复权因子
前复权价 = 后复权价 / 最新累计复权因子
```

配股、拆股、合并等情形更复杂，实际以交易所和数据商的除权公式为准。还有一点常被忽略：**复权通常只调价格，不调成交量**。算换手率、成交额、Amihud 指标时，要用原始成交量/成交额，或者同步做反向调整。

### 停牌、ST、退市

- **停牌**：停牌期间没有成交，因子和收益的对齐要跳过；回测不能假设「想卖就能卖」，长期停牌复牌后往往补跌或补涨。
- **ST/*ST**：主板涨跌幅 ±5%，基本面恶化、流动性变差。股票池要不要包含 ST，必须在研究前写死；ST 状态是时变的，不能用今天的标记回填历史。
- **退市**：只保留当前仍上市的股票，会制造幸存者偏差。正确做法是保留退市股票，按最后交易日价格清算，并把退市整理期的极端跌幅计入。
- **新股**：上市初期换手极高、波动大，部分板块前几日无涨跌幅限制；通常剔除上市前 N 个交易日的样本，规则要固定。
- **代码变更/并购/更名**：用稳定的证券 ID 对齐，不要用会复用的股票代码做主键。

### Point-in-Time：公告日不是报告期

财报的数据属于「报告期」，但只有「公告日」之后才可见。用报告期直接对齐，会提前几周甚至几个月知道业绩，这是最典型的未来函数。

```
报告期 03-31 ───── 公告日 04-28 ───── 信号可用 04-29
   数据所属期            信息可见时点          可交易时点
```

| 数据 | 报告期 | 公告日 | 最早可用 |
| --- | --- | --- | --- |
| 2023 年一季报 | 2023-03-31 | 2023-04-28 | 2023-04-29 |
| 2023 年年报 | 2023-12-31 | 2024-04-25 | 2024-04-26 |
| 宏观月度数据 | 2024 年 3 月 | 2024-04-15 左右 | 发布日之后 |

还要注意财报的**追溯调整与重述**：后来修订过的财务数据不能回填到当时，否则等于用了未来版本。分析师预期同理，要用预期发布日，而不是报告截止日。

### 数据对齐

- **交易日历**：A 股、港股、美股假期不同，必须用交易日索引，不能用自然日 `reindex` 后再前填。
- **时区**：A 股 UTC+8，美股 UTC-5/-4，跨市场因子统一到 UTC 再对齐。
- **缺失值**：区分「停牌」「未上市」「数据缺失」。行情缺失不要随意前值填充；基本面缺失可以用行业中位数，但要保留缺失标记。
- **股票池**：指数成分股是时变的，用今天的沪深 300 成分回测 2015 年，会系统性高估收益。

## 因子研究流程

```
原始数据 → 清洗 → 去极值 → 缺失值处理 → 标准化 → 中性化 → 因子值 → 评价
             │        │            │           │          │
           停牌/ST  MAD/缩尾    行业中位数    Z-score   行业/市值回归
```

| 步骤 | 常用方法 | 注意点 |
| --- | --- | --- |
| 清洗 | 剔除停牌、ST、上市不足 N 日、异常价格 | 规则在样本外保持不变 |
| 去极值 | MAD 法、1%/99% 缩尾 | 不要用均值 ±3σ，极值会污染均值和标准差 |
| 缺失值 | 保留 NaN、行业中位数填充、前值填充 | 前值填充只适合低频基本面，不适合行情 |
| 标准化 | Z-score、排序百分位、rank | 极值多时用 rank 更稳健 |
| 中性化 | 对行业哑变量、log 市值回归取残差 | 行业分类也要用当时的版本 |

MAD 去极值的写法：

```
med = median(x)
mad = median(|x - med|)
上下界 = med ± n × 1.4826 × mad      # n 常取 3—5
```

行业中性化就是做一次横截面回归，把行业解释不了的部分留下来：

```
x = X·β + ε
β = (X'X)^(-1)·X'x
factor_neutral = ε
```

X 里放行业哑变量（必要时加 log 市值），ε 就是剔除行业/市值暴露后的因子值。**中性化不是越多越好**：如果因子逻辑本身就是行业轮动，做行业中性化会把 Alpha 一起删掉。

## 因子分类与经济学解释

| 大类 | 代表因子 | 经济学直觉 | 失效场景 |
| --- | --- | --- | --- |
| 价值 | EP（1/PE）、BP（1/PB）、CFP、股息率 | 低估值补偿基本面风险或过度悲观 | 价值陷阱、成长风格极致、会计质量差 |
| 成长 | 营收增速、净利润增速、分析师上调 | 景气度上行、盈利加速 | 高估值透支、财务造假、基数效应 |
| 质量 | ROE、毛利率、应计利润、现金流/利润 | 盈利能力可持续、应计项目质量高 | 周期顶部、杠杆失真、行业差异 |
| 动量 | 20/60/120 日收益 | 信息扩散慢、处置效应、趋势延续 | 震荡市、反转、动量崩溃 |
| 反转 | 1—5 日收益 | 流动性冲击后的过度反应修复 | 强趋势、低流动性小盘股 |
| 波动率 | 历史波动率、特质波动率、Beta | 低波动异象、投资者偏好彩票型股票 | 牛市高波占优、杠杆约束变化 |
| 流动性 | 换手率、Amihud、成交额 | 流动性溢价、交易拥挤 | 小盘/情绪行情、注册制改革 |
| 规模 | 总市值、流通市值 | 小盘溢价、覆盖不足 | 2017 年后 A 股小盘因子波动显著放大 |
| 情绪/资金流 | 北向资金、融资余额、新闻情感、龙虎榜 | 注意力与资金驱动 | 数据噪声、监管变化、拥挤反转 |

A 股有一些本地化特征：短期反转、换手率、小市值、北向持股、融资余额、分析师覆盖在历史上都出现过阶段性效果。但**阶段性有效不等于长期有效**，尤其要警惕制度变化（注册制、退市改革、涨跌幅调整）带来的结构断裂。

## 因子评价

最常用的三个指标：

```
IC_t     = Pearson(f_{i,t}, r_{i,t+1})      # 截面相关
RankIC_t = Spearman(f_{i,t}, r_{i,t+1})     # 排序相关，抗极值
ICIR     = mean(IC_t) / std(IC_t)
t 值     = ICIR × sqrt(T)
```

| 指标 | 看什么 | 经验判断 |
| --- | --- | --- |
| IC / RankIC 均值 | 预测方向与强度 | 日频 \|IC\| 0.03—0.10 已可能有价值，>0.1 要排查泄漏 |
| ICIR | 稳定性 | 未年化 >0.2—0.3、年化 >0.5 更可信 |
| t 值 | 统计显著性 | 绝对值 >2 是起点，不是终点 |
| IC 衰减 | 信号能活多久 | 半衰期决定调仓频率 |
| 分组收益 | 单调性 | 5/10 组从低到高应大致单调 |
| 换手率 | 可交易性 | 高 IC + 高换手可能被成本吃光 |
| 拥挤度 | 是否已被人群交易 | 因子多头估值高、成交占比高时警惕反转 |

IC 的经验区间不能绝对化：月频因子的 IC 通常高于日频，小样本的 IC 波动更大，不同股票池的可比性也有限。**一个因子能不能用，最终要看扣费后的多空/多头收益、容量和样本外稳定性，而不是单独一个 IC 数字。**

分组回测的做法是每个截面按因子值排序分成 5 组或 10 组，观察每组下一期平均收益是否单调，以及最高组减最低组的多空收益。A 股融券成本高、券源有限，多空回测的收益往往不能直接当成可实现收益，纯多头组合更接近实际产品。

## 多因子合成

| 方法 | 权重 | 优点 | 风险 |
| --- | --- | --- | --- |
| 等权打分 | 标准化后取平均 | 简单、稳健、不易过拟合 | 忽略因子质量差异 |
| IC 加权 | `w_k = IC_k / Σ\|IC_k\|` | 让近期更有效的因子占更大权重 | IC 估计噪声大、容易追涨杀跌 |
| 最大化 ICIR | `w ∝ Σ^(-1)·μ` | 考虑因子相关性与稳定性 | 协方差估计不稳，需收缩和约束 |
| 机器学习 | 模型学习非线性与交互 | 能捕捉复杂关系 | 过拟合、可解释性差、样本要求高 |

IC 加权和均值-方差优化的公式：

```
IC 加权：score_i = Σ_k w_k · z_{i,k},  w_k = IC_k / Σ_j |IC_j|
最大化 ICIR：max_w  (w'μ) / sqrt(w'Σw)  ⇒  w ∝ Σ^(-1) μ

μ：各因子 IC 均值向量
Σ：各因子 IC 协方差矩阵
```

合成之后仍要做中性化、分组检验、换手率测算和成本评估。因子数量增加会带来多重检验问题：试了 100 个因子，总有几个「显著」是运气。**先有逻辑，再看统计；先做样本外，再谈上线。**

## 实践：从面板数据到 RankIC 与分层收益

下面构造 500 只股票 × 250 个交易日的模拟面板，计算 20 日动量因子，评估 RankIC、ICIR 和 5 分组收益。数据是人为生成的，重点看流程和指标口径。

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(2024)
n_stocks, n_days, n_ind = 500, 250, 10

dates = pd.bdate_range("2023-01-02", periods=n_days)
codes = np.array([f"S{i:04d}" for i in range(n_stocks)])
industry = rng.integers(0, n_ind, n_stocks)

# 行业共同收益 + 个股特质收益
ind_ret = rng.normal(0.0002, 0.010, size=(n_days, n_ind))
idio = rng.normal(0.0, 0.018, size=(n_days, n_stocks))
rets = ind_ret[:, industry] + idio

# 注入弱动量：过去 20 日收益越高，当日收益略高（仅用于演示）
for t in range(20, n_days):
    past = np.prod(1 + rets[t - 20:t], axis=0) - 1
    z = (past - past.mean()) / past.std()
    rets[t] += 0.0006 * z

prices = 10 * np.cumprod(1 + rets, axis=0)
px = pd.DataFrame(prices, index=dates, columns=codes)

mom20 = px.pct_change(20)          # t 日收盘后可用的 20 日动量
fwd1 = px.pct_change().shift(-1)   # t → t+1 的下一期收益

# 先横截面排秩再算 Pearson，等价于 Spearman，且不依赖 scipy
rank_ic = mom20.rank(axis=1).corrwith(fwd1.rank(axis=1), axis=1).dropna()
print(f"RankIC 均值 {rank_ic.mean():.4f}，标准差 {rank_ic.std():.4f}")
print(f"ICIR（未年化）{rank_ic.mean() / rank_ic.std():.4f}")
print(f"ICIR（年化）{rank_ic.mean() / rank_ic.std() * np.sqrt(252):.2f}")
print(f"IC>0 占比 {(rank_ic > 0).mean():.1%}，"
      f"t 值 {rank_ic.mean() / rank_ic.std() * np.sqrt(len(rank_ic)):.2f}")

# 每日按因子值分 5 组，统计各组下一期平均收益
rows = []
for dt in dates:
    df = pd.concat([mom20.loc[dt].rename("factor"),
                    fwd1.loc[dt].rename("fwd")], axis=1).dropna()
    if len(df) < 100:
        continue
    df["group"] = pd.qcut(df["factor"].rank(method="first"), 5, labels=False)
    rows.append(df.groupby("group")["fwd"].mean())

grp = pd.DataFrame(rows).mean()
grp.index = [f"G{i + 1}" for i in grp.index]
print((grp * 100).round(3).to_string())
print(f"多空 G5-G1：{(grp.iloc[-1] - grp.iloc[0]) * 100:.3f}% / 日")
```

这段代码做了三件关键的事：因子只用截至 t 日的数据；收益用 t→t+1；分组在每个截面内独立做。任何一处改成「用当日收益」或「全样本统一分组」，都会产生未来函数或信息泄漏。

## 实践：去极值、标准化与行业中性化

接着取某个交易日的截面，演示从原始因子到中性化因子的完整处理。

```python
def mad_winsorize(s, n=5):
    """MAD 去极值：中位数 ± n × 1.4826 × MAD。"""
    med = s.median()
    mad = (s - med).abs().median()
    if mad == 0 or np.isnan(mad):
        return s
    scale = 1.4826 * mad
    return s.clip(med - n * scale, med + n * scale)

def zscore(s):
    """横截面 Z-score。"""
    return (s - s.mean()) / s.std(ddof=0)

dt = dates[150]
f = mom20.loc[dt].dropna()
f_z = zscore(mad_winsorize(f))

# 行业哑变量回归，取残差作为行业中性化因子
ind = pd.Series(industry, index=codes).reindex(f_z.index)
X = pd.get_dummies(ind, drop_first=True, dtype=float)
X.insert(0, "const", 1.0)
beta, *_ = np.linalg.lstsq(X.values, f_z.values, rcond=None)
f_neu = pd.Series(f_z.values - X.values @ beta, index=f_z.index)

print(f"截面股票数 {len(f_z)}，行业数 {ind.nunique()}")
print(f"中性化前 行业均值最大绝对值 {f_z.groupby(ind).mean().abs().max():.4f}")
print(f"中性化后 行业均值最大绝对值 {f_neu.groupby(ind).mean().abs().max():.6f}")
print(f"中性化前后相关系数 {f_z.corr(f_neu):.4f}")
```

如果还要做市值中性化，把 `log(流通市值)` 作为一列加进 X 即可。顺序上通常先去极值、再标准化、再中性化；中性化之后可以再标准化一次，方便后续等权合成。

## 常见误区与坑

| 误区 | 后果 | 正确做法 |
| --- | --- | --- |
| 用当日收盘价算因子，又用当日收益做检验 | 因子和收益重叠，IC 虚高 | 因子截至 t，收益用 t→t+1 |
| 财报按报告期对齐 | 提前知道业绩，未来函数 | 按公告日/最早可用日对齐 |
| 全样本去极值、标准化 | 用到了未来截面的均值和标准差 | 每个截面独立处理，训练期参数固化 |
| 用当前指数成分股回测历史 | 幸存者偏差，收益虚高 | 使用时变成分股或全市场股票池 |
| 用复权价判断涨跌停、成交价 | 价格水平失真，成交假设错误 | 涨跌停/成交用不复权价，收益用复权价 |
| 因子在牛市有效就认为长期有效 | 把风格 Beta 当成 Alpha | 分市场状态、分样本期检验，看样本外 |
| 只看 IC，不看换手和容量 | 高 IC 被成本吃光 | IC + ICIR + 分组 + 换手 + 冲击成本一起看 |
| 因子越多越好 | 多重检验、过拟合、拥挤 | 控制因子数量，做相关性剔除和样本外验证 |
| 用最新行业分类回填历史 | 行业暴露失真 | 使用当时的行业分类版本 |

## 常见问题 Q&A

**Q：免费数据能做因子研究吗？**

A：能。日线、财报、指数成分股足够验证大部分低频逻辑。但免费数据的复权、退市股覆盖、公告日字段和历史稳定性往往不完整，适合做研究原型，不适合直接上生产。生产环境至少要保证 Point-in-Time 和退市样本。

**Q：IC 多少算好？**

A：日频因子 |IC| 0.03—0.05 已经可能有价值，0.05—0.10 算较好，超过 0.1 要优先怀疑数据泄漏或极值处理问题。月频 IC 通常更高。最终要结合 ICIR、t 值、分组单调性、换手率和扣费后收益判断，不能用一个阈值一刀切。

**Q：为什么 RankIC 和 Pearson IC 差很多？**

A：Pearson IC 对极端值敏感，RankIC 只看排序。差异大通常说明因子分布有厚尾、异常值，或者因子与收益是非线性关系。先检查去极值和数据错误，再决定用哪个口径。

**Q：行业中性化会不会把 Alpha 去掉？**

A：会去掉行业配置带来的收益，保留行业内选股的超额。如果策略的核心就是行业轮动，不该做行业中性化；如果目标是纯选股 Alpha，中性化能降低行业暴露和回撤的偶然性。两种做法对应两种产品定位。

**Q：因子换手率太高怎么办？**

A：可以平滑因子（如 5 日移动平均）、降低调仓频率、在组合优化里加换手惩罚，或设置换手约束。核心是算清楚「多赚的 IC」能不能覆盖「多付的成本」；覆盖不了就降频。

**Q：因子失效了怎么办？**

A：先区分正常回撤和逻辑失效。看滚动 IC、分组单调性、因子拥挤度、制度环境有没有变化。如果只是短期回撤，按预设风控降权；如果经济学逻辑被破坏（比如制度变化让某类股票不再存在），应当下线，而不是不断加参数救活它。
