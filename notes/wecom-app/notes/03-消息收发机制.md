# 03 消息收发机制

## 一句话

企微消息分两种：**接收**（用户发给你的应用或群聊中 @应用）和**发送**（你主动推送消息给员工/客户）。回调 URL 是接收的入口，应用消息 API 是发送的通道。

## 消息类型全景

```
消息流 ────────────────────────────────────────────────┐
                                                        │
    用户发送消息                          企业微信服务器    │
    (聊天/群聊@应用)                        │              │
                                            ▼              │
                                    POST 回调 URL          │
                                    (XML 或 JSON)          │
                                            │              │
                       ┌───────────────────┤              │
                       ▼                   ▼              │
                  被动回复消息          事件通知            │
                  (在 5 秒内响应)     (审批/打卡/...)      │
                       │                   │              │
                       ▼                   ▼              │
                   你的后端处理逻辑                        │
                       │                                  │
                       ▼                                  │
           主动推送消息 API                                │
           (24 小时内可推)  ←──────────────────────────────┘
```

## 接收消息：回调处理

### 1. 企微推送的消息格式

企微会向你配置的回调 URL POST XML 或 JSON（安全模式是加密的）：

```xml
<!-- 用户发文本消息 -->
<xml>
  <ToUserName><![CDATA[企业ID]]></ToUserName>
  <AgentID>1000002</AgentID>
  <FromUserName><![CDATA[用户UserID]]></FromUserName>
  <MsgType><![CDATA[text]]></MsgType>
  <Content><![CDATA[你好]]></Content>
  <MsgId>12345678901234567890</MsgId>
  <CreateTime>1348831860</CreateTime>
</xml>
```

### 2. 消息类型一览

| MsgType | 说明 | 关键字段 |
| --- | --- | --- |
| text | 文本消息 | Content |
| image | 图片 | MediaId, PicUrl |
| voice | 语音 | MediaId, Format |
| video | 视频 | MediaId |
| event | 事件通知（审批/打卡/关注） | Event, EventKey |
| card | 企业微信卡片消息（回调发送） | — |

### 3. Python 处理回调的完整示例

```python
from flask import Flask, request, make_response
import hashlib, xml.etree.ElementTree as ET, time, json

app = Flask(__name__)

TOKEN = "your_callback_token"
ENCODING_AES_KEY = "your_43_char_key"

@app.route('/api/wecom/callback', methods=['GET', 'POST'])
def wecom_callback():
    if request.method == 'GET':
        # 回调 URL 验证（见第 02 章）
        msg_signature = request.args.get('msg_signature')
        timestamp = request.args.get('timestamp')
        nonce = request.args.get('nonce')
        echostr = request.args.get('echostr')
        # ... 验签 + 解密 echostr ...
        return echostr  # 简单起见
    else:
        # 接收消息
        body = request.data
        msg_signature = request.args.get('msg_signature')
        timestamp = request.args.get('timestamp')
        nonce = request.args.get('nonce')

        # 安全模式：验签 + 解密 body
        # ...

        # 解析 XML
        root = ET.fromstring(body)
        msg_type = root.find('MsgType').text
        from_user = root.find('FromUserName').text

        if msg_type == 'text':
            content = root.find('Content').text
            reply = handle_text(from_user, content)
            return make_response(reply)
        elif msg_type == 'event':
            event = root.find('Event').text
            handle_event(from_user, event, root)
            # 事件不需要回复
            return make_response('success')

def handle_text(userid, content):
    # 业务逻辑
    if content == 'help':
        return reply_text_xml(userid, "可用命令：help, status, report")
    elif content == 'status':
        return reply_text_xml(userid, "系统运行正常 ✓")
    else:
        return reply_text_xml(userid, f"收到: {content}")

def reply_text_xml(userid, content):
    return f"""<xml>
  <ToUserName><![CDATA[{userid}]]></ToUserName>
  <FromUserName><![CDATA[SYSTEM]]></FromUserName>
  <CreateTime>{int(time.time())}</CreateTime>
  <MsgType><![CDATA[text]]></MsgType>
  <Content><![CDATA[{content}]]></Content>
</xml>"""

if __name__ == '__main__':
    app.run(port=8080)
```

## 事件回调：除了消息还有什么

事件是企微主动通知你发生了某件事，常见事件类型：

| Event | 触发时机 | 说明 |
| --- | --- | --- |
| enter_agent | 用户进入应用 | 员工点工作台图标进入 |
| click | 点击应用菜单 | 底部菜单被点 |
| job_expired | 客户联系离职 | 绑定的员工离职 |
| change_contact | 客户变更 | 客户信息更新 |
| approval | 审批通过/驳回 | 审批流结束 |
| check_in | 打卡事件 | 员工打卡 |
| add_external_contact | 添加客户 | 员工新增客户 |

## 发送消息：主动推送

### 1. 应用消息（最常用）

给应用可见范围内的员工推送：

```bash
POST https://qyapi.weixin.qq.com/cgi-bin/message/send
  ?access_token=YOUR_TOKEN

{
  "touser": "UserID1|UserID2",
  "msgtype": "text",
  "agentid": 1000002,
  "text": {
    "content": "你好，这是一条应用消息"
  },
  "safe": 0
}
```

**关键限制**：
- 24 小时内最多主动推送 200 次/人
- 超过限制需要用户主动触发（进入应用或发消息）

### 2. 消息类型参数一览

| msgtype | 结构 | 适用场景 |
| --- | --- | --- |
| text | `{"content": "..."}` | 纯文本通知 |
| textcard | `{"title", "description", "url"}` | 带跳转链接的卡片 |
| markdown | `{"content": "### 标题\n内容"}` | 富文本（企微客户端支持） |
| news | `{"articles": [{"title", "description", "picurl", "url"}]}` | 图文消息 |
| file/image/video | `{"media_id": "..."}` | 先上传素材再发送 |

### 3. 卡片消息（交互性最强）

```json
{
  "touser": "UserID1",
  "msgtype": "textcard",
  "agentid": 1000002,
  "textcard": {
    "title": "📊 每日日报",
    "description": "2024-01-15\n营收 125 万 | 增长 +12%\n新客户 23 个",
    "url": "https://yourdomain.com/report/today"
  }
}
```

### 4. Python 封装

```python
class WeComMessenger:
    BASE = "https://qyapi.weixin.qq.com/cgi-bin"

    def __init__(self, token_mgr, agentid):
        self.token_mgr = token_mgr
        self.agentid = agentid

    def send_text(self, userid, content):
        return self._send({
            "touser": userid,
            "msgtype": "text",
            "agentid": self.agentid,
            "text": {"content": content}
        })

    def send_card(self, userid, title, desc, url):
        return self._send({
            "touser": userid,
            "msgtype": "textcard",
            "agentid": self.agentid,
            "textcard": {
                "title": title,
                "description": desc,
                "url": url
            }
        })

    def _send(self, data):
        token = self.token_mgr.get_token()
        resp = requests.post(
            f"{self.BASE}/message/send?access_token={token}",
            json=data
        ).json()
        if resp.get('errcode') != 0:
            raise Exception(f"发送失败: {resp}")
        return resp
```

## 频控与限流

| 接口 | 频控 | 说明 |
| --- | --- | --- |
| gettoken | 2000 次/天 | 每天最多 2000 次 |
| 应用消息发送 | 200 次/人/天 | 主动推送限制 |
| 消息回调 | 每条 | 超时 5 秒后企微重试 3 次 |
| 其他 API | 约 100 次/分钟 | 具体看官方文档 |

## 常见坑

| 坑 | 解决方案 |
| --- | --- |
| 回调超时 5 秒 | 同步处理不了就先回 'success'，异步处理 |
| 消息推送到用户但对方收不到 | 检查应用可见范围 + 24 小时限制 |
| access_token 失效 | 每次调用前检查或用缓存管理 |
| 加密解密错 | Token 和 EncodingAESKey 是两个不同的东西 |
| 回调 POST body 是空的 | 企微加密模式下 body 是 XML 格式（Encrypt 字段包密文） |
