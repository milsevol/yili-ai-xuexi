# 04 客户联系与客户群

## 一句话

客户联系是企微最值钱的功能：把企业员工和外部客户（普通微信用户）绑定在一起，客户关系归企业所有，员工离职不会带走。客户群让多个员工一起服务一群客户。

## 核心概念

```
企业微信
  │
  ├── 成员（员工 UserID）     ← 内部身份
  │     │
  │     │ 客户联系（双向绑定）
  │     ▼
  ├── 外部联系人（客户 ExternalUserID）  ← 客户身份
  │     │
  │     │ 可加入
  │     ▼
  └── 客户群（ChatID）  ← 多个员工 + 多个客户
```

| 概念 | 说明 | 标识 |
| --- | --- | --- |
| **成员** | 企业内部员工 | UserID（企业内唯一） |
| **外部联系人** | 企业的客户（可绑定多个成员） | ExternalUserID |
| **客户群** | 企业组建的群聊（成员 + 客户） | ChatID |
| **群主** | 客户群的创建者（必须是企业成员） | — |
| **客户标签** | 给客户打标签，用于分群运营 | TagID |

## 第一步：开通客户联系功能

管理后台 → 「应用管理」→ 「客户联系」→ 「开启」：

- 需要「客户联系」权限（默认给管理员和部分成员）
- 开启后，员工可以添加外部微信用户为客户
- 客户联系有独立的 Secret（在「客户联系」权限配置里获取）

> ⚠️ **关键**：客户联系的 Secret 和自建应用的 Secret 不同，获取 access_token 时用哪个 Secret 决定了能调哪些 API。

### 3. 编辑客户标签

```bash
# 创建标签组 + 标签
POST https://qyapi.weixin.qq.com/cgi-bin/externalcontact/add_tag
  ?access_token=TOKEN

{
  "tag": {
    "group_name": "客户分层",
    "tag_name": ["VIP", "潜力", "一般"]
  }
}

# 给客户打标签
POST https://qyapi.weixin.qq.com/cgi-bin/externalcontact/mark_tag
  ?access_token=TOKEN

{
  "userid": "UserID1",
  "external_userid": "woAJ2GCAAA...",
  "add_tag": ["tagid1", "tagid2"],
  "remove_tag": ["tagid3"]
}
```

### 4. 获取成员添加的客户统计

```bash
  ?access_token=TOKEN
# 返回可以使用客户联系功能的成员列表
```

## 客户群管理 API

### 1. 获取客户群列表

```bash
POST https://qyapi.weixin.qq.com/cgi-bin/externalcontact/groupchat/list
  ?access_token=TOKEN

{
  "status_filter": 0,        # 0=全部，1=已跟进，2=待跟进
  "owner_userid_list": ["UserID1", "UserID2"],
  "limit": 100
}

# 返回
{
  "group_list": [
    {
      "chat_id": "wrOgQhDgAAxSRM2uvh7rM",
      "name": "2024 VIP 客户群",
      "owner": "UserID1",
      "member_count": 15,
      "external_member_count": 12
    }
  ]
}
```

### 2. 获取客户群详情

```bash
POST https://qyapi.weixin.qq.com/cgi-bin/externalcontact/groupchat/get
  ?access_token=TOKEN

{
  "chat_id": "wrOgQhDgAAxSRM2uvh7rM",
  "need_name": 1
}

# 返回完整成员列表（内部成员 + 外部客户）
```

## 离职继承：客户不流失

**这是企微客户联系最核心的价值**：

### 1. 离职分配（手动/自动）

管理后台 → 「客户联系」→ 「离职继承」：
- 成员离职时，他的客户和客户群可以一键分配给其他成员
- 支持设置自动分配规则

### 2. API 调用

```bash
# 离职分配客户
POST https://qyapi.weixin.qq.com/cgi-bin/externalcontact/resigned/transfer_customer
  ?access_token=TOKEN

{
  "handover_userid": "离职员工UserID",
  "takeover_userid": "接管员工UserID",
  "external_userid": ["客户1", "客户2", "..."]
}
```

### 3. 离职分配客户群

```bash
POST https://qyapi.weixin.qq.com/cgi-bin/externalcontact/resigned/transfer_groupchat
  ?access_token=TOKEN

{
  "chat_id_list": ["群1", "群2"],
  "new_owner": "接管员工UserID"
}
```

## SCRM 场景：客户联系能做什么

### 场景 1：客户分级自动打标

```
新客户添加员工时
    │
    ▼
企微推送 change_contact 事件
    │
    ▼
你的后端收到事件，判断客户来源渠道
    │
    ▼
调用 mark_tag API 自动打标签（来源渠道 / 意向等级）
```

### 场景 2：客户流失预警

```python
# 每天定时拉取所有客户
# 对比 30 天前，看看哪些客户的 follow_info.createtime 很早但最近没互动
# 标记为"沉睡客户"
# 自动分配给客户经理跟进
```

### 场景 3：客户群运营

```
客户群有新成员加入
    │
    ▼
你的后端收到 groupchat.event 事件
    │
    ▼
自动推送欢迎语 + 新人红包链接
    │
    ▼
定时推送群内活跃度报告给群主
```

### 场景 4：离职自动交接

```
员工发起离职审批 → 审批通过 → 触发回调
    │
    ▼
你的后端批量拉取该员工的所有客户和客户群
    │
    ▼
根据预设分配规则（按部门/按标签）自动分配给同事
    │
    ▼
推送通知给接手员工和客户
```

## 频率限制

| API | 频率 | 说明 |
| --- | --- | --- |
| get_externalcontact | 10000 次/分钟 | 获取单个客户 |
| batch_get_by_user | 100 次/分钟 | 批量获取客户列表 |
| groupchat.list | 100 次/分钟 | 客户群列表 |
| transfer_customer | 5000 次/天 | 离职分配 |
