# 09 企业内部实战案例

## 一句话

把前面 01-08 章学的东西串起来，完整走一遍「从需求到上线」的实战：给销售团队做一个「客户跟进助手」——侧边栏看客户资料、审批里做客户录入、消息推送做跟进提醒。

## 需求背景

> **客户跟进助手**：销售团队 30 人，管理 500+ 外部客户，痛点是：
> 1. 客户资料散在 Excel 和 CRM，聊天时查不到
> 2. 新客户录入要走审批，流程慢
> 3. 客户沉睡了没人跟进，容易流失

## 实战 1：侧边栏 CRM

这是高频场景——销售和客户聊天时，右边自动弹出客户卡片：

### 1. 配置侧边栏 URL

```
应用详情 → 客户联系 → 客户信息栏

侧边栏 URL: https://crm.yourcompany.com/sidebar/customer
            ?external_userid={external_userid}
            &userid={userid}
```

### 2. 后端侧边栏 API

```python
@app.get('/api/sidebar/customer')
def sidebar_customer():
    external_userid = request.args.get('external_userid')
    userid = request.args.get('userid')

    # 1. 从企微 API 拿客户基础信息
    token = token_mgr.get_token()
    cust = requests.get(
        'https://qyapi.weixin.qq.com/cgi-bin/externalcontact/get',
        params={'access_token': token, 'external_userid': external_userid}
    ).json()

    # 2. 从自家数据库拿跟进历史、订单、标签
    local_data = db.query_customer_records(external_userid)

    return jsonify({
        'name': cust.get('name'),
        'avatar': cust.get('avatar'),
        'tags': cust.get('tag_list'),
        'follow_records': local_data['records'],
        'last_order': local_data['last_order'],
        'is_asleep': local_data['last_contact_days'] > 30,
    })
```

### 3. 侧边栏 H5 前端


## 实战 2：新客户录入审批流

销售添加了新客户后，需要走审批才能正式进入客户库：

### 1. 审批模板配置

- **模板名**：新客户录入审批
- **审批人**：直属经理 → 销售总监
- **表单控件**：客户名称、行业、预估金额、来源渠道、客户联系人

### 2. 审批回调处理

```python
def handle_approval_event(root):
    approval_id = root.find('ApprovalCode').text
    status = root.find('SpStatus').text

    if status != '2':  # 只关心通过
        return

    # 拉审批详情
    detail = get_approval_detail(approval_id)
    applyer = detail['applyerid']

    # 从审批表单解析客户信息
    customer_data = parse_approval_form(detail['component'])

    # 1. 插入自家数据库
    customer_id = db.insert_customer(customer_data)

    # 2. 企微里给这个客户自动打标签
    #    （客户联系 API）
    tag_token = customer_token_mgr.get_token()
    requests.post(
        'https://qyapi.weixin.qq.com/cgi-bin/externalcontact/mark_tag',
        params={'access_token': tag_token},
        json={
            'userid': applyer,
            'external_userid': customer_data['external_userid'],
            'add_tag': ['新客户', customer_data['industry']]
        }
    )

    # 3. 给销售推送通知
    messenger.send_text(applyer,
        f"✅ 客户 {customer_data['name']} 已正式入库！ID: {customer_id}")
```

## 实战 3：沉睡客户自动提醒

每天凌晨定时任务扫描，对超过 30 天没跟进的客户推送提醒：

```python
# 定时任务（每天 08:00 跑）
@app.cli.command('check-sleep-customers')
def check_sleep():
    # 1. 查所有 30 天未跟进的客户
    sleepers = db.query_sleep_customers(days=30)

    # 2. 按负责人分组推送
    for owner_userid, customers in group_by(sleepers, 'owner'):
        if not customers:
            continue

        # 3. 用卡片消息推给对应销售
        card_desc = '\n'.join(
            f"• {c['name']}（最近跟进: {c['last_follow']}）"
            for c in customers[:5]
        )

        messenger.send_card(
            userid=owner_userid,
            title=f"🔔 你有 {len(customers)} 个沉睡客户",
            description=card_desc,
            url="https://crm.yourcompany.com/sleep/customers"
        )

        # 4. 给部门总监汇总
        messenger.send_card(
            userid=get_manager(owner_userid),
            title=f"📊 团队沉睡客户提醒",
            description=f"{owner_userid} 有 {len(customers)} 个沉睡客户",
            url="https://crm.yourcompany.com/report/sleep"
        )
```

```javascript
async function askAI(customerQuestion) {
  const resp = await fetch('/api/ai/suggest', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({
      external_userid,
      question: customerQuestion,
      context: custProfile  // 客户画像：行业、历史、偏好
    })
  })

  const result = await resp.json()
  // result = { suggestion: '建议您这样说...', confidence: 0.92 }
```

```python
# 后端：调大模型生成话术建议
@app.post('/api/ai/suggest')
def ai_suggest():
```
