# 02 应用注册与配置

## 一句话

在企微管理后台创建自建应用，拿到 CorpID / AgentID / Secret 三要素，配置好回调 URL、消息接收与菜单，就能开始调 API 了。

## 前置条件

- 已注册企业微信（https://work.weixin.qq.com/ ，个人也可注册试用）
- 有一个公网可访问的服务器（回调 URL 需要 HTTPS）
- 或使用内网穿透工具（ngrok、cpolar）做本地开发

## 第一步：获取 CorpID

1. 登录企业微信管理后台 → https://work.weixin.qq.com/wework_admin/frame
2. 点击左下角「我的企业」
3. 在「企业信息」页面找到「企业ID」（就是 CorpID）
4. **注意**：CorpID 是企业级别的，所有自建应用共用同一个

## 第二步：创建自建应用

1. 管理后台 → 「应用管理」→「自建」→ 「创建应用」
2. 填写应用信息：
   - **应用名称**：内部员工可见，比如「报销助手」
   - **应用 logo**：256×256 PNG
   - **可见范围**：哪些部门/成员能看到这个应用（很重要！）
3. 创建完成后，应用详情页能看到：
   - **AgentID**：应用唯一编号（每个应用不同）
   - **Secret**：应用密钥（点击「查看」需要管理员扫码）

> ⚠️ **Secret 安全提示**：Secret 相当于应用的密码，绝对不能提交到 Git、前端代码里。后端存环境变量或密钥管理服务。

## 第三步：配置回调 URL（消息接收必备）

企微需要把用户消息、审批事件等推送到你的服务器，你需要提供一个回调 URL。

### 1. 在管理后台配置

应用详情页 → 「接收消息」→「设置API接收」：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| **URL** | 你的后端接收回调的 HTTPS 地址 | `https://yourdomain.com/api/wecom/callback` |
| **Token** | 自定义字符串，用于签名校验 | `wecom_callback_token_xxx` |
| **EncodingAESKey** | 随机生成，用于消息加解密 | 43 位字符串 |

### 2. 验证回调 URL

配置保存时，企微会发一个 GET 请求到你的 URL 来验证：

```
GET https://yourdomain.com/api/wecom/callback
  ?msg_signature=xxx
  &timestamp=xxx
  &nonce=xxx
  &echostr=xxx
```

你的后端需要：
1. 把 `msg_signature`、`timestamp`、`nonce`、`Token`（你配置的那个）按字典序排序
2. SHA1 加密得到签名
3. 和 `msg_signature` 对比
4. 一致的话，解密 `echostr`（AES + EncodingAESKey），把明文返回

```python
# Python 伪代码
import hashlib, time, random, string
from Crypto.Cipher import AES

def verify_callback(token, timestamp, nonce, echostr, msg_signature, encoding_aes_key):
    # 1. 校验签名
    sort_list = sorted([token, timestamp, nonce])
    sha1 = hashlib.sha1(''.join(sort_list).encode()).hexdigest()
    assert sha1 == msg_signature, "签名校验失败"

    # 2. 解密 echostr
    key = base64.b64decode(encoding_aes_key + '=')
    cipher = AES.new(key, AES.MODE_CBC, iv=key[:16])
    plaintext = cipher.decrypt(base64.b64decode(echostr))
    # 去除 PKCS7 padding
    pad = plaintext[-1]
    plaintext = plaintext[:-pad]
    # 去掉前面 16 字节随机串 + 4 字节 corpId 长度 + corpId
    return plaintext[16:]
```

### 3. 消息加解密模式

| 模式 | 说明 | 推荐 |
| --- | --- | --- |
| **明文模式** | 只验签，消息体明文传输 | 本地调试 |
| **兼容模式** | 同时支持明文和加密 | 过渡期 |
| **安全模式** | 必须验签 + AES 加解密 | ✅ 生产环境 |

## 第四步：配置应用可见范围

**很多新手踩的坑**：创建了应用，但员工在工作台看不到。

检查「应用详情」→「可见范围」：
- 默认可能只包含「创建者自己」
- 需要把目标部门或成员加进去
- 支持按部门、按标签、按成员三种方式

## 第五步：配置自建应用菜单

应用详情页 → 「应用主页」→ 「设置」：

- **主页 URL**：微应用 H5 入口地址，比如 `https://yourdomain.com/app/home`
- **工作台展示**：是否在工作台显示
- **菜单按钮**：自定义底部菜单（类似公众号底部菜单）

```
┌─────────────────────────┐
│   工作台图标（员工可见）   │
│      📊 数据报表         │
└─────────────────────────┘

┌─────────────────────────┐
│   数据报表微应用          │
│  ┌─────┬─────┬─────┐    │
│  │日报  │周报  │月报  │    │
│  └─────┴─────┴─────┘    │
└─────────────────────────┘
```

## 第六步：本地开发环境搭建

### 方案 A：内网穿透（推荐）

用 cpolar 或 ngrok 把本地端口暴露到公网 HTTPS：

```bash
# cpolar（国内速度快）
cpolar http 8080

# ngrok
ngrok http 8080

# 输出类似 Forwarding  https://xxxx.ngrok-free.app -> http://localhost:8080
# 把这个 HTTPS 地址填到回调 URL
```

### 方案 B：企微沙箱环境

企微提供了测试号（类似微信测试号），但需要企业微信管理员申请。

### 方案 C：先用明文模式调试

本地开发时先用明文模式跳过加解密，跑通主流程后再切安全模式。

## access_token 获取与缓存

access_token 是调所有企微 API 的前提：

```
GET https://qyapi.weixin.qq.com/cgi-bin/gettoken
  ?corpid=your_corp_id
  &corpsecret=your_app_secret

# 返回
{
  "access_token": "xxxxxx",
  "expires_in": 7200   // 2 小时有效期
}
```

**缓存要点**：
- 有效期 7200 秒，提前 5 分钟刷新（7200 - 300 = 6900）
- 每个应用的 access_token 独立（不同 Secret 不同 token）
- **重要**：频控！每天 2000 次获取上限，超时后当天不能再调

```python
class WeComTokenManager:
    def __init__(self, corpid, secret, cache_file='/tmp/wecom_token.json'):
        self.corpid = corpid
        self.secret = secret
        self.cache_file = cache_file

    def get_token(self):
        cached = self._load_cache()
        if cached and cached['expire_at'] > time.time() + 300:
            return cached['access_token']

        resp = requests.get(
            'https://qyapi.weixin.qq.com/cgi-bin/gettoken',
            params={'corpid': self.corpid, 'corpsecret': self.secret}
        ).json()

        if 'access_token' not in resp:
            raise Exception(f"获取 token 失败: {resp}")

        self._save_cache(resp['access_token'], time.time() + resp['expires_in'])
```

## 完整配置清单

| 配置项 | 在哪配 | 用途 |
| --- | --- | --- |
| CorpID | 我的企业 | 企业唯一标识 |
| AgentID | 自建应用详情 | 应用唯一编号 |
| Secret | 自建应用详情 | 应用密钥 |
