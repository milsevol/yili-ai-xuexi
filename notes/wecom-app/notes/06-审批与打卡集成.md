# 06 审批与打卡集成

## 一句话

企微内置了审批流引擎和打卡系统，你可以用 API 读取审批实例、监听审批结果、获取打卡数据，把 OA 流程嵌入到自己的业务系统里。

## 审批系统全景

```
员工发起申请
    │
    ▼
企微审批模板（可视化配置）
    │
    ├─ 审批通过 ──▶ 你的回调 URL（approval 事件）
    │
    ├─ 审批驳回 ──▶ 你的回调 URL
    │
    └─ 审批撤回 ──▶ 你的回调 URL
                      │
                      ▼
                  你的后端处理
                  （更新业务系统）
```

## 第一步：配置审批模板

管理后台 → 「应用管理」→ 「审批」→ 「创建审批模板」：

### 审批模板要素

| 要素 | 说明 | 示例 |
| --- | --- | --- |
| **模板名称** | 员工可见 | 报销申请 / 请假申请 |
| **审批人** | 两级/三级审批 | 直属经理 → 部门总监 → HR |
| **抄送人** | 审批完成后通知谁 | 财务 / 人事 |
| **表单控件** | 申请表单里的字段 | 金额（数字）、事由（文本）、发票（图片） |

### 示例：报销申请模板

```
┌────────────────────────────────────┐
│  报销申请                            │
├────────────────────────────────────┤
│  ✍️ 报销事由  [________________]    │
│  💰 报销金额  [_____] 元             │
│  📎 发票照片  [+ 上传]               │
│  📅 发生日期  [2024-01-15]           │
├────────────────────────────────────┤
│  审批流程：                          │
│  员工提交 → 经理审批 → 财务审批 → 打款│
└────────────────────────────────────┘
```

### 配置审批回调

审批模板创建后，在模板详情页开启「状态变更回调」，企微会把审批通过/驳回事件推送到你的回调 URL。

## 审批 API

### 1. 获取审批模板列表

```bash
POST https://qyapi.weixin.qq.com/cgi-bin/oa/approval/list
  ?access_token=TOKEN

{
  "ids": ["模板ID1", "模板ID2", "..."]
}
```

### 3. 审批回调事件处理

```python
# 企微 POST 到你的回调 URL（和消息回调是同一个！）
# 判断 MsgType='event'，Event='approval'

def handle_approval_event(root):
    approval_event = root.find('Approval')
    approval_id = approval_event.find('ApprovalCode').text
    status = approval_event.find('SpStatus').text  # 1审批中 2通过 3驳回 4撤回
    applyer = approval_event.find('ApplyUserId').text

    # 拉取审批详情
    detail = get_approval_detail(approval_id)

    # 更新业务系统
    if status == '2':  # 已通过
        # 在 ERP 系统中创建报销单，触发打款流程
        create_erp_expense(detail)
    elif status == '3':  # 已驳回
        notify_applyer(applyer, "报销申请已驳回，请修改后重新提交")
```

## 打卡系统 API

### 1. 获取打卡规则

```bash
POST https://qyapi.weixin.qq.com/cgi-bin/checkin/getcheckindata
  ?access_token=TOKEN

{
  "datetime": 1705392000,
  "useridlist": ["UserID1", "UserID2"],
  "type": 3  # 1=上下班打卡，2=外出打卡，3=全部
}

# 返回每个员工当天的打卡详情
```

### 2. 获取打卡数据

```bash
POST https://qyapi.weixin.qq.com/cgi-bin/checkin/getcheckindata
  ?access_token=TOKEN

{
  "opencheckindatatype": 3,
  "starttime": 1705305600,
  "endtime": 1705392000,
  "useridlist": ["UserID1"]
}

# 返回
{
  "info": [
    {
      "userid": "UserID1",
      "groupname": "行政班",
      "checkintime": 1705392000,
      "checkouttime": 1705428000,
      "result": {
        "work_in": {
          "lat": 39.9, "lng": 116.4, "loc": "公司门口",
          "late": 0, "remark": ""
        },
        "work_out": {
          "lat": 39.9, "lng": 116.4, "loc": "公司门口",
          "late": 0
```

### 3. 打卡回调事件

员工打卡后，企微会推送 `check_in` 事件到你的回调 URL：

```python
def handle_checkin_event(root):
    # Event = 'check_in'
    userid = root.find('UserID').text
    checkin_type = root.find('CheckinType').text  # 1=上班 2=下班

    # 触发业务逻辑，比如考勤系统实时更新
    update_attendance(userid, checkin_type)
```

## 实战场景：报销 → 审批 → 打款 全链路

```
1. 员工在企微工作台点「报销助手」
        │
        ▼
2. 微应用 H5 填写报销单
        │
        ▼
3. 调 API applyevent 发起审批
        │
        ▼
4. 经理在企微聊天里收到审批通知 → 审批通过
        │
        ▼
5. 企微推送 approval 事件 → 你的后端
        │
        ▼
6. 后端拉审批详情 → 创建 ERP 报销单
        │
        ▼
7. 调用企业财务系统 → 触发打款
        │
        ▼
8. 打款后 → 调消息 API 推给员工「报销已打款 1250 元」
```
