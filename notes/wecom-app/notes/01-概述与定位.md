# 01 概述与定位

## 一句话

**企业微信（WeCom）**：腾讯面向企业的通讯协作平台，开放 API 让企业内部系统嵌入 IM 能力、OA 审批、客户管理、侧边栏轻应用。不只是「企业版微信」，更是企业数字化的**统一入口**。

## 为什么需要企业微信

企业内部 IT 系统的普遍痛点：员工装一堆 App 各管各的、审批在 OA、沟通在微信、客户资料在 CRM —— 数据割裂、入口分散、移动端体验差。企微的核心解法是**把通讯、审批、应用、客户这四件事统一到一个入口**：

| 现实问题 | 传统做法 | 企微的做法 |
| --- | --- | --- |
| 审批流程多：请假 / 报销 / 采购各一套 | 装 OA、发邮件、走纸质 | 企微审批模板，内置可视化流程 |
| 内部系统移动端体验差 | 写原生 App 成本高、H5 体验弱 | 企微微应用 = 容器 + JS-SDK，一次开发两端通 |
| 客户沟通用私人微信，客户关系离职带不走 | 销售私人号、CRM 又不实时 | 客户联系 API：客户身份绑定企业、聊天留痕 |
| 内部通知经常漏看 | 邮件、短信、电话轰炸 | 企微应用消息推送，已读回执 |
| 新员工入职，装一堆东西 | 给个 U 盘、配个 VPN、一个一个装 | 通讯录成员开通后直接进入企业组织架构 |

## 企业微信 vs 微信 vs 钉钉

| 维度 | 企业微信 | 微信开放平台 | 钉钉 |
| --- | --- | --- | --- |
| **定位** | 企业内部 + 企业间客户联系 | C 端用户社交 | 阿里生态 OA 平台 |
| **身份体系** | CorpID + UserID（企业成员） | OpenID + UnionID（C 端用户） | 企业 ID + staffId |
| **应用类型** | 自建应用、代开发应用、第三方应用 | 公众号、小程序、服务号 | H5 应用、微应用 |
| **API 开放度** | 全开放（内部管理、OA、客户） | 受限（关注关系、模板消息） | 全开放（阿里系深度） |
| **客户联系** | ✅ 专属 API | ✅ 企业微信客服 | ❌ |
| **审批/打卡** | ✅ 内置 API | ❌ | ✅ 内置 API |
| **消息推送** | 应用消息、卡片、模板消息 | 模板消息、订阅消息 | 工作通知 |
| **外部联系** | 可添加普通微信用户 | 本来就是微信用户 | 有限 |
| **适合场景** | 已有微信生态、需要同时服务内部和外部客户 | 面向 C 端用户 | 阿里生态深度集成 |

## 企业微信开放平台架构

```
  开发者
    │
    ▼
┌──────────┐   access_token    ┌──────────────┐
│ 自建应用  │ ───────────────▶  │  企微服务器   │
│ (你的后端) │ ◀─────────────── │  (api.weixin │
│           │   回调事件 POST    │   .qq.com)   │
└────┬─────┘                   └──────┬───────┘
     │                                │
     │ 微应用前端(H5)                 │ 消息下发
     ▼                                ▼
┌──────────┐                   ┌──────────────┐
│ 员工手机  │                   │ 企微 App      │
│ 企微客户端 │ ◀── JS-SDK API ── │ (聊天/通讯录) │
└──────────┘                   └──────────────┘
```

**核心概念三要素**：

| 要素 | 说明 | 在哪获取 |
| --- | --- | --- |
| **CorpID** | 企业唯一标识，类似公司的身份证 | 企业管理后台 → 我的企业 → 企业信息 |
| **AgentID** | 自建应用的唯一编号 | 应用管理 → 自建应用详情页 |
| **Secret** | 应用的访问密钥，类似应用的密码 | 自建应用详情页（注意保密！） |

## 开发链路总览

```
① 注册企业微信 → 获取 CorpID
② 创建自建应用 → 获取 AgentID + Secret
③ 配置回调 URL → 接收消息/事件推送
④ 后端获取 access_token → 调用 API
⑤ 开发微应用前端(H5) → JS-SDK 调起原生能力
⑥ 联调测试 → 沙箱环境验证
⑦ 上线 → 发布到企微工作台
```

## 发展简史

- **2016** 企业微信 1.0 发布，定位企业内部 IM
- **2018** 上线客户联系能力，打通企业微信 ↔ 个人微信
- **2020** 上下游、消费者微信联动，"三个连接" 战略成型
- **2022** 企业微信 4.0，视频号、客服、会议深度融合
- **2024+** AI 能力内嵌（智能报表、AI 助理）、微信生态更紧密
