# 08 微应用与小程序

## 一句话

企微微应用（H5 容器）、企微小程序（原生小程序框架）、第三方应用（ISV 市场上架）是三种不同形态。微应用一次开发两端通，小程序体验更好但能力受限。

## 三者对比

| 维度 | 微应用（H5） | 企微小程序 | 第三方应用 |
| --- | --- | --- | --- |
| **技术栈** | HTML + CSS + JS | WXML + WXSS + JS | 后端接口 |
| **开发成本** | 低，Web 技术复用 | 中，需学小程序语法 | 低，ISV 上架即可 |
| **原生能力** | JS-SDK 有限 | 完整（扫码、支付、订阅消息） | 有限 |
| **离线能力** | 无 | 部分支持缓存 | 无 |
| **上架方式** | 自建（内部使用） | 自建（内部）或上架市场 | 上架企微应用市场 |
| **适用场景** | 内部工具、CRM、报表 | 高频轻应用、员工自助 | 给其他企业用 |

## 微应用开发

微应用本质上就是一个 H5 页面 + JS-SDK：

### 最小微应用骨架

```
my-wecom-app/
  ├── index.html        # 入口页
  ├── login.html         # OAuth 登录页
  ├── pages/
  │   ├── home.html     # 首页
  │   ├── report.html   # 日报页
  │   └── settings.html
  ├── css/
  ├── js/
  │   ├── auth.js       # 登录/OAuth
  │   ├── api.js        # 后端接口
  │   └── wecom.js      # JS-SDK 封装
  └── backend/          # Node.js / Python 后端
```

### 移动端适配要点

企微微应用运行在移动端（iOS / Android），和普通 Web 有几个差异：

```html
<!-- 必须加 viewport -->
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">

<!-- 禁用双指缩放（企微内不支持） -->
<!-- touch-action 优化 -->
<style>
  * { box-sizing: border-box; -webkit-tap-highlight-color: transparent; }
  body {
    font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", sans-serif;
    background: #f5f5f7;
    padding-bottom: env(safe-area-inset-bottom);  <!-- iPhone 底部安全区 -->
  }
  .hide-in-wecom { display: none; }  <!-- 在 PC 浏览器调试时隐藏某些元素 -->
</style>
```

### 检测运行环境

```javascript
function isWecomEnv() {
  const ua = navigator.userAgent.toLowerCase()
  return ua.includes('wxwork') || ua.includes('wecom')
}

if (isWecomEnv()) {
  // 初始化 JS-SDK
  initWxConfig()
} else {
  // PC 浏览器调试模式，模拟数据
  useMockData()
}
```

## 企微小程序开发

企微小程序基于微信小程序框架，语法和微信小程序几乎一致，但能力略有差异。

### 小程序项目结构

```
my-wecom-miniprogram/
  ├── app.js
  ├── app.json
  ├── app.wxss
  ├── pages/
  │   ├── index/
  │   │   ├── index.js
  │   │   ├── index.json
  │   │   └── index.wxml
  │   └── detail/
  └── utils/
```

### app.json 配置

```json
{
  "pages": [
    "pages/index/index",
    "pages/detail/detail"
  ],
  "window": {
    "navigationBarTitleText": "日报助手",
    "navigationBarBackgroundColor": "#1d4ed8",
    "navigationBarTextStyle": "white"
  },
  "permission": {
    "scope.userLocation": {
      "desc": "用于打卡定位"
    }
  }
}
```

### 小程序登录

企微小程序的登录和普通小程序不同：

```javascript
// app.js
App({
  onLaunch: function () {
    wx.login({
      success: (res) => {
        // res.code → 后端调 jscode2session
        wx.request({
          url: 'https://yourdomain.com/api/miniprogram/login',
          data: { code: res.code },
          success: (resp) => {
            // resp.data.userid, session_key
            wx.setStorageSync('userid', resp.data.userid)
          }
        })
      }
    })
  }
})
```

### 订阅消息

小程序可以给员工发订阅消息（类似推送）：

```javascript
// 前端请求订阅授权
wx.requestSubscribeMessage({
  tmplIds: ['模板ID1', '模板ID2'],
  success: (res) => {
    // res['模板ID1'] = 'accept' | 'reject'
  }
})

// 后端发送订阅消息
POST https://qyapi.weixin.qq.com/cgi-bin/miniprogram/subscribe_send
  ?access_token=TOKEN

{
  "to_user": "UserID1",
  "template_id": "模板ID",
  "page": "pages/index/index",
  "data": {
    "thing1": { "value": "报销申请" },
    "time2": { "value": "2024-01-15 14:30" }
  }
}
```

### 小程序跳转微应用

小程序内可以跳转到微应用页面：

```javascript
wx.openEmbeddedMiniProgram({
  appId: 'CORP_ID',
  path: 'pages/webview/index?url=https://yourdomain.com/app'
})
```

## 微应用 vs 小程序：怎么选

| 你的情况 | 推荐 |
| --- | --- |
| 只有 Web 开发经验 | 微应用（H5） |
| 已有 Web 前端，要快速上线 | 微应用 |
| 需要复杂 UI/交互、高频使用 | 小程序 |
| 需要离线能力 | 小程序 |
| 需要发布到企微应用市场给其他企业用 | 第三方应用（需要认证） |
