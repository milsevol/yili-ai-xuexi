# 07 通讯录与身份验证

## 一句话

通讯录 API 让你同步企业的成员/部门架构，OAuth2 网页授权让微应用识别「当前操作者是谁」，三者组合起来就是企业内部应用的身份基础设施。

## 通讯录数据模型

```
企业（CorpID）
  │
  ├── 部门 0（根部门）
  │     │
  │     ├── 部门 1（技术部）
  │     │     ├── 成员 A（UserID1）
  │     │     └── 成员 B（UserID2）
  │     ├── 部门 2（市场部）
  │     │     ├── 成员 C（UserID3）
  │     │     └── 成员 D（UserID4）
  │     └── 部门 3（产品部）
  │
  └── 成员属性
        ├── UserID（员工唯一标识，企业内）
        ├── Name（姓名）
        ├── Mobile（手机号，加密存储）
        ├── Email
        ├── Position（职位）
        ├── Department（所属部门 ID 列表）
        └── Tag（成员标签）
```

## 通讯录 API

### 1. 获取部门列表

```bash
GET https://qyapi.weixin.qq.com/cgi-bin/department/list
  ?access_token=TOKEN
  &id=0    # 0=根部门，返回所有

# 返回
{
  "department": [
    {"id": 1, "name": "技术部", "parentid": 0, "order": 1},
    {"id": 2, "name": "市场部", "parentid": 0, "order": 2},
    {"id": 3, "name": "前端组", "parentid": 1, "order": 1}
  ]
}
```

### 2. 获取成员详情

```bash
GET https://qyapi.weixin.qq.com/cgi-bin/user/get
  ?access_token=TOKEN
  &userid=UserID1

# 返回
{
  "userid": "UserID1",
  "name": "张三",
  "department": [1, 3],
  "mobile": "138****1234",     // 敏感字段脱敏！
  "email": "zhangsan@company.com",
  "position": "前端工程师",
  "gender": 1,
  "avatar": "https://...",
  "status": 1                   // 1=正常 2=已离职 4=未激活
}
```

### 3. 批量获取部门成员

```bash
GET https://qyapi.weixin.qq.com/cgi-bin/user/list
  ?access_token=TOKEN
  &department_id=1
  &fetch_child=1               # 1=包含子部门

# 返回部门下所有成员的简要信息
```

### 4. 敏感数据获取权限

> ⚠️ **重要**：手机号、邮箱等敏感字段默认脱敏（`138****1234`）。要获取完整数据，需要：
> 1. 管理员在「通讯录权限」中给应用授权
> 2. 前端发起 `getuserinfo` 授权请求
> 3. 用户同意后才能拿到完整数据

```javascript
// 前端发起敏感信息授权
WwOpen.invoke('getuserinfo', {
  scope: 'snsapi_privateinfo',
  corpId: 'CORP_ID',
  agentid: 1000002,
  success: function (res) {
    // res.user_info.user_id = 'UserID1'
    // res.user_info.mobile = '13800001234'（完整手机号）
  }
})
```

## OAuth2 网页授权：识别当前用户

微应用 H5 页面打开时，需要知道「谁在看这个页面」——这就是 OAuth2 网页授权的作用。

### 授权流程（3 步）

```
① 前端跳转到企微授权链接
    │
    ▼
② 企微自动跳转回你的页面，带上 auth_code
    │
    ▼
③ 你用 auth_code 换 UserID
```

### 第一步：跳转授权

```javascript
// 微应用首页加载时，检测是否已有登录态
const authUrl = `https://open.weixin.qq.com/connect/oauth2/authorize?appid=${CORP_ID}&redirect_uri=${encodeURIComponent(REDIRECT_URI)}&response_type=code&scope=snsapi_base&agentid=${AGENT_ID}#wechat_redirect`

if (!localStorage.getItem('userid')) {
  location.href = authUrl
}
```

### 第二步：企微自动跳转回来

```
# 企微跳回你的 redirect_uri，带上 code 参数
https://yourdomain.com/app/home?code=CODE_XXX&state=STATE#wechat_redirect
```

> **scope 说明**：
> - `snsapi_base`：静默授权，只能拿到 UserID，用户无感
> - `snsapi_privateinfo`：用户授权后才能拿敏感信息（手机号、邮箱）

### 第三步：用 code 换 UserID（后端做）

```bash
POST https://qyapi.weixin.qq.com/cgi-bin/miniprogram/jscode2session
  ?access_token=TOKEN

{
  "auth_code": "CODE_XXX"
}

# 返回
{
  "userid": "UserID1",
  "session_key": "xxx",
  "corp_id": "CORP_ID"
}
```

> 老版本用的是：
> `GET https://qyapi.weixin.qq.com/cgi-bin/user/getuserinfo?access_token=TOKEN&code=CODE_XXX`
> 现在推荐 jscode2session。

### 完整登录态示例

```python
# 后端：用 code 换 UserID，生成业务登录态

@app.get('/api/auth/callback')
def auth_callback():
    code = request.args.get('code')
    if not code:
        return redirect('/')

    # 1. 用 code 换 UserID
    token = token_mgr.get_token()
    resp = requests.post(
        f"https://qyapi.weixin.qq.com/cgi-bin/miniprogram/jscode2session?access_token={token}",
        json={"auth_code": code}
    ).json()

    userid = resp.get('userid')
    if not userid:
        return redirect(f'/login?error={resp.get("errmsg")}')

    # 2. 生成业务 session
    session_id = create_session(userid)

    # 3. 重定向回前端
    return redirect(f'/app/home?session={session_id}')
```

## UserID vs OpenID 转换

| 场景 | 需要转换 |
| --- | --- |
| 自建应用内 | 用 UserID |
| 客户联系（外部） | 用 ExternalUserID |
| 企业间互通 | 可能需要 OpenID |

```bash
# UserID 转 OpenID
POST https://qyapi.weixin.qq.com/cgi-bin/user/convert_to_openid
  ?access_token=TOKEN

{
  "userid_list": ["UserID1", "UserID2"]
}

# 返回
{
  "openid_list": [
    {"userid": "UserID1", "openid": "oDJ..."},
    {"userid": "UserID2", "openid": "oXX..."}
  ]
}
```

## 通讯录事件回调

成员/部门变更时，企微会推送事件到你的回调 URL：

| Event | 触发时机 |
| --- | --- |
| change_contact | 成员变更（新增/修改/离职） |
| edit_contact | 部门变更 |

```python
def handle_change_contact(root):
    # Event='change_contact', ChangeType='create'|'update'|'leave'
    change_type = root.find('ChangeType').text
    sync_time = root.find('TimeStamp').text

    if change_type == 'leave':
        # 员工离职 → 触发离职继承流程
        userid = root.find('UserID').text
        trigger_resign_process(userid)
```
